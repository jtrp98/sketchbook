# HIG: ฐานราก (ตัวอักษร สี วัสดุ layout ขนาดควบคุม)

ตรวจร่วมกับ `hig-macos-bars.md` อ้างเป็นเลขข้อ เช่น "HF2: ตัวอักษรเล็กกว่า 10 pt"
ถ้าโปรเจกต์มี brand (`projects/<ชื่อ>/brand.md`) ค่าหน้าตาใช้ตาม brand ส่วนข้อนี้ใช้เป็น**ขั้นต่ำและพฤติกรรม**ที่ผู้ใช้ Mac คาดหวัง ถ้าขัดกัน ให้บันทึกเป็นข้อตัดสินใจใน design ไม่เลือกเงียบ ๆ
ค่าของ Apple ที่ "ไม่ควร hardcode" (สีระบบ) ให้ใช้ชื่อ semantic แทนค่า hex

## ตัวเลขที่ต้องจำ

| เรื่อง | macOS | หมายเหตุ |
|---|---|---|
| ขนาดตัวอักษรปริยาย / ต่ำสุด | 13 pt / 10 pt | iOS 17 / 11 pt, visionOS 17 / 12 pt |
| ขนาดปุ่ม/ตัวควบคุมปริยาย / ต่ำสุด | 28×28 pt / 20×20 pt | iOS/iPadOS 44 / 28, visionOS 60 / 28 (44 pt ไม่ใช่เกณฑ์ของ Mac) |
| ระยะรอบตัวควบคุม | ~12 pt รอบปุ่มที่มีกรอบ, ~24 pt รอบองค์ประกอบที่ไม่มีกรอบ | กันกดผิด |
| divider ของ split view | 1 pt (แบบบาง) | |
| ช่องว่างรอบรูปในปุ่มรูป | ~10 px | ขอบปุ่มคือพื้นที่คลิก |
| ชื่อหน้าต่าง | < 15 ตัวอักษร | |
| แท็บใน tab view | ไม่เกิน 6 | |

## เกณฑ์ตรวจ

| # | หมวด | เกณฑ์ | ตัวอย่างที่ไม่ผ่าน |
|---|---|---|---|
| HF1 | Hierarchy / layout | เรียงตามความสำคัญ (บน-ซ้ายสำคัญสุดในภาษาอ่านซ้ายไปขวา) จัดแนวเพื่อให้สแกนง่าย ใช้ย่อหน้าบอกลำดับชั้น จัดกลุ่มด้วยที่ว่าง/กล่อง/เส้นคั่น เปิดเผยทีละชั้นด้วย disclosure/เมนู | ทุกองค์ประกอบขนาดเดียวกัน ไม่มีกลุ่ม |
| HF2 | ตัวอักษร | ไม่เล็กกว่า 10 pt บน Mac ใช้ text style ที่กำหนดไว้เป็นฐาน ลดจำนวนชนิดฟอนต์ ไม่ใช้น้ำหนัก Ultralight/Thin/Light (โดยเฉพาะตัวเล็ก) ใช้น้ำหนัก/ขนาด/สีสร้างลำดับ | ตัวอักษร 9 pt น้ำหนัก Light |
| HF3 | ขนาดควบคุม | พื้นที่กดไม่เล็กกว่า 20×20 pt (ปริยาย 28×28) มีระยะรอบตัวควบคุมพอกันกดพลาด (~12 pt / ~24 pt) | ปุ่มไอคอน 16 pt ชิดกัน |
| HF4 | สี: ความหมายเดียว | สีหนึ่งสีสื่อความหมายเดียว ไม่ใช้สีแบรนด์ทั้งกับสิ่งที่กดได้และข้อความธรรมดา | ข้อความน้ำเงินที่กดไม่ได้ |
| HF5 | สี: ทุกโหมด | ใช้ได้ทั้ง light, dark และ Increase Contrast สีเปลี่ยนตามหน้าตาระบบ ทดสอบทั้งสภาพแสงสว่างและมืด | ออกแบบ light อย่างเดียว |
| HF6 | สี: ไม่พึ่งสีอย่างเดียว | ข้อมูลสำคัญ/สถานะ/ความเป็นปุ่มต้องมีข้อความหรือรูปทรงคู่สี และสื่อได้ในวัฒนธรรมของผู้ใช้ (แดงไม่ได้แปลว่าอันตรายทุกที่) | สถานะบอกด้วยจุดแดง/เขียวอย่างเดียว |
| HF7 | สีระบบ | ใช้สี semantic (ชื่อตามหน้าที่ เช่น พื้นหลัง, ข้อความ, accent ของระบบ) ไม่ hardcode ค่า และไม่เปลี่ยนความหมายของสีระบบ (เช่น เอาสีพื้นหลังมาเป็นสีข้อความ) สีควบคุมที่ผู้ใช้เลือกใน System Settings ต้องสะท้อนใน sidebar | ไอคอน sidebar ไม่ตาม accent |
| HF8 | Liquid Glass: ชั้นของมัน | ใช้กับชั้น controls/navigation ที่ลอยเหนือเนื้อหา (toolbar, sidebar, tab bar) เท่านั้น ไม่ใช้ในชั้นเนื้อหา (พื้นหลัง app ใช้ standard material) ใช้กับ control ที่ทำเองให้น้อย ปล่อยให้ component มาตรฐานรับผิวนี้เอง | การ์ดเนื้อหาทุกใบเป็นกระจก |
| HF9 | Liquid Glass: ชนิด | ใช้ regular เป็นหลัก (เบลอ ปรับความสว่างให้อ่านได้) ใช้ clear เฉพาะบนพื้นหลังภาพ/วิดีโอสด ถ้าพื้นหลังสว่าง เพิ่มชั้นมืด ~35% ใต้ clear | กระจกใส ตัวหนังสือจมในรูปสว่าง |
| HF10 | Liquid Glass: สี | โดยปริยายแถบเป็นสีเดียว ไม่มีสีของตัวเอง ใส่สีเฉพาะที่ควรเน้น (action หลัก, สถานะ) และใส่ที่พื้นหลังของปุ่ม ไม่ใช่ที่สัญลักษณ์/ข้อความ ถ้าพื้นหลังสีสด ให้แถบเป็นโทนเดียว | ไอคอนและป้ายใน toolbar สีสดทุกปุ่ม |
| HF11 | แยกตัวควบคุมออกจากเนื้อหา | ใช้ผิวกระจก/scroll edge effect ยกตัวควบคุมให้ลอยเหนือเนื้อหา แทนการทาพื้นทึบใต้ตัวควบคุม ขยายเนื้อหา/ภาพพื้นหลังไปใต้ sidebar และ toolbar | พื้นขาวทึบใต้ toolbar ตัดภาพขาดครึ่ง |
| HF12 | ปรับตามขนาดหน้าต่าง | layout ปรับตามขนาดหน้าต่างที่ผู้ใช้ย่อขยาย ฟีเจอร์ไม่เปลี่ยนตามขนาด (ปริมาณที่เห็นเปลี่ยนได้) ตั้งขนาดต่ำสุดที่ UI ไม่ทับกัน | ย่อหน้าต่างแล้วปุ่มทับกัน |
| HF13 | ไม่วางสิ่งสำคัญที่ขอบล่าง | ผู้ใช้มักลากหน้าต่างให้ขอบล่างหลุดจอ (ตรงกับ HM21) | ปุ่มหลักอยู่ล่างสุด |
| HF14 | ปุ่ม | ป้ายปุ่มบอกสิ่งที่จะเกิด ใส่ … เมื่อเปิดหน้าต่างหรือรับข้อมูลเพิ่ม ปุ่มรูปมีช่องว่างในรอบรูป (~10 px) ปุ่มรูป/ปุ่ม help อยู่ใน view ไม่ใช่ใน frame หน้าต่าง | ปุ่ม "OK" ไม่บอกว่าตกลงอะไร |
| HF15 | คีย์บอร์ด | รองรับการใช้คีย์บอร์ดล้วน (Full Keyboard Access, tab ไปตามลำดับ) shortcut มาตรฐานทำงานเหมือนเดิม คำสั่งที่ใช้บ่อยเฉพาะ app มี shortcut ในเมนู | ทำได้เฉพาะเมาส์ |
| HF16 | ทางเลือกนอกจาก gesture | งานสำคัญทำได้ด้วยวิธีที่ไม่ใช่ gesture ซับซ้อน (มีปุ่มคู่กับการปัด/หลายนิ้ว) ป้ายควบคุมครบสำหรับ VoiceOver/Voice Control | ลบได้ด้วยการปัดอย่างเดียว |

## วิธีใช้
- **Feasibility:** เช็กค่าขั้นต่ำและพฤติกรรมของ platform ที่ requirement ไปชน (HF3, HF12, HF15, HF16)
- **Designer:** ใช้ตาราง "ตัวเลขที่ต้องจำ" และ text styles เป็นฐาน แล้วใส่ค่าหน้าตาจาก brand ของโปรเจกต์ ระบุข้อ HF ที่ใช้
- **Reviewer:** ให้ผล ผ่าน/ไม่ผ่าน/ไม่เกี่ยวข้อง รายข้อ HF1-HF16 ใช้คู่กับ `wcag-aa.md` (contrast คำนวณตามเกณฑ์ทีม ไม่ใช่ตามความรู้สึก)

## ระดับความรุนแรงเมื่อไม่ผ่าน
- **สูง:** อ่านหรือกดไม่ได้จนงานไม่สำเร็จ (HF2 เล็กเกิน, HF3 พื้นที่กดเล็กกว่าขั้นต่ำ, HF6 สื่อด้วยสีอย่างเดียว, HF13, HF15 ใช้ได้เฉพาะเมาส์)
- **กลาง:** ใช้ได้แต่สับสน/ไม่คุ้น (HF1, HF4, HF5, HF7, HF8, HF9, HF11, HF12, HF14, HF16)
- **ต่ำ:** ความประณีต (HF10)
