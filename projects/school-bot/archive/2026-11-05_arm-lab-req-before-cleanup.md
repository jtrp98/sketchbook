# R1, R5, R11, R14, R15, R17 ก่อนเกลา 2026-11-05 (ruler รอบ 8 · OQ71–OQ78)

- R1 (M): ใช้ frame 6A แขนกล (MainV6A) เป็นฐานฟังก์ชันและ layout · **อนุมัติแล้ว (DEC-08)** แก้ผ่านใบสั่งแก้เท่านั้น ห้ามทำใหม่ทั้งหน้า · ฟังก์ชันและพฤติกรรมความปลอดภัยต้องครบตาม R5, R12–R16 หลังปรับให้เข้ากับ cloud, Raspberry Pi และ ป.1–6 · **ขนาดปุ่ม/ตัวอักษรคงตาม 6A เดิม ไม่ปรับให้ผ่านเกณฑ์ ≥16px/44px** (ผู้ใช้ตัดสิน 2026-10-21 · OQ20) · โน้ตเพื่อทบทวนอนาคต: ใน 6A มี control ต่ำกว่า 16px อยู่ 129 จาก 152 ตัว ไม่ผ่านเกณฑ์เด็กของ brand/context.md (ความเสี่ยงที่ยอมรับ ร่วมกับ RSK-04) · (FR-10, AC-07, DEL-04)
- R5 (M): ปุ่มหยุดเห็นได้ตลอด · เตือนก่อนสั่งขยับไกลหรือเล่นวนไม่หยุด · ปิดปุ่มสั่งงานเมื่อหลุดการเชื่อมต่อ · (FR-14, NFR-04, AC-07)
- R11 (M): เชื่อมต่อหุ่นผ่าน USB ในโปรแกรมติดตั้ง Windows/Mac · ไม่ต้องติดตั้ง driver (ฝังใน installer) · สถานะ: ยังไม่เชื่อม (ปุ่มสั่งงานปิด) / กำลังเชื่อมต่อ / เชื่อมแล้ว / หลุด · ชื่อหุ่นและการจับคู่ → OQ5 · (NFR-03, EC-03, FR-11, ST-19, ST-20) · **เชื่อมไม่สำเร็จ** (หุ่นไม่ตอบ/พอร์ตถูกใช้) → กลับ "ยังไม่เชื่อม" + ข้อความผลบนหน้าเชื่อมต่อ ไม่ลิงก์กลับ workspace (ข้อเสนอ ruler ผู้ใช้ยังไม่ยืนยัน) · **ทางเข้า (ผู้ใช้ตัดสิน 2026-11-04 · OQ30, OQ43):** เข้า Arm Lab เห็นหน้างาน ไม่บังคับผ่านหน้าเชื่อมต่อก่อน · ปุ่มเชื่อมหุ่นถูกไฮไลต์ ชื่อ **"เชื่อมหุ่น"** (ยังไม่เชื่อม) / **"เปลี่ยนหุ่น"** (เชื่อมแล้ว) · ยังไม่เชื่อม: กดในพื้นที่ทำงานหลักขึ้น popup เตือนให้เชื่อมหุ่นแล้ว popup สั่น (ลดการเคลื่อนไหว = ไม่สั่น ใช้ไฮไลต์) ⟨OQ31/OQ34: ข้อยกเว้นของ "กดที่ใดก็ตาม" (แถบบน ☰ บันทึก ส่งออก ปุ่มหยุด dialog ระบบ)⟩ · **flow เริ่มต้น (ผู้ใช้ตัดสิน 2026-11-04):** กด "เชื่อมหุ่น" ใน workspace → หน้าเชื่อมต่อ → เลือกหุ่น → เชื่อมต่อ → กลับ workspace ทันที **ไม่มีขั้นพาไปท่าพัก ไม่มีติ๊กในหน้าเชื่อมต่อ ไม่มีขั้นตั้งชื่อไฟล์** · เชื่อมสำเร็จ: เน้น+สั่น "เพิ่มท่า" เฉพาะไฟล์ที่ไม่มีท่า G#### ที่ผู้ใช้เพิ่ม (ไม่นับท่า 0) · เชื่อมหุ่นไว้แล้วในรอบนี้แล้วเปิดไฟล์ใหม่/ไฟล์ที่สอง ⟨OQ54 ค: ข้ามเลย หรือ popup "ใช้หุ่นเดิมต่อ/หุ่นใหม่"⟩ · **ไฟล์อัตโนมัติ (ผู้ใช้ตัดสิน 2026-11-04 · OQ48, OQ54):** ทางเข้า "เริ่มต้น" = **เฉพาะเข้า Arm Lab ครั้งแรกจากปุ่มใน workspace ที่ไม่มีไฟล์งาน** ⟨OQ54 ข/OQ57 ง: นิยาม "ครั้งแรก/ไม่มีไฟล์งาน" และทางอื่นเมื่อไม่มีไฟล์ให้กลับ⟩ · เชื่อมสำเร็จ → สร้างไฟล์ชื่อ `Arm Lab 2026-11-04` (วันที่ปัจจุบัน ค.ศ.
