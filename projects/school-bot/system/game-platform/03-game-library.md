# 5. Game Library Strategy

## 5.1 แนวทาง

1. **จำนวน gameplay pattern:** 7 world/editor × กติกาใน Evaluator ให้ได้ **~10 แกนการเล่นที่ต่างกันจริง** (นำทาง, บีบโปรแกรม, ควบคุมสด, ตอบสนอง sensor, สอน AI, แก้ข้อมูล, ต่อวงจร, วินิจฉัย, ตัดสินใจไหลต่อเนื่อง, สร้างอิสระ) · มากกว่านี้ในปีแรกจะเกินกำลังดูแล (CON-05)
2. **เปลี่ยนธีมไม่เปลี่ยน engine:** `theme_pack` = sprite ของ tile/หุ่น/วัตถุ + สี accent + เสียง (จาก DS) · กติกาเดิมทั้งหมด · **ห้ามนับเกมที่ต่างแค่ธีมเป็นเกมใหม่**
3. **ปรับยากไม่เขียนเกมใหม่:** `difficulty_profile` (บล็อกที่เปิด, budget, ขนาดแผนที่, จำนวนแกน, ความไว, เวลา, fault ที่ใส่) · ทุกเกมมี 3–4 profile
4. **รวมความรู้หลายบทเรียน:** เกมระดับสูงเปิด engine หลายตัวพร้อมกัน (G3 Grid + Sensor + If · G13 Circuit + Program + Mechanic) · Evaluator ใช้ predicate ข้ามโดเมน (เช่น "ไปถึงเป้า **และ** ไม่มีวงจรเสีย")
5. **สร้างเกมใหม่จาก config:** ด่านเป็น JSON (06-config-schema.md) · มี `generator` (ตัวสร้างด่านสุ่มตามกติกา) สำหรับโหมดเล่นไม่สิ้นสุด → เหตุผลให้เล่นซ้ำโดยไม่ต้องผลิตเนื้อหาเพิ่ม
6. **เงื่อนไขรับเข้าคลัง** (กันหลักข้อ 1, 3): มีแกนการเล่นที่ไม่ซ้ำกับเกมอื่นในหมวด **และ** มีอย่างน้อย 1 ใน: ด่านสุ่ม · สร้างด่านเอง · แข่งสถิติตัวเอง · สร้างผลงาน

## 5.2 เกม 14 เกม

ชื่อเป็นชื่อทำงาน (ต้องผ่าน voice ใน brand.md) · ความยาก: ★ ป.1–2 · ★★ ป.3–4 · ★★★ ป.5–6 (เป็นคำแนะนำ ไม่ล็อก)

### G1 ทางลัดหุ่นจิ๋ว (Robot Adventure + Block Coding)
- **Objective:** ลำดับคำสั่ง · loop เพื่อลดคำสั่ง
- **Pattern / Engine:** Limited Block Challenge · Block Editor → IR → Grid World
- **Mechanics:** Block Budget, Step Execution, collect
- **Interaction:** ลากบล็อก ↑ ↶ ↷ ลงแถบโปรแกรม → ▶ หุ่นเดินทีละช่อง เก็บแบตเตอรี่
- **ความยาก:** ★ → ★★★ (profile ตาม 02 §4.1)
- **เล่นซ้ำเพราะ:** เป้าเสริม "บล็อกน้อยสุด" ท้าให้กลับมาบีบ (ไม่ใช่ดาว · Q7) · ด่านสุ่มรายวัน · **โหมดสร้างด่านให้เพื่อนแก้**

### G2 คีบให้ทัน (Robot Adventure)
- **Objective:** ทิศโยก ↔ การเคลื่อนข้อต่อ · ลำดับ pick & place · คัดแยก
- **Pattern / Engine:** Joystick Simulator · Joystick Input → Arm World
- **Mechanics:** Joystick Control, Pick & Place, Sorting
- **Interaction:** โยกก้าน แขนหมุน/ก้มตามจริง · กดปิดมือคีบรอบกล่อง · ย้ายลงตะกร้าสีตรงกัน
- **ความยาก:** ★ (แกนเดียว) → ★★★ (คัดแยกจับเวลา)
- **เล่นซ้ำเพราะ:** ความรู้สึกคุมเครื่องจักรจริง · สถิติเวลา · ของชิ้นใหม่ (ไข่ = ต้องคีบเบา, ลูกบอล = กลิ้ง)

### G3 รถสำรวจในความมืด (Robot Adventure + Block Coding)
- **Objective:** sensor + if/else · โปรแกรมที่ใช้ได้กับแผนที่ที่ไม่เคยเห็น
- **Pattern / Engine:** Grid World (แผนที่ซ่อน) + Sensor บนหุ่น + IR
- **Mechanics:** Step Execution, `if (ระยะ < x)`, `repeat until`
- **Interaction:** เห็นแค่ช่องรอบหุ่น · เขียนกฎ "ถ้าข้างหน้ามีกำแพง ให้เลี้ยวขวา" แล้วทดสอบกับ 3 แผนที่สุ่ม
- **ต่างจาก G1:** G1 วางเส้นทางที่รู้ล่วงหน้า · G3 เขียนพฤติกรรมที่ต้องใช้ได้ทุกแผนที่ (generalization)
- **ความยาก:** ★★ → ★★★
- **เล่นซ้ำเพราะ:** ผ่าน 3/3, 5/5, 10/10 แผนที่สุ่ม · ไม่มีเฉลยตายตัว

### G4 สอนหุ่นแยกขยะ (AI Playground)
- **Objective:** AI เรียนจากตัวอย่าง · ข้อมูลน้อย/ลำเอียง = AI พลาด
- **Pattern / Engine:** AI Training (classifier จากชุดภาพที่เตรียมไว้)
- **Mechanics:** Drag (ภาพ → ถังป้าย), Sorting (ทดสอบบนสายพาน)
- **Interaction:** ลากภาพลงถัง "กระดาษ/พลาสติก/เศษอาหาร" → กดสอน → ของใหม่ไหลมาบนสายพาน AI ทาย พร้อมแถบความมั่นใจ
- **ความยาก:** ★ (2 ถัง) → ★★★ (4 ถัง, ของกำกวม)
- **เล่นซ้ำเพราะ:** ชุดทดสอบเปลี่ยนทุกรอบ · ท้า "สอนด้วยภาพน้อยที่สุดให้ถูก 8/10"

### G5 หมอข้อมูล (AI Playground)
- **Objective:** คุณภาพข้อมูล · ข้อมูลผิดทำ AI ผิด (ต่อจาก ป.1 "Real or Not", "รู้ทันข้อมูล")
- **Pattern / Engine:** AI Training (ชุดข้อมูลที่ถูกใส่ป้ายผิดไว้) + Debug Mode กับข้อมูล
- **Mechanics:** Fault Inject (ป้ายผิด), Drag ย้ายป้าย
- **Interaction:** AI ทายแมวเป็นหมาบ่อย → เปิดกองข้อมูลสอน หาภาพที่ป้ายผิด แก้แล้วสอนใหม่ ดูความแม่นขึ้น
- **ต่างจาก G4:** G4 สร้างข้อมูล · G5 วินิจฉัยข้อมูล
- **ความยาก:** ★★
- **เล่นซ้ำเพราะ:** คดีใหม่ (ชุดข้อมูลใหม่) · เวลาที่ใช้ปิดคดี

### G6 เต้นตามจังหวะ (Block Coding)
- **Objective:** หารูปแบบที่ซ้ำ · loop ซ้อน
- **Pattern / Engine:** Block Editor → IR → Stage (มาสคอต · ใช้ stage ของ Block Lab R7)
- **Mechanics:** Block Budget, Step Execution
- **Interaction:** ดูท่าเต้นตัวอย่าง 16 จังหวะ → สร้างโปรแกรมให้มาสคอตเต้นเหมือน โดยใช้บล็อกไม่เกิน 6
- **ต่างจาก G1:** ไม่มีแผนที่/เส้นทาง โจทย์คือ "บีบลำดับ" ล้วน ๆ (pattern recognition)
- **ความยาก:** ★ → ★★★ · ข้อจำกัด: มาสคอตมี 10 ท่า (DEC-30) → ท่าเต้นมาจาก 10 ท่า + การเคลื่อนตำแหน่ง
- **เล่นซ้ำเพราะ:** ดนตรี · โหมดแต่งท่าเต้นเองให้เพื่อนเลียนแบบ

### G7 ล่าบั๊ก (Block Coding)
- **Objective:** debugging: อ่านโปรแกรม เทียบผลจริงกับที่ตั้งใจ
- **Pattern / Engine:** Debug Mode บน world ใดก็ได้ (Grid, Circuit, Arm) · ด่านมาพร้อมโปรแกรมที่มีบั๊ก
- **Mechanics:** Fault Inject, Step Execution, **Edit Budget** (แก้ได้ไม่เกิน N จุด)
- **Interaction:** ดูหุ่นทำผิด → กดทีละก้าว → เจอบล็อกที่ผิด → แก้ ≤ 2 จุด
- **ความยาก:** ★★ → ★★★
- **เล่นซ้ำเพราะ:** "แก้น้อยที่สุด" · บั๊กชนิดใหม่ (ลำดับ, จำนวนรอบ, เงื่อนไขกลับ)

### G8 ไฟดับทั้งเมือง (Circuit Lab)
- **Objective:** วงจรครบรอบ · สวิตช์ · ต่ออนุกรม/ขนาน
- **Pattern / Engine:** Circuit World (โหมดปริศนา: ชิ้นจำกัด, จุดต่อล็อกไว้บางส่วน)
- **Mechanics:** Drag & Connect, budget สาย
- **Interaction:** ลากสายจากแบตไปบ้าน 3 หลัง · บ้านสว่างเมื่อครบวงจร · สวิตช์คุมเฉพาะบ้านที่ต้องการ
- **ความยาก:** ★ (1 บ้าน) → ★★ (ขนาน, สวิตช์หลายตัว)
- **เล่นซ้ำเพราะ:** สายน้อยสุด · เมืองโตขึ้นเรื่อย ๆ (สะสม)

### G9 ช่างซ่อมวงจร (Circuit Lab)
- **Objective:** วินิจฉัย: LED กลับขั้ว, ไม่มีตัวต้านทาน, สายหลวม, sensor ผิดพอร์ต
- **Pattern / Engine:** Circuit World + Fault Inject (ใช้ความเสียหายสมจริงของ block-lab R5)
- **Mechanics:** Fault Inject, Debug Mode (มิเตอร์วัดไฟ)
- **Interaction:** งานซ่อมเข้ามาทีละใบ · ใช้มิเตอร์จิ้มจุดต่าง ๆ ดูไฟ → แก้จุดเสีย
- **ต่างจาก G8:** G8 สร้าง · G9 หาข้อผิดในของที่มีอยู่
- **ความยาก:** ★★ → ★★★
- **เล่นซ้ำเพราะ:** ร้านซ่อมเลื่อนระดับ · จับเวลา · ใช้มิเตอร์น้อยครั้ง

### G10 โรงงานคัดของ (Flowchart & Logic)
- **Objective:** decision logic · AND/OR (ป.4) · สายการผลิต (ป.6)
- **Pattern / Engine:** Flowchart Editor → IR → Factory World (สายพานไหลต่อเนื่อง)
- **Mechanics:** Drag & Connect (กล่องตัดสินใจ), Sorting, Step Execution
- **Interaction:** ลากกล่อง "สีแดง?" "ใหญ่?" ต่อเส้นไปประตูคัด · เปิดสายพาน ของไหลผ่าน flowchart แบบเห็นเส้นทาง
- **ความยาก:** ★ (1 เงื่อนไข) → ★★★ (เงื่อนไขซ้อน, ของปนเปื้อน, cycle time)
- **เล่นซ้ำเพราะ:** ความเร็วสายพานเพิ่ม · ของชนิดใหม่ · คะแนนของเสียน้อยสุด

### G11 คุมไฟจราจร (Flowchart & Logic)
- **Objective:** state machine: สถานะ + เงื่อนไขเปลี่ยน + timer + sensor (ต่อจาก ป.3 "ไฟจราจร")
- **Pattern / Engine:** Flowchart Editor (โหมด state) → IR → Factory World (โหมดสี่แยก)
- **Mechanics:** Drag & Connect, Step Execution
- **Interaction:** สร้างวง เขียว → เหลือง → แดง กำหนดเวลา · เพิ่ม "ถ้ามีรถรอฝั่งซอย" · รถจำลองติดถ้าตั้งผิด
- **ต่างจาก G10:** G10 ตัดสินใจต่อชิ้น · G11 เปลี่ยนสถานะตามเวลาและเหตุการณ์
- **ความยาก:** ★★ → ★★★
- **เล่นซ้ำเพราะ:** ช่วงเร่งด่วนแบบสุ่ม · รถติดน้อยสุด

### G12 หุ่นในฝัน (Creative Workshop)
- **Objective:** ความคิดสร้างสรรค์ · (ทางเลือก) ระบุส่วน Sensor/Motor
- **Pattern / Engine:** Shape Editor
- **Mechanics:** Free-form Drawing
- **Interaction:** ผืนผ้าใบว่าง สร้างหุ่นจากรูปทรงใดก็ได้ ตั้งชื่อ บอกว่าช่วยอะไร (เหมือนใบงาน S4 "My Dream Robot")
- **ความยาก:** ไม่มีระดับ (เครื่องมือเปิดทีละชั้น)
- **เล่นซ้ำเพราะ:** ผลงานใช้เป็นสกินหุ่นใน G1/G2/G3 · คอลเลกชันหุ่นของตัวเอง

### G13 ประกอบหุ่นทำภารกิจ (Creative Workshop · Integration)
- **Objective:** หุ่น = Circuit + Program + Mechanic ทำงานร่วมกัน
- **Pattern / Engine:** Robot Model + Circuit World + Block Editor + Grid/Arm World
- **Mechanics:** C+P+M Integration, Fault Trace, Pick & Place
- **Interaction:** ภารกิจ "ย้ายกล่องไปจุด B" → เลือกล้อ/แขน/มือคีบ → ต่อมอเตอร์/servo → เขียนโปรแกรม → ทดสอบ → Fault Trace บอกว่าพังที่ระบบไหน
- **ความยาก:** ★★ → ★★★ (ป.1 ใช้แบบสายโซ่ 3 ช่องในบทเรียนเท่านั้น)
- **เล่นซ้ำเพราะ:** หลายทางแก้ (ล้อเร็ว vs แขนยาว) · ภารกิจใหม่ · เทียบชิ้นส่วนน้อยสุด/เวลาน้อยสุด

### G14 เครื่องกลลูกโซ่ (Creative Workshop · Phase 3)
- **Objective:** การส่งกำลัง: เฟือง (ทิศ/ความเร็ว), คาน, ล้อ
- **Pattern / Engine:** **ต้องเพิ่ม Mechanism sub-engine** (physics 2D ของเฟือง/คาน) → เหตุผลด้านการเรียนรู้: ส่วน Mechanic ของ C+P+M ไม่มีที่ให้ทดลองกลไกอย่างเดียว · ถ้าไม่ผ่านการตัดสินใจ ให้ตัดเกมนี้ ไม่กระทบเกมอื่น
- **Interaction:** วางเฟืองให้มอเตอร์หมุนธงที่ปลายทาง ทิศและความเร็วตามโจทย์
- **ความยาก:** ★★ → ★★★
- **เล่นซ้ำเพราะ:** ทางแก้หลายแบบ · โหมดอิสระสร้างเครื่องยาวที่สุด
