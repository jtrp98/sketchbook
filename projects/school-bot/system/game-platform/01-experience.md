## สองเมนู หนึ่งระบบ

```
                 ┌──────────────── หน้าหลัก ────────────────┐
                 │  เรียนต่อ (บทเรียน)   ·   เกมแนะนำวันนี้     │
                 └──────┬───────────────────────────┬───────┘
                        │                           │
          ┌─────────────▼──────────┐   ┌────────────▼─────────────┐
          │ A. บทเรียน (Lessons)    │   │ B. เกม (Game Library)      │
          │ Level → เทอม → แผนที่    │   │ หมวด → การ์ดเกม → ระดับ    │
          │ → ด่าน (ลำดับ, ล็อก,    │   │ → เล่น (ไม่ล็อก, ไม่เรียง,  │
          │   ดาว, ส่งผลให้ครู)      │   │   ไม่ส่งคะแนน)              │
          └─────────────┬──────────┘   └────────────┬─────────────┘
                        │   Game Definition (config) │
                        └────────────┬───────────────┘
                                     ▼
                   Engine ชุดเดียวกัน (02-engines.md)
```

| | A. บทเรียน | B. เกม |
|---|---|---|
| ใครกำหนดลำดับ | หลักสูตร (curriculum-source S1) | เด็กเลือกเอง |
| การล็อก | ตาม level/access (quiz R7) และลำดับด่าน | **ไม่ล็อกด้วยบทเรียน** (หลักข้อ 2) · ระดับยากแสดงเป็นคำแนะนำ ไม่ใช่ประตู |
| หน่วยของเนื้อหา | ด่าน = ลำดับ item (แบบฝึก + เกมสั้น) | เกม = 1 engine setup + ชุดระดับ + ตัวสร้างด่านใหม่ |
| ผล | ดาว 0–3 จากแบบฝึกเท่านั้น (ด่านเกมไม่ให้ดาว · ผู้ใช้ 2026-11-06) → ครู (phase 2 ส่ง SchoolBright ตาม quiz R5/R16) | สถิติที่ดีที่สุด / เป้าเสริม / ผลงานในแกลเลอรี · ไม่ส่งครู (เสนอ) |
| เป้าทางใจ | "ทำภารกิจของวันนี้ให้จบ" | "อยากลองอีกรอบ ทำให้ดีกว่าเดิม / สร้างของตัวเอง" |
| ความยาว | 1 คาบ หรือ 1 Unit (OQ18) | 2–10 นาทีต่อรอบ เล่นซ้ำได้ไม่สิ้นสุด |

## ความสัมพันธ์ระหว่าง 2 เมนู (ไม่ใช่สำเนากัน)

1. **บทเรียน → เกม (ปลดล็อกของเล่น ไม่ใช่ปลดล็อกการเข้า):** จบด่านที่ใช้ engine ใด → การ์ดเกมที่ใช้ engine นั้นติดป้าย "ลองเล่นต่อ" และได้ **ชิ้นส่วน/ธีม/บล็อกพิเศษ** ในเกม (เช่น จบ "มุม 0/90/180" ได้สกินแขนใหม่ในเกมคีบ) · เกมเล่นได้ตั้งแต่แรกเสมอ
2. **เกม → บทเรียน:** การ์ดเกมบอก "ฝึกทักษะ" ด้วยไอคอน 1–2 ตัว (ไม่ใช่รหัสคาบ) · ไม่บังคับย้อนกลับไปเรียน
3. **ความต่างของคลังเกมกับบทเรียน (หลักข้อ 3):** เกมในคลังมีอย่างน้อย 1 ใน 4 อย่างที่บทเรียนไม่มี — ด่านสุ่ม/ไม่สิ้นสุด · โหมดสร้างด่านเอง · โหมดแข่งกับสถิติตัวเอง · โหมดสร้างผลงานอิสระ · เกมที่ไม่มีอย่างใดเลย = บทเรียนเปลี่ยนชื่อ ไม่รับเข้าคลัง

## หมวดของคลังเกม (ตามประเภทการเล่น)

| หมวด | หัวใจของการเล่น | engine หลัก |
|---|---|---|
| Robot Adventure | บังคับ/นำทางหุ่นในโลก | Grid World, Arm World |
| AI Playground | สอน/ทดสอบ/แก้ข้อมูลของ AI | AI Training |
| Block Coding | วางแผนและบีบโปรแกรม แก้บั๊ก | Program Runtime + World ใดก็ได้ |
| Circuit Lab | ต่อ/ซ่อมวงจร | Circuit |
| Flowchart & Logic | ตัดสินใจและสถานะ | Flowchart Editor + Factory/Traffic World |
| Creative Workshop | สร้างของตัวเอง | Shape Editor, Robot Integration |

หมวดเป็น "ป้ายกรอง" ไม่ใช่โฟลเดอร์ · 1 เกมอยู่ได้หลายหมวด (เช่น Sensor Rover = Robot Adventure + Block Coding)
