## สรุปสั้นของชุด (ไว้ให้ session หลักใช้เร็ว)
- **ชั้น A กิจกรรมในด่าน 16 แบบ** (เลือกตอบ 4 ช้อยส์ เฉลยจบ · ที่เหลือตอบได้รวม 3 ครั้ง + ใบ้ 3 ขั้น) · **ชั้น B เกมจำลอง GP-01–14** (รันใหม่ไม่จำกัด + ใบ้ 3 ขั้น)
- บทเรียน: แบบฝึกล้วน / เกมล้วน / ผสม 3 ข้อ · ดาวจากข้อแบบฝึก · ป.1 ~44 ด่าน
- เกม: ไม่มีดาว ไม่ตอบคำถาม · ความยากระดับเดียว · ด่านวันนี้ · สถิติตัวเอง
- ค่าภาพทั้งหมดมาจาก DS · ส่วนที่ขาด = DS gap
