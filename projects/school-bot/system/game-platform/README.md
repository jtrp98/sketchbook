## 1. Executive Summary

**ทิศทาง:** แพลตฟอร์มเดียว 2 ประสบการณ์ (บทเรียน + คลังเกม) ที่ใช้ **engine ชุดเดียวกัน** ต่างกันที่ config · บทเรียนคือ "เส้นทางที่ครูกำหนด" ผ่าน engine ส่วนคลังเกมคือ "สนามเด็กเล่น" ของ engine เดียวกันที่ปลดเงื่อนไข ลำดับ และการให้คะแนนออก

**การตัดสินใจทางสถาปัตยกรรมที่สำคัญที่สุด 5 ข้อ:**

1. **แยก Editor · Runtime · World ออกจากกัน** (02-engines.md) · Block, Flowchart, Joystick เป็นแค่ "วิธีป้อนคำสั่ง" ทั้งหมดแปลงเป็น **Program IR** ตัวเดียว แล้วรันบน World (Grid, Circuit, Arm, Factory) ตัวไหนก็ได้ → เพิ่ม World ใหม่ 1 ตัว ได้เกมเพิ่มกับทุก Editor ทันที · นี่คือคำตอบของ "เพิ่มเกมใหม่โดยไม่สร้างระบบใหม่"
2. **ลดรายการ engine ของ prompt จาก 9 เหลือ 7 + 2 โหมดกลาง** · Debugging ไม่ใช่ engine แต่เป็นโหมดที่ทุก World ต้องรองรับ (step, trace, ใส่บั๊ก) · Sensor & Signal เป็นส่วนของ Circuit/World ไม่แยก engine · และ**เพิ่ม Item Engine** (แบบฝึก 4 กลุ่มของ quiz R3 ที่มีอยู่แล้ว) ซึ่ง prompt ไม่ได้นับ แต่บทเรียนทุกด่านต้องใช้
3. **Circuit + Program + Mechanic ผูกกันด้วย "สัญญาณ"** ไม่ใช่ 3 หน้าจอ · Robot Model กลางเก็บว่ามีพลังงานไปถึงพอร์ตไหน โปรแกรมสั่งพอร์ตไหน กลไกแปลงการหมุนเป็นการเคลื่อนที่อย่างไร · ผิดที่ชั้นไหนเห็นผลที่ชั้นนั้นและไล่ย้อนกลับได้ (Fault Trace)
4. **ใช้ของที่กำลังทำอยู่ซ้ำ:** ตัวจำลองวงจรแบบ Tinkercad และ editor บล็อกของ Block Lab (R4–R6, R16–R18) คือ Circuit Engine + Block Editor ของแพลตฟอร์ม · แผนที่/ดาว/สถานะด่านของ quiz (R4, R7, R13) คือ Lesson Shell · ไม่สร้างซ้ำ
5. **ความยากมาจาก config ไม่ใช่ UI ใหม่** (สอดคล้อง DEC-06/CON-06 UI เดียว ป.1–6) · ระดับ Beginner→Expert คือชุดค่า (block ที่เปิด, budget, จำนวนแกนจอยสติ๊ก, ความไว, fault ที่ใส่) บน engine เดิม

**สิ่งที่เสนอให้ต่างจาก prompt (พร้อมเหตุผล):**

| prompt | ข้อเสนอ | เหตุผล |
|---|---|---|
| Block budget เป็นเงื่อนไขแพ้ | budget เป็น **เป้าดาว** ไม่ใช่เงื่อนไขผ่าน (ยกเว้นระดับ Challenge) | productive failure: เด็กควรไปถึงเป้าก่อน แล้วค่อยถูกชวนให้ "ทำให้สั้นลง" · ตรงกับข้อ "ไม่ใช้คะแนนเป็นตัววัดอย่างเดียว ให้เข้าใจการปรับปรุง algorithm" |
| Shape editor ครบ 9 รูปทรง + layer + rotate ตั้งแต่แรก | เปิดเครื่องมือทีละชั้น (ป.1 เห็น 5 รูปทรง สี ย้าย ลบ ย้อน) | หลักข้อ 7 ห้ามซับซ้อนเกินวัย · ไม่จำกัดรูปร่างผลงาน แค่จำกัดจำนวนปุ่มที่เห็นพร้อมกัน |
| Joystick 2 แกน คุมแขนทั้งแขน | 1 ก้าน 2 แกน + **ปุ่มสลับคู่ข้อต่อ** (ฐาน+ไหล่ / ศอก+ข้อมือ) · Basic เปิดแกนเดียว | แขนจริงมี 5 ข้อต่อ + มือคีบ (arm-lab R13) ก้านเดียวคุมพร้อมกันไม่ได้ · แยกฝึกแกนเดียวก่อนตามที่ prompt กำหนด |
| AI Training ฝึกจากภาพ | ป.1–2 ใช้**ชุดภาพที่เตรียมไว้**ก่อน · กล้องเป็นทางเลือกที่ต้องตัดสิน | ข้อมูลผู้เยาว์ (NFR-05, RSK-05) · ห้องเรียนไม่ได้มีกล้องทุกเครื่อง |
| Free-form ไม่มีโครงหัว/ตัว/แขน/ขา | คงตามนั้น + เพิ่ม **ป้ายหน้าที่ (Sensor / Controller / Motor)** ที่เด็กแปะบนรูปทรงใดก็ได้ | ตรงกับใบงาน "My Dream Robot" (S4: วงกลมส่วน Sensor สี่เหลี่ยมส่วน Motor) และแนวคิดรวบยอด ป.1 U1 · ไม่จำกัดรูปร่าง แต่เชื่อมความคิดสร้างสรรค์กับแนวคิดหุ่นยนต์ (ยังแยกจาก Functional Engineering: ป้ายไม่มีผลต่อการทำงาน) |
