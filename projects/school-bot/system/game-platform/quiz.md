# เมนูบทเรียน (quiz): ใช้ pattern ออกแบบตามกฎ quiz

อ่านคู่กับ `pattern.md` (มี pattern อะไร) · `pattern-rule.md` §1 (ทั้งสองเมนู) + §3 (PR-Q) · requirement ที่เป็นของจริง = `modules/quiz/requirements.md` (ไม่คัดลอก R# ซ้ำ) · **เนื้อหาอิง `modules/quiz/curriculum-source.md` เท่านั้น** (CLAUDE.md 2026-11-05)

ไฟล์นี้ใช้เป็นข้อมูลให้ `crayon` และคนเขียนเนื้อหาด่าน · canvas ของ quiz = C1 (D1–D4 เดิมต้องแก้ตาม CHANGELOG 2026-11-06 และกฎใหม่ถ้ายืนยัน)

ป้ายหลักฐานในตารางหลักสูตร: **[ต้นฉบับ]** ชื่อหัวข้อจาก `curriculum-source.md` · **[อนุมาน]** pattern ที่ผมจับคู่เอง ยังไม่เทียบใบงาน/แผนรายคาบ (เหลือแผนที่อ่านได้เฉพาะ ป.1 U1) · **[รอข้อมูล]** แหล่งไม่มี

## 2. ชนิดด่าน 3 แบบ ← หยิบ pattern อย่างไร

| ชนิด | ประกอบด้วย | จำนวน | ผ่านเมื่อ | ดาว |
|---|---|---|---|---|
| **แบบฝึกล้วน** | กิจกรรมในด่าน (ผสมได้หลายชนิด) | 5–8 ข้อ | ≥1 ดาว (≥60%) | 0–3 |
| **เกมล้วน** | GP 1 ตัว (หรือ item เกมหลายตัว) | ≥1 item | ถึงเป้าหลักทุก item | ไม่มี |
| **ผสม** | item GP + ข้อแบบฝึก **3 ข้อพอดี** | – | ถึงเป้าหลักทุก item **และ** ≥1 ดาว | 0–3 (จาก 3 ข้อ) |

**สูตรเรียงภารกิจในด่าน (PR-Q6):** ภารกิจแรกง่าย → กลางเป็นกลไกหลักของบท → ท้ายต้องให้เหตุผล/ใช้กับข้อมูลใหม่ · กลไกหลักไม่ซ้ำกับด่านติดกัน · `02-pick-1of2` ≤1 ต่อบท · `05-find` ไม่ติดกันสองบท

**กติกาข้อแบบฝึก:** เลือกตอบ 4 ช้อยส์ (`01-choose-4`) เฉลยจบ ไม่ทำข้อซ้ำ · กิจกรรมอื่น ตอบได้รวม 3 ครั้ง + ใบ้ 3 ขั้น (PR-A1 · ผิดครั้งที่ 3 → ใบ้ขั้น 3 แล้วไปต่อ) · ดาวนับครั้งที่ถูก · **กติกา item เกม:** ไปต่อเมื่อถึงเป้าหลัก ไม่มีข้าม รันใหม่ไม่จำกัด + ใบ้ 3 ขั้น (PR-A2/Q9)
