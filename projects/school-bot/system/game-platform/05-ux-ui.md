# 8. UX/UI Architecture

กรอบ: หน้าต่าง 1440×900 (แถบหน้าต่าง 60 + พื้นที่ 840 · context.md) · UI เดียว ป.1–6 (DEC-06) · WCAG 2.2 AA + เกณฑ์เด็ก · ไอคอนคู่ข้อความ

## 8.1 Shared UI Components (ทุกเกม/ด่านใช้ชุดเดียว = Consistent Interaction Language)

| component | ตำแหน่ง | หน้าที่ |
|---|---|---|
| Game HUD | แถบบนพื้นที่เกม | ออก · ชื่อเป้า (ภาพ + ≤ 6 คำ) · ตัวนับ (budget / เวลา / ชิ้น) · เป้าเสริม (ไม่ใช่ดาว · quiz R4) |
| Run Controls | ตำแหน่งเดียวกันทุก world ที่มี IR | ▶ รัน · ⏭ ทีละก้าว · ↺ เริ่มใหม่ · ⏹ หยุด (สั่งหุ่นจริงต้องเป็นปุ่มหยุดตาม NFR-04) |
| Hint (มาสคอต) | มุมล่าง | ใบ้ 3 ชั้น: ชี้ตำแหน่ง → บอกแนวคิด → ทำให้ดู 1 ก้าว · ท่ามาสคอตจาก 10 ท่าเท่านั้น (DEC-30) |
| Feedback Layer | ซ้อนบน world | ไฮไลต์จุดผิด + ข้อความสาเหตุสั้น · ผิดไม่ลงโทษ ไม่ล้างงาน |
| Result Card | modal จบรอบ | ดาว/สถิติ · "ทำให้ดีขึ้น" (ชี้สิ่งที่ปรับได้) · เล่นอีก / ต่อ |
| Game Card | คลังเกม | ภาพเกม · ชื่อ · ไอคอนทักษะ 1–2 · ระดับแนะนำ · สถิติดีสุดของฉัน |

## 8.2 Layout ตามประเภทเกม (ไม่ใช้ master layout เดียว)

| Layout | ใช้กับ | โครง |
|---|---|---|
| L1 World + Program | G1, G3, G6, G7 · ด่าน grid | world ซ้าย (ใหญ่) · ชุดบล็อก + แถบโปรแกรมขวา · Run Controls ใต้ world · เห็นผลกับโปรแกรมพร้อมกัน |
| L2 Live Control | G2 | world กลางเต็มกว้าง · จอยสติ๊กล่างซ้าย · มือคีบ + สลับคู่ล่างขวา · มุมมองบนเล็กมุมขวาบน · ไม่มีแถบโปรแกรม (โหมด Playback ป.5 เพิ่มแถบท่าด้านล่าง) |
| L3 Workbench | G8, G9, G12, G14 · Circuit | แถบเครื่องมือซ้าย · ผืนงานกลาง · แผงคุณสมบัติขวา (ซ่อนได้) · ตรงกับ Block Lab ตัวจำลอง → ใช้ของ Block Lab |
| L4 Data Board | G4, G5 | กองตัวอย่างซ้าย · ถังป้ายกลาง · แผงทดสอบ (สายพาน + ความมั่นใจ) ขวา |
| L5 Flow + World | G10, G11 | flowchart ซ้าย · world (สายพาน/สี่แยก) ขวา · จุดไฟวิ่งบน flowchart ตามชิ้นที่กำลังตัดสิน |
| L6 Integration | G13 | world บน (เห็นหุ่นตลอด) · แท็บ วงจร / โปรแกรม / กลไก ล่าง · แถบ Fault Trace เชื่อมผลกับแท็บที่ผิด |
| L7 Item | แบบฝึกบทเรียน | ตามหน้าเล่นของ quiz (D3) |

## 8.3 โครงหน้าจอ

**A. Main Menu:** sidebar 5 เมนู (หน้าหลัก · บทเรียน · เกม · Block Lab · Arm Lab · ผู้ใช้เลือก 2026-11-06 Q1 · ต้องแก้ app-shell R7) · หน้าหลักมี "เรียนต่อ" + "เกมแนะนำ" (เกมที่ใช้ engine เดียวกับด่านล่าสุด)

**B. Lesson:** เลือก Level (quiz D1) → แผนที่ 2 เทอม (D2) → แผงด่าน: เป้าหมาย (ภาพ) · ประเภทเกมในด่าน (ไอคอน engine) · ดาว → เล่น (L1–L7 ตาม item) → ผล (D4)

**C. Game Library:** แถบหมวด (ชิปภาพ + คำ) · ตารางการ์ด (ใหญ่ 3 คอลัมน์) · กรองด้วย "เหมาะกับฉัน" (ตามชั้น · ไม่ซ่อนเกมอื่น) → หน้าเกม: เลือกระดับ 3–4 ปุ่มภาพ + ปุ่มโหมด (เล่น / ด่านสุ่ม / สร้างด่าน / อิสระ) → เล่น

**D. Creative:** Shape Editor (L3) · Circuit (L3 = Block Lab) · Block (L1 / Block Lab)

**E. Simulation:** Grid (L1) · Circuit Sim (L3) · Sensor Sim (ใน L3/L1: คลิกค้าง sensor เพื่อเปลี่ยนค่า ตาม block-lab R6) · Arm Joystick (L2)

## 8.4 หลักการต่อวัย (ตรวจทุกหน้า)

| หลัก | ใช้อย่างไร |
|---|---|
| Visual First / Minimal Reading | เป้าหมายเป็นภาพ + ≤ 6 คำ · ไม่มีย่อหน้าในเกม |
| Large Targets | บล็อก, ก้านจอย, ปุ่มมือคีบ ขนาดตาม token เป้าสัมผัสของ DS |
| Immediate Feedback | ทุกการวางบล็อก/สาย/การโยก ตอบภาพ + เสียงทันที |
| Productive Failure | ผิดแล้วเห็นสาเหตุ แก้ต่อจากเดิม ไม่เริ่มใหม่ทั้งหมด |
| Progressive Disclosure | เครื่องมือ/บล็อกเปิดตาม config ของระดับ |
| Consistent Language | Run Controls, Hint, Result เหมือนกันทุก world |
