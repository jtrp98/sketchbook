# กฎของ pattern (ใช้ทั้ง 2 เมนู / เกม / บทเรียน)

รายการ pattern อยู่ที่ `pattern.md` · ใช้ในเมนูเกม `game.md` · ใช้ในเมนูบทเรียน `quiz.md`

**วิธีอ่าน:** ทุกกฎมี ID `PR-A#` (ทั้งสองเมนู) · `PR-G#` (เมนูเกมเท่านั้น) · `PR-Q#` (เมนูบทเรียนเท่านั้น) · คอลัมน์ "ที่มา" บอกว่าใครสั่ง/R# ใด/แหล่งใด เพื่อตรวจย้อนได้

**ป้าย:** **[ยืนยัน วว]** ผู้ใช้ตัดสินในแชตวันนั้น · **[R# เดิม]** ยืนยันแล้วใน requirement (ไม่คัดลอกซ้ำ ใส่แค่สรุป+อ้างอิง) · **[ต้นฉบับ]** มาจากเอกสารแหล่ง · **[เสนอ]** ผมเสนอ รอยืนยัน

**ลำดับความถูกต้องเมื่อขัดกัน:** ผู้ใช้ตัดสินล่าสุด → ไฟล์นี้ → requirement เดิม (ใน `modules/`) → `01–07` → ไฟล์แหล่งอ้างอิง (FM1, FM2) · **GP-doc** = เอกสาร 8 pattern ที่ผู้ใช้วางในแชต 2026-11-09 ย่อยลงไฟล์ชุดนี้แล้ว (`pattern.md` §3.1–3.2, ไฟล์นี้ §1.8 และ §5) ไม่มีไฟล์ต้นฉบับ · "GP-doc §n" = หัวข้อที่ n ของเอกสารนั้น · ข้อที่ไฟล์นี้ขัดกับ requirement เดิมอยู่ในตาราง "§4 ความสัมพันธ์กับ requirement เดิม" · **ยังไม่มีการแก้ requirement ใด** กฎเปลี่ยน requirement ใน CLAUDE.md ต้องทำเมื่อผู้ใช้สั่ง
