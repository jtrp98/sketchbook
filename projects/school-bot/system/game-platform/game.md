## 2. วิธีหยิบ pattern มาทำเป็นเกม (ขั้นตอนออกแบบ 1 เกม)

1. เลือก **GP หลัก** (1 ตัว) จาก `pattern.md` §3 → ได้ world/engine และ layout (L1–L7)
2. กำหนด **ทักษะ** 1–2 ตัว + **หมวด** (PR-G8) + **ช่วงชั้นแนะนำ** 2 ชั้น (ตามเกมที่ทีมส่ง ไม่ใช่ตัวเลือกในเกม)
3. ตรวจ **เงื่อนไขรับเข้าคลัง** (PR-G10): แกนเล่นไม่ซ้ำเกมอื่นในหมวด + มี ≥1 ของ ด่านสุ่ม / สถิติตัวเอง / สร้างผลงาน
4. เขียน **config** (06): engine, ชุดบล็อกที่เปิด, เป้าหลัก (predicate), เป้าเสริม, ใบ้ 3 ขั้น, ธีม (`theme_pack` จาก DS) · ไม่มี Hex · ข้อความเป็น key
5. ทำ **ด่านแรก = ด่านสอนวิธีเล่น** แล้วเรียงด่านง่าย→ยาก 10–20 ด่าน
6. กำหนด **generator** ของด่านวันนี้ (ถ้าสร้างสุ่มได้ · ไม่ได้ → OQ1 ของ game-library)
7. ตรวจ **DS gap** (PR-A21) ก่อนส่ง `crayon`

## 5. ตัวอย่างการออกแบบ 1 เกมจาก pattern (ตัวอย่างวิธี ไม่ใช่ข้อกำหนดเนื้อหา)

**G1 ทางลัดหุ่นจิ๋ว ← GP-01**
- **world:** Grid World · **editor:** Block Editor (ป.1–2 ชุดบล็อกลูกศร ไม่มีตัวเลข)
- **ด่านแรก (สอนวิธีเล่น):** ตาราง ≤4×4 ไม่มีสิ่งกีดขวาง · บล็อกเดิน/เลี้ยว 3 ตัว
- **ด่านถัดไป:** เพิ่มสิ่งกีดขวาง → ไอเทม → เปิด `repeat` (ทีละอย่าง · progressive disclosure PR-A10)
- **เป้าหลัก:** `reach_cell` · **เป้าเสริม:** `collected_all(battery)` · `block_count_lte(n)` (PR-A11)
- **ผิด:** หุ่นหยุดที่คำสั่งที่ชน บล็อกนั้นสั่น เส้นที่เดินจริงซ้อนเส้นประที่ตั้งใจ (PR-A6)
- **ด่านวันนี้:** generator สร้างแผนที่จาก seed วันที่ (เวลาไทย)
- **ทำไมเล่นซ้ำ:** เป้าเสริม "บล็อกน้อยสุด" · ด่านวันนี้ (PR-G5)

(ค่าทั้งหมดใน config ใช้ key และ `theme_pack` จาก DS ไม่มี Hex)
