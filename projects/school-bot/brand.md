### กฎเฉพาะ

- **stop vs danger (D-01):** ปุ่มใหญ่ **สี่เหลี่ยมมุมมน** (ผู้ใช้อนุมัติ 2026-10-26 Q2 · เดิมวงกลม · DSG-18 รอเจ้าของ design system แก้ D-01) + ไอคอน `stop` (SVG) + ตำแหน่งตายตัวทุกหน้า = ของปุ่มหยุดทั้งหมดเท่านั้น
- **ตัวอักษรบนส้ม:** บน `action-robot` และ `mode-block` ใช้ `text-primary` เสมอ (ขาวบนส้มคอนทราสต์ไม่ผ่าน)
- **warning (D-02):** แถบหรือกล่องที่มีไอคอน `warning` (SVG) + ข้อความ ไม่ใช่ปุ่มนูน · ตัวอักษรใช้ `text-primary`
- **off (D-03):** พื้น `off-bg` แทบเท่ากับ `background` จึงต้องมีขอบ `border` ทุกครั้ง · ปุ่มที่ใช้ไม่ได้ใช้ `aria-disabled` + popup อธิบาย ไม่ใช่ disabled เงียบ
- **สีประจำแอป (D-04):** ห้ามใช้บนปุ่ม สถานะ หรือ Attention Ring

### เนื้อหาหลัก vs ข้อมูลรอง (D-12)
**≥16px:** ทุกอย่างที่กด/พิมพ์/เลือกได้ (ปุ่ม, ช่องกรอก, dropdown, แท็บ, รายการเมนู, chip ที่กดได้) · ข้อความสั่งงาน คำแนะนำทีละขั้น error และคำเตือน · ชื่อที่เป็นเนื้อหาหลักของการ์ด (ชื่อท่า ชื่อหุ่น ชื่องาน) · ค่าที่ต้องอ่านเพื่อทำงาน (มุมข้อต่อ เวลาเข้าท่า จำนวนรอบ)
**12–14px ได้:** คำใบ้คีย์ลัด · metadata (วันที่ เวลาแก้ล่าสุด พอร์ต COM) · ป้ายสเกล min/max ของ slider · ตัวเลขใน badge · คำบรรยายใต้ภาพ
**ตัดสินเมื่อไม่แน่ใจ:** ซ่อนข้อความนั้นแล้วเด็กยังทำงานต่อได้ = รอง · ทำต่อไม่ได้ = หลัก

### Focus ring (D-17)
- **แก้ 2026-10-28 (ผู้ใช้สั่ง · แทน #B85E00 ทั้งหมด):** `outline: 3px solid #1866C9; outline-offset: 2px` ทุก control ที่โฟกัสได้ ผ่าน `:focus-visible` (ปุ่ม, tab, ชิป, ชื่องาน, ช่องพิมพ์, การ์ด ฯลฯ) · ช่องพิมพ์ใช้แบบ §11.17 (ขอบ 2px #1866C9 + เงา #D0EBFD)
- คอนทราสต์ #1866C9 ≈ 5.6:1 บนขาว (เกณฑ์ WCAG 1.4.11 = 3:1) · บนปุ่มพื้น action-primary ต้องคง offset 2 ให้มีช่องพื้นหลังคั่นระหว่างวงกับปุ่ม (ไม่งั้นวงกลืนกับปุ่ม)
- ~~#B85E00 (4.53 บนขาว)~~ เลิกใช้เป็น focus 2026-10-28
- **แก้ 2026-10-28 (ผู้ใช้): โฟกัสแสดงเฉพาะเมื่อมาจากคีย์บอร์ด** · คลิก/แตะด้วยเมาส์ = ไม่มีวงหรือขอบโฟกัสเลย รวมช่องพิมพ์ (ตัวแก้โค้ด, terminal, เปลี่ยนชื่องาน) · ช่องพิมพ์ต้องจำ modality ล่าสุด (keydown vs pointerdown) เพราะเบราว์เซอร์นับคลิกช่องพิมพ์เป็น :focus-visible · คลิกเข้าช่องพิมพ์ = เหลือเคอร์เซอร์เป็นตัวบอก
- วงฟ้าอ่อน #D0EBFD ใช้เป็นเงาตกแต่ง (hover, ช่องกรอกที่กำลังพิมพ์) ได้ แต่ห้ามใช้เป็นตัวบอก focus อย่างเดียว (1.24:1 ไม่ผ่าน)
- focus ring ≠ Attention Ring: focus = ตำแหน่งคีย์บอร์ด เส้นนิ่ง · Attention Ring = ชี้สิ่งที่ต้องทำต่อ กะพริบ สีมีความหมาย (หมวด 5)

## 5. Motion (APPROVED)

### Attention Ring (จาก Skill เดิม — งานจริงตรงแล้ว)
- ระบบกะพริบเดียวทั้งแอป: `dur-ring` 2.4s `ease-ring` วนไม่หยุด · วงนอกโปร่ง .15 → .7 · ต่างกันได้แค่สี
- น้ำเงิน `dc-ring` = กดต่อ ไม่ขยับหุ่น · ส้ม `dc-ring-or` = กดแล้วหุ่นขยับ · แดง `dc-ring-red` = ผิดพลาด/ขีดจำกัด · เขียว `dc-ring-gr` = สำเร็จ ครั้งเดียว `dur-success`
- ปุ่มในแถบที่ตัดขอบใช้วงด้านใน (inset 2→3px)
- ไม่ใช่ focus ring (หมวด 4)

### Duration และ Easing (D-19)
| Token | ค่า | ใช้กับ / ปัดค่าเดิม |
| --- | --- | --- |
| `dur-press` | 0.1s | กดยุบ, hover · .06–.15 → .1 |
| `dur-move` | 0.2s | เข้า/ออก (popover, การ์ด, toast) · .18–.26 → .2 |
| `dur-shake` | 0.45s | สั่นครั้งเดียวเมื่อกดผิด |
| `dur-spin` | 0.8s | spinner ตอนโหลด |
| `dur-success` | 1.2s | วงเขียวสำเร็จ ครั้งเดียว |
| `dur-advance` | 2s | แถบนับก่อนไปต่อเอง |
| `dur-ring` | 2.4s | Attention Ring |
| `ease-out` | cubic-bezier(.2,.8,.2,1) | ของที่เข้ามา |
| `ease-in` | ease-in | ของที่ออกไป |
| `ease-ring` | ease-in-out | Attention Ring เท่านั้น |
| `linear` | linear | spinner และแถบนับเท่านั้น |

### กฎการเคลื่อนไหว (D-19)
1. วนไม่หยุด (infinite) ได้แค่ 2 อย่าง: Attention Ring และ spinner ตอนโหลด
2. เปลี่ยนความทึบ/ขนาด **ครั้งเดียว** ได้ ถ้าไม่เกิน `dur-move` หรือเป็นการสั่น/วงสำเร็จที่กำหนดไว้
3. ทุก animation ต้องมีแบบ `prefers-reduced-motion: reduce` — ไม่มี = ไม่ผ่าน · Attention Ring ตอนลดการเคลื่อนไหว = วงนิ่งความเข้ม .5

### ค้างไว้
- MainV6A `dcBulbOn` (2 จุด) ไม่มีแบบลดการเคลื่อนไหว → เพิ่มเมื่อแตะบอร์ด
- duration 13 ค่าและ easing 5 แบบในงานจริง → ใช้ token เมื่อแตะบอร์ด

### 11.3 ชิป
- ชิปมีกรอบ (สถานะอุปกรณ์/คลาวด์): สูง 32 (พื้นที่กด 44) · padding 0 space-3 12 · radius-pill · border-default 2px · ไอคอน 20 + ข้อความ 16/600 · gap space-2 8 · hover ขอบ action-primary

- **[เพิ่ม 2026-10-28] tab ไอคอนล้วน (โหมด บล็อก | โค้ด ในส่วนหัว):** tab 44×44 ไอคอน 20 · ไม่มีข้อความบนจอ · aria-label + tooltip ใต้ปุ่ม (§11.8) ขึ้นตอน hover/focus-visible · สถานะอื่นตามด้านบน
### 11.7 สถานะ selected
- การ์ด/แถว/รายการที่เลือก: ขอบ border-selected 3px action-primary + พื้น action-primary-subtle (ตัวอย่างต้นแบบ: การ์ดท่าใน Arm Lab) · วงนอก 3px #D0EBFD ตกแต่งได้ (ห้ามเป็นตัวบอกเดียว)
- เลือกหลายรายการ (ท่าชุด): ขอบ 3px group + พื้น group-bg
- ไม่ได้เลือก: ขอบ 2px border (ล่าง 4px ถ้าเป็นการ์ดกดได้ — raise)
- hover รายการเมนู/แถว: พื้น action-primary-subtle
- **รายการนำทางแนวตั้ง (เช่น แถบหมวดบล็อก):** selected = แบบ tab (พื้น surface ขาว + เงาเบา DSG-20 + ตัว/ไอคอนข้อความ action-primary · ไม่มีกรอบสี) · ผู้ใช้ตัดสิน 2026-10-26 · ไอคอนหมวดยังคงสีหมวดเดิม · ไม่ใช้กรอบ 3px ฟ้ากับรายการนำทาง (ใช้กับการ์ด/แถวที่เลือกข้อมูลเท่านั้น)
