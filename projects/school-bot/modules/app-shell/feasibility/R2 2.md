## คุณสมบัติที่ออกแบบแล้ว (FRM-05 r1/r2 · Observed ยังไม่ได้ render บน canvas จริง)
- สูง 44 · board 1440×900 = แถบ 44 + พื้นที่ตัวอย่าง 856 (r2, CR-09) · dialog สูง 780 (เว้นแถบล่าง 76)
- **Windows:** ปุ่มขวา ซ่อน/ย่อ/ปิด 48×44 · hover ใช้ `action-primary-subtle`
- **Mac:** ปุ่มซ้าย ปิด/ย่อ/ซ่อน วงกลม 28 ในพื้นที่กด 40×44 · สี #FF5F57 / #FEBC2E / #28C840 + ไอคอน #14243D เห็นตลอด (DSG-11 Proposed → ผู้ใช้เลือก)
- ไอคอน Lucide inline เส้น 2.4 · ซ่อน = arrow-down-to-line / arrow-up-to-line ตามตำแหน่ง tray / menu bar
- Tweaks: `os` win/mac · `sync` online/syncing/offline/fail · `device` hidden/none/connecting/board/robot/lost · `lang` th/en/zh · `closeCase` auto/robot · `preview`
- props สำหรับ import: robotMoving, onRetry, onStopRobot (preview = false) · ห่อด้วย wrapper สูง 44 z 80 (ปัญหา → R5)
- กดได้: ป้ายสถานะ → popover (Esc/แตะข้างนอกปิด) + ลองอีกครั้ง (fail) · ซ่อน/ย่อ → การแจ้งจำลอง · ปิด → dialog (หุ่นขยับ / ยังไม่ขึ้นคลาวด์)
- ข้อความ 3 ภาษา · zh ใช้ IBM Plex Sans SC (DSG-02) · ข้อมูลตัวอย่าง: เวลา 10:42 / 10:40 · รอ 2 งาน · รหัส E-CLOUD, E-USB
