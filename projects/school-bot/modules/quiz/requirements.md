## เป้าหมาย
นักเรียน ป.1–6 เรียนผ่าน "บทเรียน": เห็นหน้าเลือก **Level 1–6 (= ป.1–6)** → เข้าแผนที่ภารกิจของ level (แผนที่เดียวยาว 2 เทอม) → ทำแบบฝึกทีละด่าน (1 ด่าน = 1 คาบเรียน) ได้ดาว 0–3 · เนื้อหาตามหลักสูตรของแต่ละชั้น (Course Plan) · **phase 1 (MVP นี้) ยังไม่ส่ง/ดึงคะแนนกับ SchoolBright** เก็บความคืบหน้าและดาวที่ cloud ของ School Bot ผูกบัญชีนักเรียน · เมื่อมี requirement เชื่อม SchoolBright (phase 2) คะแนน Quiz เป็นคะแนนเดียวที่ส่งกลับและที่ครูเห็นบนเว็บครู (DEC-18)

## Requirements
ลำดับ: M = Must · ? = ยังไม่ยืนยัน (ดู OQ) · P2 = phase 2 ยังไม่ทำใน MVP

- R1 (M): Quiz Game คือเมนู "บทเรียน" ใน sidebar · เปิดแล้วเห็น **หน้าเลือก Level (R12)** แล้วเข้า**แผนที่ภารกิจแนว Duolingo ของ level (R13)** พร้อมสถานะของแต่ละด่าน: ผ่าน / กำลังเรียน / ล็อก · (FR-06, AC-05, DEC-02, SCR-06)
- R2 (M): เนื้อหาตามหลักสูตร **Course Plan ป.1–6** (Google Sheet ของบริษัท: ป.1 Robot&AI, ป.2 แขนกล Zide, ป.3–4 โค้ด/Arduino/sensor, ป.5 แขนกลขั้นสูง ฯลฯ) · **1 ด่าน = 1 คาบเรียน** ราว 22 ด่านต่อเทอม ต่อ level · บริษัทเป็นผู้สร้างเนื้อหา **ดึงจาก cloud** (มีสถานะโหลดไม่สำเร็จ ST-12) · การจับแถวใน Course Plan เป็นด่านและแบ่งเทอม → OQ18 · ใครเขียนโจทย์ดิจิทัล → OQ23 · "ครูเปิด/ปิดหน่วยรายห้อง" (เดิม FR-27) ยังไม่นิยามใหม่ว่า "หน่วย" คืออะไรในโครง level/เทอม/ด่าน → OQ22 · (FR-07, ENT-07, ENT-08, ARC-I03, DEV-Q12)
- R3 (M): หน้าด่านมีแบบฝึก **4 กลุ่ม**: (ก) เลือกตอบ (ข้อความ + ภาพ) · (ข) เรียงบล็อก · (ค) จับคู่ / ลากป้ายวางตำแหน่ง · (ง) ปรับสไลเดอร์ให้ตรงเงา (จำลองแขนกลบนจอ) · **ไม่มีภารกิจกับหุ่นจริงใน MVP** · **5–8 ข้อต่อด่าน** (แล้วแต่ด่าน) · การกระทำ: ตอบ, ตรวจ, ออก (**ไม่มีปุ่มข้าม** · ผู้ใช้ 2026-11-01) · ตอบแล้วกด "ตรวจ" → เห็นถูก/ผิด + เฉลยสั้น → ไปข้อต่อ · **ตอบผิดไม่ลองซ้ำข้อเดิม ไม่มีคำใบ้ ไม่มีเสียงอ่านโจทย์** (ผู้ใช้ 2026-10-31) · ความคืบหน้าในด่านแสดงเสมอ (แถบ + x/n + มาสคอต R18) · ข้อที่ตอบผิดบนข้อเรียง/จับคู่/สไลเดอร์แสดงคำตอบที่ถูก · คะแนนข้อที่ไม่ใช่เลือกตอบ/เกณฑ์ผ่านสไลเดอร์ → OQ13 (ก), OQ20 · (FR-06, FR-08, ENT-09, SCR-07, ST-13)
- R4 (M): **กติกาดาว 0–3 ต่อด่าน** ตามสัดส่วนข้อถูก ไม่ปัดเศษ (เทียบด้วยจำนวนเต็ม: ถูก×100 ≥ 60×n ไม่ใช้ทศนิยม): **≥60% = 1 ดาว (ผ่านด่าน), ≥80% = 2 ดาว, 100% = 3 ดาว** · ต่ำกว่า 60% = 0 ดาว ไม่ผ่านด่าน (Inferred จากเกณฑ์ผ่านที่ผู้ใช้ให้) · ใช้ได้ทุกจำนวนข้อ 5–8 (เช่น 5 ข้อ: 3/4/5 · 6 ข้อ: 4/5/6 · 8 ข้อ: 5/7/8) · ผลจบด่านแสดงดาวและจำนวนข้อถูก มีปุ่ม "ไปต่อ" และ "เล่นใหม่" (ระดับด่าน ไม่ใช่ระดับข้อ) · **ไม่มีเหรียญ** · "ดาวใหม่ +n" บนหน้าผลแสดงเฉพาะดาวที่เพิ่มขึ้นจากครั้งก่อน (Proposed) · เล่นซ้ำนับคะแนนอย่างไร → OQ12 · (FR-08, ENT-10, SCR-08, ARC-I02 Closed)
- R5 (M ส่วนเก็บ · P2 ส่วน SchoolBright): **phase 1: ไม่ส่งคะแนนเข้า SchoolBright และไม่ดึงข้อมูลของ Quiz (คะแนน) จาก SchoolBright** · ยังยืนยันตัวตนผ่าน SchoolBright ตอน login (`app-shell` R6) และใช้ข้อมูลตอน login (ชื่อ/ห้อง/ชั้น) ได้ (OQ28 answered 2026-11-01) · ผลการเล่นทุกด่าน**เขียนลงเครื่องทันที แล้วส่งขึ้น cloud ของ School Bot ผูกบัญชีนักเรียนเมื่อออนไลน์** (เปลี่ยนเครื่องแล้วเห็นดาวเดิมเมื่อ sync แล้ว) ผลไม่หาย · คิวผลแยกตามบัญชี (เครื่องห้องคอมใช้ร่วมกัน) logout ตอนออฟไลน์ที่ยังมีผลค้างส่งต้องเตือน · ผลการเล่นเป็น **log เพิ่มอย่างเดียว** (มี ID ฝั่ง client ส่งซ้ำได้ ไม่เกิดแถวซ้ำ) ไม่ใช้กติกา "ฉบับใหม่กว่าชนะ" ของ `my-work` · ดึงความคืบหน้าจาก cloud ไม่สำเร็จ (เช่นเปลี่ยนเครื่อง) ห้ามแสดงเหมือนครั้งแรก (R8) · ผู้ใช้เห็นสถานะ sync ที่แถบหน้าต่าง (`app-shell`) · **phase 2 (P2):** เมื่อมี requirement เชื่อม SchoolBright จึงเพิ่มการส่งคะแนน (เดิม R5: คิวส่ง, "ส่งแล้ว/รอส่งคะแนน", ส่งซ้ำ) และตัดสินใจตาม OQ21 · Arm Lab และ Block Lab ไม่ส่งคะแนน · (FR-09, AC-06, EC-05, DEC-04, DEC-18, ENT-11, ST-15, ST-16)
- R6 (M): **ความสำเร็จ = ดาว** (ไม่มีเหรียญใน MVP · OQ4 answered 2026-10-31) · แสดงดาวรวมบนหน้าหลัก (sidebar/ส่วนความสำเร็จ · module `app-shell` · FR-05) บนการ์ด Level (R12) และบนแผนที่ (R13) · ดาวคำนวณจากผลด่าน (ใช้ดาวสูงสุดต่อด่านรวม · OQ12) · (ENT-12 ตัด)
- R7 (M): **สถานะด่าน:** ผ่าน (มีดาว) · กำลังเรียน · **ล็อก** · **ล็อกระดับ level ตาม access (ผู้ใช้ 2026-11-05 · แทน "ทุก level เข้าได้อิสระ"):** access ถึง Level N = เข้าได้ Level 1 ถึง N · level สูงกว่า N เห็นแต่ล็อกพร้อมเหตุผล (แตะแล้วเห็นเหตุผล ไม่เข้าแผนที่) · **ค่าเริ่มต้น N = ชั้นของนักเรียน** (ป.3 → Level 1–3 · ชั้นมาจากข้อมูลโปรไฟล์ SchoolBright ตอน login · R5) · **ครูที่สอนชั้นนั้นเปลี่ยน N ได้ทีละระดับชั้นผ่านเว็บครู** (`teacher-web` · phase 1 · R16 · ค่าล่าสุดชนะ · บันทึกว่าใครเปลี่ยนล่าสุด) · ถ้าลด N แล้วมีนักเรียนเคยเล่น level ที่จะถูกปิด: เว็บครูขึ้นเตือนก่อนยืนยัน · ฝั่งนักเรียนล็อกเมื่อ login ครั้งถัดไป และแจ้ง "ติดต่อครูเพื่อปลดล็อก" · ความคืบหน้า/ดาวของ level ที่ถูกปิดเก็บไว้ · ผลที่เล่นออฟไลน์ใน level ที่ถูกปิดระหว่างนั้นรับไว้เสมอ (OQ38 answered) · **ไม่รู้ชั้น** (SchoolBright ไม่ส่งชั้น/ชั้นนอก ป.1–6): เปิดแค่ Level 1 และทุกด่านล็อก พร้อมแถบแจ้งเตือนแบบโหมด guest (OQ39 answered · รายละเอียด guest ตัดสินใน app-shell แผน 4) · **โหลดค่า access ไม่ได้** (cloud ล้ม/ออฟไลน์และไม่มีแคช): ล็อกทุกใบ + ลองอีกครั้ง (OQ43 answered · R8) · ในแต่ละ level **ด่านแรกของ level (ด่านที่ 1 ของเทอม 1) เปิดเสมอใน level ที่เข้าได้** (ยกเว้นกรณีไม่รู้ชั้น) · ด่านถัดไปเปิดเมื่อ**ผ่านด่านก่อนหน้าใน level นั้น = ได้ ≥1 ดาว (≥60%)** (OQ9 answered 2026-11-01) · **ด่านที่ผ่านแล้วไม่ล็อกกลับ** · **ด่านแรกของเทอม 2 เปิดเมื่อผ่านด่านสุดท้ายของเทอม 1** (เทอม 2 ต่อเนื่องจากเทอม 1 **ไม่มีการข้ามด่านหรือข้ามเทอม** · ผู้ใช้ 2026-10-31) · **checkpoint ไม่ใช่ด่านที่เล่นได้** · ด่านล็อกอีกกรณีคือครูปิด (→ OQ22 · OQ10) · **ต้องบอกเหตุผลที่ล็อก** (ไม่ปล่อยให้กดแล้วเงียบ) · (AC-05, ST-11, ENT-08)
- R8 (M): **สถานะระบบของส่วนบทเรียน:** ระหว่างโหลดค่า access ใช้ skeleton (ห้ามแสดงล็อกแล้วค่อยปลด) · โหลดค่า access ไม่ได้ = ล็อกทุกใบ + ลองอีกครั้ง (OQ43) · level ที่เข้าได้แต่ยังไม่มีเนื้อหา → OQ42 · ครั้งแรกของแต่ละ level (ยังไม่ผ่านด่านใด → ชี้ไปด่านที่ 1 ปุ่มเริ่ม ST-09) · กำลังโหลด · โหลดเนื้อหาไม่สำเร็จ (ลองใหม่ ST-12) · **ยังโหลดความคืบหน้าไม่ได้ "ลองอีกครั้ง"** (ห้ามแสดงเหมือนครั้งแรก/ดาวเป็น 0 ตอนดึงจาก cloud ไม่สำเร็จ) · ออกกลางด่าน (ยืนยันว่าความคืบหน้าในด่านจะหาย ST-14) · ออฟไลน์/กำลัง sync (แสดงที่แถบหน้าต่าง ST-03 · module `app-shell`) · ออฟไลน์เปิดด่านที่ไม่มีแคช → OQ16
- R9 (M): **มาสคอต School Bot** ใช้ในช่วงสำคัญของ Quiz ตาม `../../brand.md` §8: ตอบถูก (ชูกำปั้น) · ตอบผิด (คิด ? พร้อมข้อความให้กำลังใจ · **ไม่ใช้ "ลองใหม่นะ" เพราะไม่มีลองซ้ำ** · ถ้อยคำใหม่ตาม `../../brand.md` §7 · Designer เสนอ) · จบด่าน 3 ดาว (กระโดด+ดาว) · ผ่าน checkpoint/จบเทอม และจบ level (กอดหัวใจ) · **ไม่ใช้ท่าคำใบ้ (หลอดไฟ)** · ต้องมีข้อความกำกับเสมอ ไม่สื่อด้วยภาพอย่างเดียว · alt ตามกฎ · ไม่กะพริบ · ใช้ 10 ท่าที่มีเท่านั้น · (FR-32, AC-19, DEC-29, DEC-30)
- R10 (M): **ใช้ UI เดียวกัน ป.1–6** (โครงและพฤติกรรมเดียว ต่างกันที่ธีมของ level R17) · คำถามและเฉลยใช้ภาษาง่ายสั้น ไอคอนคู่ข้อความ เป้าสัมผัสใหญ่ (≥ 44×44 Proposed) ไม่พึ่ง hover · **ไม่มีเสียงอ่านโจทย์ (ตัดปุ่ม 🔊 ใน MVP · ผู้ใช้ 2026-10-31)** และไม่มีโหมดแยกสำหรับ ป.1–3 · **ไม่ใช้ emoji** ใช้ไอคอนชุดโปรเจกต์ (`../../brand.md` §6) · แบบฝึกเรียง/จับคู่/ลากป้ายต้องมีทางเลือกที่ไม่ต้องลาก (แตะเลือกแล้วแตะวาง · WCAG 2.5.7 AA · Proposed จาก AUD-C) · สไลเดอร์มีปุ่ม ‹ › คู่เสมอ · รางวัล/เกมมีเป้าหมายการเรียนรู้ ไม่ใช่กลไกดึงให้ใช้นาน · **ปุ่มหลักใช้ `action-primary` (น้ำเงิน)** ปุ่ม "เริ่มภารกิจ" ไม่ใช้สีส้มเพราะส้ม = ปุ่มที่ทำให้หุ่นขยับ (`../../brand.md` §1 · OQ29 answered 2026-11-01) · จุดจับสไลเดอร์และเป้ากดทุกจุด ≥ 44 · (NFR-02, DEC-06, DEC-19, RSK-04)

## กฎ/Logic
- **AC-05:** When เปิดบทเรียน Then เห็นหน้าเลือก Level; เลือก level ที่อยู่ใน access แล้วเห็นแผนที่ พร้อมสถานะผ่าน กำลังเรียน หรือล็อก · แตะ level ที่ล็อกแล้วเห็นเหตุผล ไม่เข้าแผนที่ (R7)
- **AC-06 (P2):** When จบด่าน Quiz ที่ให้คะแนน Then คะแนนถูกส่งเข้า SchoolBright และถ้าส่งไม่สำเร็จ ต้องไม่สูญหาย · **phase 1:** When จบด่าน Then ผลบันทึกที่ cloud ของ School Bot (หรือเข้าคิว sync เมื่อออฟไลน์) ไม่หาย
- **UJ-02 เรียนด่าน:** หน้าหลัก → บทเรียน → เลือก Level → แผนที่ (เทอม 1/2) → เลือกด่าน/แผงภารกิจ → ทำแบบฝึก 5–8 ข้อ → ดาว → ด่านถัดไป (FR-06, FR-08)
- **ดาว (ตัวแทนที่ใช้ออกแบบ · ARC-I02 Closed):** ดาว 0–3 ต่อด่าน + จำนวนข้อถูกต่อด่าน + % ด่านที่ผ่าน (ตัวเลขที่ครูเห็นบนเว็บครูใน phase 2 หรือเมื่อ OQ22 ตัดสิน · module `teacher-web` · FR-26)
- **ข้อมูลที่เก็บต่อการเล่น (ENT-10):** นักเรียน, level, **เทอมหลักสูตร (1/2 ตามแผนที่ ไม่ใช่เทอมปฏิทินของเว็บครู)**, ด่าน (ID คงที่), ข้อถูก/ทั้งหมด, ดาว, **เวลาที่ได้**, **ห้อง ณ เวลานั้น** (เพื่อจัดเข้าเทอม/ห้องให้เว็บครูได้แม้นักเรียนย้ายห้อง · ARC-I01) · ผลการเล่นแก้ไม่ได้ (Proposed)
- **ออฟไลน์:** login ต้องออนไลน์ หลัง login ทำงานต่อได้ · ผลการเล่นเข้าคิว sync (Proposed · ARC-I05 · ดู `my-work`/`app-shell`)
- **ล็อกด่าน (ST-11):** ต้องบอกเหตุผลที่ล็อก (ยังไม่ผ่านด่านก่อนหน้า / ยังไม่ผ่านด่านสุดท้ายของเทอม 1 สำหรับด่านเทอม 2 / ครูปิด) ข้อความตามความคืบหน้า ไม่ใช่เวลาปฏิทิน
- **ออกกลางด่าน (ST-14):** กดออก → ยืนยันว่าความคืบหน้าในด่านนี้จะหาย
- ถ้อยคำ: ข้อความภาษาเด็ก ไม่ลงโทษความผิดพลาด ตาราง "คำที่ตัดสินแล้ว" ใน `../../brand.md` §7

## Edge cases
- (P2) ส่งคะแนน Quiz เข้า SchoolBright ไม่สำเร็จ (EC-05): คะแนนไม่หาย เข้าคิว แสดง "รอส่งคะแนน" (ST-16) · รายละเอียดการลองซ้ำ → OQ8 (เลื่อน phase 2)
- เน็ตหลุดระหว่างเล่นด่าน: เล่นต่อได้ (ทำงานแบบออฟไลน์หลัง login) · ผลเข้าคิว sync (Proposed)
- นักเรียนเปลี่ยนเครื่อง (EC-04): ความคืบหน้าบทเรียนผูกกับบัญชี/cloud ของ School Bot (ผู้ใช้ยืนยัน 2026-10-31)
- นักเรียน ป.1 อ่านคำถามไม่ออก (EC-06): ไม่มีตัวช่วยเพิ่มและไม่มีเสียงอ่านใน MVP (ความเสี่ยงที่ยอมรับ RSK-04) · เนื้อหาต้องเรียบง่ายตามระดับ ป.1 · ใช้ภาพช่วยในโจทย์
- นักเรียนเข้า level ที่ไม่ใช่ชั้นตัวเอง: เข้าไม่ได้ เห็นการ์ดล็อกพร้อมเหตุผล จนกว่าครูเปลี่ยน level ให้ระดับชั้น (R7 · 2026-11-05) · ผลนับเข้า SchoolBright ใน phase 2 → OQ21
- ครูปิดหน่วยขณะนักเรียนกำลังเล่น/เคยผ่านแล้ว: ยังไม่กำหนด → OQ10, OQ22
- โหลดเนื้อหาจาก cloud ไม่สำเร็จ (ST-12): ลองใหม่ ไม่ทำให้ผลที่เล่นไปแล้วหาย
- เนื้อหา 22 ด่านต่อเทอมไม่เท่ากันตาม level (คาบต่อสัปดาห์ต่างกัน): แผนที่ต้องรองรับจำนวนด่านไม่เท่ากัน ไม่ fix 22 → OQ18
- เปิดแผนที่หลังผ่านครบทั้ง 2 เทอม: แสดงสถานะจบ level (เส้นชัย) + ไปที่ด่านสุดท้าย
