- R3 (M): หน้าด่านมีแบบฝึก **4 กลุ่ม**: (ก) เลือกตอบ (ข้อความ + ภาพ) · (ข) เรียงบล็อก · (ค) จับคู่ / ลากป้ายวางตำแหน่ง · (ง) ปรับสไลเดอร์ให้ตรงเงา (จำลองแขนกลบนจอ) · **(2026-11-09 · อ้างรายการกิจกรรม 16 แบบที่ `../../system/game-platform/pattern.md` §2: (ก) = `01-choose-4` (เลือกตอบ 4 ช้อยส์) · (ข) = `06-order-3`/`07-order-long` · (ค) = `03-match`/`04-sort` · (ง) = `11-slider-match` · กิจกรรมอื่นในรายการใช้เป็นกลุ่มเสริมของด่านได้ตามเนื้อหา · PQ7 ที่ยังไม่เทียบใบงาน ป.3–6 → OQ64)** · **ไม่มีภารกิจกับหุ่นจริงใน MVP** · **5–8 ข้อต่อด่าน** (แล้วแต่ด่าน) · การกระทำ: ตอบ, ตรวจ, ออก (**ไม่มีปุ่มข้าม** · ผู้ใช้ 2026-11-01) · ตอบแล้วกด "ตรวจ" → ถูก = เฉลยเหตุผลสั้นแล้วกด "ไปต่อ" · ผิด = ตามกติกาลองซ้ำด้านล่าง (ผิดแล้วแก้คำตอบเดิมแล้วกด "ตรวจ" ซ้ำ ไม่มีปุ่ม "ลองใหม่" ระดับข้อ · ปุ่มระดับด่านใช้ "เล่นอีกครั้ง" เท่านั้น) · **ข้อหลายส่วน (เรียง/จับคู่/`10-roles`): 1 ครั้ง = กด "ตรวจ" ทั้งข้อ ถูกเมื่อทุกส่วนถูก (ผู้ใช้ 2026-11-09 · OQ78)** · **ตอบถูกในครั้งที่ 2–3 เห็นเฉลยเหตุผลด้วย** · **`14-explore`/`15-reflect`/`16-create` (ไม่ตัดสินถูกผิด): นับใน progress x/n (จบ = กด "ไปต่อ"/"เสร็จแล้ว") แต่ไม่เข้าตัวหารดาว · "5–8 ข้อ" และ "ด่านผสม 3 ข้อ" นับเฉพาะข้อตัดสิน · ด่านที่ไม่มีข้อตัดสินและไม่มีเกม (n=0) ผ่านเมื่อจบทุก item ดาว "ไม่มี" (ผู้ใช้ 2026-11-09 · OQ77)** · **ตอนจบด่านบันทึกรายข้อ: item_id คงที่, ถูก/ไม่ถูก, ครั้งที่ใช้ 1–3, ใบ้ขั้นสูงสุด 0–3 (ไม่แสดงให้นักเรียน · ผู้ใช้ 2026-11-09 · OQ74 · ENT-10)** · **กติกาลองซ้ำและใบ้ (แก้ 2026-11-09 · `../../system/game-platform/pattern-rule.md` PR-A1, PR-A5, PR-A44, PR-Q1, PR-Q2 · แทนข้อความเดิม "ไม่ลองซ้ำ ไม่มีใบ้" ของผู้ใช้ 2026-10-31):** แยก 2 กลุ่ม — (1) **`01-choose-4` (เลือกตอบ 4 ช้อยส์):** ตอบผิดเห็นเฉลยเหตุผลแล้ว**จบข้อ ไม่ลองซ้ำ ไม่มีใบ้** · (2) **กิจกรรมอื่นในด่าน:** **ตอบได้รวม 3 ครั้งต่อข้อ** ผิดครั้งที่ 1 → ใบ้ขั้น 1 (ชี้จุด) แล้วตอบใหม่ · ผิดครั้งที่ 2 → ใบ้ขั้น 2 (บอกแนวคิด) แล้วตอบใหม่ · ผิดครั้งที่ 3 → ใบ้ขั้น 3 (ทำให้ดู/เฉลย) **แล้วไปข้อต่อ นับไม่ถูก** (หลังใบ้ขั้น 3 ไม่ให้ทำซ้ำ) · ถูกครั้งใดก็ได้คะแนนเต็มข้อนั้น · **`02-pick-1of2` และ `10-roles` (เลือกจาก 2 ทาง):** ตอบได้ **2 ครั้ง** ใบ้ขั้นแรกบอกเหตุผล ผิดครั้งที่ 2 → เฉลยพร้อมเหตุผลแล้วไปข้อต่อ นับไม่ถูก · ใบ้ไม่กระทบดาว · **ใบ้ขึ้นเองหลังตอบผิด ไม่มีปุ่มกดใบ้เองในข้อแบบฝึก (ผู้ใช้ 2026-11-09 · OQ76 · ใบ้ของ item เกมยังกดเองตามเดิม)** · **แสดงตัวบอกครั้งที่ตอบเป็นจุด 3 จุด (`02`/`10` = 2 จุด) ไม่ใช้ตัวเลขอย่างเดียว (OQ80 · DS gap OQ81)** · **ไม่มีปุ่ม "ไม่แน่ใจ"** (ไม่แน่ใจก็ตอบไปเลย) · ทำข้อใหม่ได้เมื่อเล่นด่านซ้ำทั้งด่าน (R4) · **ไม่มีเสียงอ่านโจทย์** (ผู้ใช้ 2026-10-31 · คงเดิม) · ความคืบหน้าในด่านแสดงเสมอ (แถบ + x/n + มาสคอต R18) · **x นับเมื่อ "จบข้อ" (ถูก หรือใช้ครั้งตอบครบ หรือ `01-choose-4` ตอบแล้ว) ลองซ้ำในข้อเดิมไม่เพิ่ม x** · ข้อที่ผิดจนครบครั้งแสดงคำตอบที่ถูก (ใบ้ขั้น 3 / เฉลย) · คะแนนข้อที่ไม่ใช่เลือกตอบ/เกณฑ์ผ่านสไลเดอร์ → OQ13 (ก), OQ20 · **ชนิดด่านและ item เกม (2026-11-06 · OQ47, OQ48, OQ50):** ด่านมี 3 ชนิด — **แบบฝึกล้วน** (5–8 ข้อ ตามข้างต้น) · **เกมล้วน** (item เกม เช่น เดินหุ่นบนตาราง จอยสติ๊กคุมแขน วาดหุ่น · engine ตาม `../../system/game-platform/02-engines.md`) · **ผสม** (item เกม + ข้อแบบฝึก **3 ข้อพอดี**) · item เกมไปต่อได้เมื่อถึงเป้าหลักเท่านั้น · **progress x/n ในด่าน นับทุก item (ข้อแบบฝึก + item เกม)** · ข้อกำหนดเนื้อหา: ด่านผสมมีข้อแบบฝึก 3 ข้อพอดี และทุก item เกมมีเป้าหลักที่ระบบตรวจได้ (ตรวจก่อนเผยแพร่) · item เกม**รันใหม่ได้ไม่จำกัด + ใบ้ 3 ขั้น** (ชี้จุด → บอกแนวคิด → ทำให้ดู 1 ก้าว) ไม่กระทบดาว · **ข้อแบบฝึกใช้กติกาลองซ้ำ/ใบ้ตามข้างต้น (แก้ 2026-11-09 · ไม่ใช่ "ไม่มีใบ้/ไม่ลองซ้ำ" ทุกข้ออีกต่อไป · กติกา "รัน/ลองไม่จำกัด" เป็นของ item เกมเท่านั้น ไม่ใช้กับข้อแบบฝึก)** · ไม่มีปุ่มข้ามทั้งสองแบบ · (FR-06, FR-08, ENT-09, SCR-07, ST-13)

## กฎ/Logic
- **AC-05:** When เปิดบทเรียน Then เห็นหน้าเลือก Level; เลือก level ที่อยู่ใน access แล้วเห็นแผนที่ พร้อมสถานะผ่าน กำลังเรียน หรือล็อก · แตะ level ที่ล็อกแล้วเห็นเหตุผล ไม่เข้าแผนที่ (R7)
- **AC-06 (P2):** When จบด่าน Quiz ที่ให้คะแนน Then คะแนนถูกส่งเข้า SchoolBright และถ้าส่งไม่สำเร็จ ต้องไม่สูญหาย · **phase 1:** When จบด่าน Then ผลบันทึกที่ cloud ของ School Bot (หรือเข้าคิว sync เมื่อออฟไลน์) ไม่หาย
- **UJ-02 เรียนด่าน:** หน้าหลัก → บทเรียน → เลือก Level → แผนที่ (เทอม 1/2) → เลือกด่าน/แผงภารกิจ → ทำแบบฝึก/เกมตามชนิดด่าน (R3) → ผล (ดาว หรือ ผ่านแบบไม่มีดาว) → ด่านถัดไป (FR-06, FR-08)
- **ดาว (ตัวแทนที่ใช้ออกแบบ · ARC-I02 Closed):** ดาว 0–3 ต่อด่าน + จำนวนข้อถูกต่อด่าน + % ด่านที่ผ่าน (ตัวเลขที่ครูเห็นบนเว็บครูใน phase 2 หรือเมื่อ OQ22 ตัดสิน · module `teacher-web` · FR-26) · **ด่านเกม (OQ53):** ครูเห็นผ่าน/ยังไม่ผ่าน + เป้าเสริม · % ด่านที่ผ่านนับด่านเกม · ค่าเฉลี่ยดาวนับเฉพาะด่านที่มีแบบฝึก (ต้องเพิ่ม R# ที่ teacher-web)
- **ข้อมูลที่เก็บต่อการเล่น (ENT-10):** นักเรียน, level, **เทอมหลักสูตร (1/2 ตามแผนที่ ไม่ใช่เทอมปฏิทินของเว็บครู)**, ด่าน (ID คงที่), **ชนิดด่าน**, ข้อถูก/ทั้งหมด, ดาว (**"ไม่มี" สำหรับด่านเกมล้วน** ไม่ใช่ 0), **ถึงเป้าหลักของเกม (ผ่าน/ไม่ผ่าน), เป้าเสริมที่ทำได้, **ผลรายข้อ (item_id คงที่ข้ามเวอร์ชัน, ถูก/ไม่ถูก, ครั้งที่ใช้ 1–3, ใบ้ขั้นสูงสุด 0–3 · OQ74 · บันทึกตอนจบด่าน ออกกลางด่านไม่บันทึก)**, เวอร์ชันเนื้อหา/config ของด่าน** · เปลี่ยนชนิดด่านใช้ ID เดิม (ข้อกำหนด dev), **เวลาที่ได้**, **ห้อง ณ เวลานั้น** (เพื่อจัดเข้าเทอม/ห้องให้เว็บครูได้แม้นักเรียนย้ายห้อง · ARC-I01) · ผลการเล่นแก้ไม่ได้ (Proposed)
- **ออฟไลน์:** login ต้องออนไลน์ หลัง login ทำงานต่อได้ · ผลการเล่นเข้าคิว sync (Proposed · ARC-I05 · ดู `my-work`/`app-shell`)
- **ล็อกด่าน (ST-11):** ต้องบอกเหตุผลที่ล็อก (ยังไม่ผ่านด่านก่อนหน้า / ยังไม่ผ่านด่านสุดท้ายของเทอม 1 สำหรับด่านเทอม 2 / ครูปิด / **level ล็อก 4 กรณี (R7 · OQ56 · 2026-11-06):** สูงกว่าชั้นตามปกติ "Level n สำหรับ ป.n" · ครูลดสิทธิ์ "ติดต่อครูเพื่อปลดล็อก" · ไม่รู้ชั้น (แถบแจ้งเตือนแบบ guest) · โหลดสิทธิ์ไม่ได้ ("ลองอีกครั้ง" · R8)) ข้อความตามความคืบหน้า ไม่ใช่เวลาปฏิทิน
- **ออกกลางด่าน (ST-14):** กดออก **ทางใดก็ตามระหว่างทำด่าน (✕ · ปุ่มบ้าน · ปิดโปรแกรม/Cmd+Q/ออกจากระบบ ตาม app-shell R5)** → ยืนยันว่าความคืบหน้าในด่านนี้จะหาย (ผู้ใช้สั่ง 2026-11-09) · **กลับเข้าด่านเดิมอีกครั้ง = เริ่มใหม่ตั้งแต่ข้อแรกเสมอ ไม่เก็บข้อที่ตอบแล้ว/ครั้งที่ใช้/ใบ้ · ลำดับข้อและเนื้อหาคงเดิม ไม่สุ่ม (OQ87) · item เกมรันใหม่ ใบ้ 0/3** · **ปุ่ม "กลับไปแผนที่" ที่หน้าผลจบด่าน (ด่านจบและบันทึกแล้ว) และหน้า "ต้องอัปเดตโปรแกรม" (ยังไม่เริ่มข้อแรก) ไปทันที ไม่มี popover (OQ88)** · โปรแกรมค้าง/ไฟดับ แสดงยืนยันไม่ได้ ยอมรับ (ไม่มี resume ไม่มีผลบางส่วนให้กู้) · ย่อหน้าต่าง/ล็อกจอ/เน็ตหลุด/session หมดอายุ ไม่ใช่การออก · **ใช้กับทุกชนิดด่านรวมด่านที่มีเกม** (OQ54 · ไม่มี resume) · ผลงานวาดหุ่นบันทึกที่งานของฉันเมื่อกด "เสร็จแล้ว" เท่านั้น · **ข้อความยืนยันบอกเฉพาะผลของด่านนี้ที่จะหาย** และถ้ากด "เสร็จแล้ว" ไปแล้ว บอกว่าผลงานวาดยังอยู่ในงานของฉัน (ไม่บอกว่าทุกอย่างหาย · ruler 2026-11-06) · วิธีเก็บผลงานใน my-work → OQ58
- ถ้อยคำ: ข้อความภาษาเด็ก ไม่ลงโทษความผิดพลาด ตาราง "คำที่ตัดสินแล้ว" ใน `../../brand.md` §7

## Edge cases
- (P2) ส่งคะแนน Quiz เข้า SchoolBright ไม่สำเร็จ (EC-05): คะแนนไม่หาย เข้าคิว แสดง "รอส่งคะแนน" (ST-16) · รายละเอียดการลองซ้ำ → OQ8 (เลื่อน phase 2)
- เน็ตหลุดระหว่างเล่นด่าน: เล่นต่อได้ (ทำงานแบบออฟไลน์หลัง login) · ผลเข้าคิว sync (Proposed)
- นักเรียนเปลี่ยนเครื่อง (EC-04): ความคืบหน้าบทเรียนผูกกับบัญชี/cloud ของ School Bot (ผู้ใช้ยืนยัน 2026-10-31)
- นักเรียน ป.1 อ่านคำถามไม่ออก (EC-06): ไม่มีตัวช่วยเพิ่มและไม่มีเสียงอ่านใน MVP (ความเสี่ยงที่ยอมรับ RSK-04) · เนื้อหาต้องเรียบง่ายตามระดับ ป.1 · ใช้ภาพช่วยในโจทย์
- นักเรียนเข้า level ที่**สูงกว่าสิทธิ์ (N)**: เข้าไม่ได้ เห็นการ์ดล็อกพร้อมเหตุผล จนกว่าครูเปลี่ยน N · **level ต่ำกว่าหรือเท่ากับ N เข้าได้** (R7 · OQ38 · แก้ 2026-11-06 ตาม ruler) · ผลนับเข้า SchoolBright ใน phase 2 → OQ21
- ครูปิดหน่วยขณะนักเรียนกำลังเล่น/เคยผ่านแล้ว: ยังไม่กำหนด → OQ10, OQ22
- โหลดเนื้อหาจาก cloud ไม่สำเร็จ (ST-12): ลองใหม่ ไม่ทำให้ผลที่เล่นไปแล้วหาย
- เนื้อหา 22 ด่านต่อเทอมไม่เท่ากันตาม level (คาบต่อสัปดาห์ต่างกัน): แผนที่ต้องรองรับจำนวนด่านไม่เท่ากัน ไม่ fix 22 → OQ18
- ติดใน item เกม: รันใหม่ได้ไม่จำกัด + ใบ้ 3 ขั้น ไม่มีข้าม (R3 · OQ48)
- เล่นด่านที่ผ่านแล้วซ้ำและรอบนั้นไม่ผ่าน: สถานะคงเป็นผ่าน ดาว/เป้าเสริมเก็บค่าที่ดีที่สุด/สะสม หน้าผลบอก "ภารกิจนี้ผ่านไว้แล้ว" (OQ51 · OQ12)
- เปิดแผนที่หลังผ่านครบทั้ง 2 เทอม: แสดงสถานะจบ level (เส้นชัย) + ไปที่ด่านสุดท้าย

คำถามที่ยังไม่ตัดสินอยู่ใน `oq.md`
