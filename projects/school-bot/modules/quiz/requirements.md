# Quiz (บทเรียน): Requirements (จาก role 1)

> นำเข้าจากระบบเก่า (`Handoff/01_REQUIREMENT` v3.1 + คำตอบผู้ใช้ใน `02_FEASIBILITY` รอบ 2 วันที่ 2026-10-20) · **sketchbook เป็นแหล่งความจริงแล้ว** · ID เดิม (FR/NFR/EC/AC/DEC/ST/SCR/ENT) เก็บในวงเล็บเพื่อ grep ข้ามไฟล์ · ป้ายหลักฐานดู `../../context.md` · ตัวอย่างสไตล์: `../arm-lab/requirements.md`
> หมายเหตุสำคัญ: `04_DECISIONS` เดิมยังเปิด OQ-09 อยู่ แต่ผู้ใช้ตอบรูปแบบคำถาม ดาว และที่มาของเนื้อหาแล้ว (ดู `oq.md` OQ1–OQ3) · สิ่งที่ยัง Unknown: เนื้อหาจริงของด่าน, เกณฑ์เหรียญ, วิธีส่งคะแนนเข้า SchoolBright

## เป้าหมาย
นักเรียน ป.1–6 (UI เดียวกันทุกชั้น) เรียนผ่าน "บทเรียน": แผนที่หน่วยและด่านแนว Duolingo ครอบคลุม AI พื้นฐาน บอร์ด โค้ด และการควบคุมแขนกล · ทำแบบฝึกทีละด่านได้ดาว 0–3 และคะแนน · **คะแนน Quiz เป็นคะแนนเดียวที่ส่งกลับ SchoolBright** และเป็นข้อมูลเดียวที่ครูเห็นบนเว็บครู (DEC-18)

## Requirements
ลำดับ: M = Must · ? = ยังไม่ยืนยัน (ดู OQ)

- R1 (M): Quiz Game คือเมนู "บทเรียน" ใน sidebar · เปิดแล้วเห็น**แผนที่หน่วยและด่านแนว Duolingo** พร้อมสถานะของแต่ละด่าน: ผ่าน / กำลังเรียน / ล็อก · (FR-06, AC-05, DEC-02, SCR-06)
- R2 (M): เนื้อหาครอบคลุม **AI พื้นฐาน, บอร์ด, โค้ด และการควบคุมแขนกล** (แนวทางเดียวกับ Zide, mBlock, micro:bit, Tinkercad, Mixly) · บริษัทเป็นผู้สร้างเนื้อหา **ดึงจาก cloud** (มีสถานะโหลดไม่สำเร็จ ST-12) · ครูเปิด/ปิดหน่วยรายห้องได้ (ตั้งค่าที่เว็บครู · module `teacher-web` · FR-27) · เนื้อหาจริงของด่าน → OQ5, OQ6 · (FR-07, ENT-07, ENT-08, ARC-I03, DEV-Q12)
- R3 (M): หน้าด่านมีคำถาม **3 รูปแบบ: เลือกตอบ, เรียงลำดับ, จับคู่** · การกระทำ: ตอบ, ตรวจ, ข้าม, ออก · ตอบแล้วกด "ตรวจ" → เห็นถูก/ผิด + เฉลยสั้น → ไปต่อ · ความคืบหน้าในด่านแสดงเสมอ · ผลของ "ข้าม" ต่อคะแนน → OQ11 · (FR-06, FR-08, ENT-09, SCR-07, ST-13)
- R4 (M): **กติกาดาว 0–3 ต่อด่าน** ตามสัดส่วนข้อถูก: **≥60% = 1 ดาว (ผ่านด่าน), ≥80% = 2 ดาว, 100% = 3 ดาว** · ต่ำกว่า 60% = 0 ดาว ไม่ผ่านด่าน (Inferred จากเกณฑ์ผ่านที่ผู้ใช้ให้) · ผลจบด่านแสดงดาวและคะแนน มีปุ่ม "ไปต่อ" และ "เล่นใหม่" · เล่นซ้ำนับคะแนนอย่างไร → OQ12 · (FR-08, ENT-10, SCR-08, ARC-I02 Closed)
- R5 (M): **คะแนนจาก Quiz เท่านั้น** ส่งกลับเข้า SchoolBright เมื่อจบด่านที่ให้คะแนน · ถ้าส่งไม่สำเร็จ (ออฟไลน์/SchoolBright ล้มเหลว) **คะแนนต้องไม่หาย** เข้าคิวแล้วส่งเองภายหลัง · ผู้ใช้เห็นสถานะ "ส่งแล้ว" / "รอส่งคะแนน" · วิธีส่ง (API) → OQ7, วิธีส่งซ้ำ → OQ8 · Arm Lab และ Block Lab ไม่ส่งคะแนน · (FR-09, AC-06, EC-05, DEC-04, DEC-18, ENT-11, ST-15, ST-16)
- R6 (?): **ความสำเร็จ (ดาวและเหรียญ)** แสดงบนหน้าหลัก (sidebar/ส่วนความสำเร็จ · module `app-shell` · FR-05) · ดาวคำนวณจากผลด่าน · **เกณฑ์เหรียญยัง Unknown** — Delegated → Designer เสนอ 3 แบบให้ผู้ใช้เลือก: (ก) ผ่านหน่วยครบ (ข) ได้ 3 ดาวครบหน่วย (ค) เล่นต่อเนื่อง (DSG-10 · ข้อเสนอ ไม่ถือเป็น requirement) · → OQ4 · (ENT-12)
- R7 (M): **สถานะด่าน:** ผ่าน (มีดาว) · กำลังเรียน · **ล็อก** · ด่านล็อกเมื่อ (ก) ยังไม่ผ่านด่านก่อนหน้า หรือ (ข) ครูปิดหน่วยนั้น · **ต้องบอกเหตุผลที่ล็อก** (ไม่ปล่อยให้กดแล้วเงียบ) · เกณฑ์ปลดล็อกที่แน่ชัด → OQ9, ผลของการปิดหน่วย → OQ10 · (AC-05, ST-11, ENT-08)
- R8 (M): **สถานะระบบของส่วนบทเรียน:** ครั้งแรก (ยังไม่มีด่าน → ปุ่มเริ่มบทแรก ST-09) · กำลังโหลด · โหลดเนื้อหาไม่สำเร็จ (ลองใหม่ ST-12) · ออกกลางด่าน (ยืนยันว่าความคืบหน้าในด่านจะหาย ST-14) · ออฟไลน์/กำลัง sync (แสดงที่แถบหน้าต่าง ST-03 · module `app-shell`)
- R9 (M): **มาสคอต School Bot** ใช้ในช่วงสำคัญของ Quiz ตาม `../../brand.md` §8: ตอบถูก (ชูกำปั้น) · ตอบผิด "ลองใหม่นะ" (คิด ?) · จบด่าน 3 ดาว (กระโดด+ดาว) · จบหน่วย (กอดหัวใจ) · คำใบ้ (หลอดไฟ) · ต้องมีข้อความกำกับเสมอ ไม่สื่อด้วยภาพอย่างเดียว · alt ตามกฎ · ไม่กะพริบ · ใช้ 10 ท่าที่มีเท่านั้น · (FR-32, AC-19, DEC-29, DEC-30)
- R10 (M): **ใช้ UI เดียวกัน ป.1–6** · คำถามและเฉลยใช้ภาษาง่ายสั้น ไอคอนคู่ข้อความ เป้าสัมผัสใหญ่ (≥ 44×44 Proposed) ไม่พึ่ง hover · ไม่มีตัวช่วยเพิ่มสำหรับ ป.1–3 (เสียงอ่าน/โหมดแยก) ใน MVP · เรียงลำดับและจับคู่ต้องมีทางเลือกที่ไม่ต้องลาก (แตะเลือกแล้วแตะวาง · WCAG 2.5.7 AA · Proposed จาก AUD-C) · รางวัล/เกมมีเป้าหมายการเรียนรู้ ไม่ใช่กลไกดึงให้ใช้นาน · (NFR-02, DEC-06, DEC-19, RSK-04)
- R11 (M): **ภาษา 3 ภาษา ไทย / EN / 中文** ครอบคลุม UI ของส่วนบทเรียน · เผื่อข้อความยาวขึ้น 40% · เนื้อหาคำถามจริงมีกี่ภาษา → OQ6 · (FR-04, ARC-I20 Closed)

## กฎ/Logic
- **AC-05:** When เปิดบทเรียน Then เห็นแผนที่หน่วยและด่าน พร้อมสถานะผ่าน กำลังเรียน หรือล็อก
- **AC-06:** When จบด่าน Quiz ที่ให้คะแนน Then คะแนนถูกส่งเข้า SchoolBright และถ้าส่งไม่สำเร็จ ต้องไม่สูญหาย
- **UJ-02 เรียนด่าน:** หน้าหลัก → บทเรียน → เลือกหน่วยและด่าน → ทำแบบฝึก → ได้คะแนนหรือดาว → คะแนน Quiz ส่งเข้า SchoolBright (FR-06, FR-08, FR-09)
- **ดาว (ตัวแทนที่ใช้ออกแบบ · ARC-I02 Closed):** ดาว 0–3 ต่อด่าน + คะแนนต่อด่าน + % ด่านที่ผ่าน (ตัวเลขที่ครูเห็นบนเว็บครู · module `teacher-web` · FR-26)
- **ข้อมูลที่เก็บต่อการเล่น (ENT-10):** นักเรียน, ด่าน, คะแนน, ดาว, **เวลาที่ได้**, **ห้อง ณ เวลานั้น** (เพื่อจัดเข้าเทอม/ห้องให้เว็บครูได้แม้นักเรียนย้ายห้อง · ARC-I01) · ผลการเล่นแก้ไม่ได้ (Proposed)
- **ออฟไลน์:** login ต้องออนไลน์ หลัง login ทำงานต่อได้ · คะแนน Quiz เข้าคิวรอส่ง (Proposed · ARC-I05 · ดู `my-work`/`app-shell`)
- **ล็อกด่าน (ST-11):** ต้องบอกเหตุผลที่ล็อก (ยังไม่ผ่านด่านก่อนหน้า / ครูปิดหน่วย)
- **ออกกลางด่าน (ST-14):** กดออก → ยืนยันว่าความคืบหน้าในด่านนี้จะหาย
- ถ้อยคำ: ข้อความภาษาเด็ก ไม่ลงโทษความผิดพลาด ("ลองใหม่นะ") ตาราง "คำที่ตัดสินแล้ว" ใน `../../brand.md` §7

## การตัดสินใจที่ผูกกับ module
- DEC-02: Quiz Game คือเมนู "บทเรียน"
- DEC-04: ส่งคะแนนกลับ SchoolBright
- DEC-18: คะแนนที่ส่ง SchoolBright และผลบนเว็บครูมาจาก **Quiz อย่างเดียว** (CR-04)
- DEC-19: ไม่มีตัวช่วยเพิ่มสำหรับ ป.1–3 · ยอมรับ RSK-04
- DEC-29/30: มาสคอตใช้ทั่วแอปนักเรียน 10 ท่าเท่านั้น (ดู `../../context.md`)

## Edge cases
- ส่งคะแนน Quiz เข้า SchoolBright ไม่สำเร็จ (EC-05): คะแนนไม่หาย เข้าคิว แสดง "รอส่งคะแนน" ส่งเองเมื่อเป็นไปได้ (ST-16) · รายละเอียดการลองซ้ำ → OQ8
- เน็ตหลุดระหว่างเล่นด่าน: เล่นต่อได้ (ทำงานแบบออฟไลน์หลัง login) · คะแนนรอส่ง (Proposed)
- นักเรียนเปลี่ยนเครื่อง (EC-04): ความคืบหน้าบทเรียนผูกกับบัญชี/cloud (ผลการเล่นเก็บบน cloud · Inferred จาก ENT-10)
- นักเรียน ป.1 อ่านคำถามไม่ออก (EC-06): ไม่มีตัวช่วยเพิ่มใน MVP (ความเสี่ยงที่ยอมรับ RSK-04) · เนื้อหาต้องเรียบง่ายตามระดับ ป.1
- ครูปิดหน่วยขณะนักเรียนกำลังเล่น/เคยผ่านแล้ว: ยังไม่กำหนด → OQ10
- โหลดเนื้อหาจาก cloud ไม่สำเร็จ (ST-12): ลองใหม่ ไม่ทำให้ผลที่เล่นไปแล้วหาย

คำถามที่ยังไม่ตัดสินอยู่ใน `oq.md`
