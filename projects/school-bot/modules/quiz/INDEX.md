# Quiz (บทเรียน) (สารบัญ module)

เป้าหมาย: นักเรียน ป.1–6 เรียนผ่านแผนที่หน่วยและด่านแนว Duolingo (AI พื้นฐาน บอร์ด โค้ด การควบคุมแขนกล) ทำแบบฝึก 3 รูปแบบ ได้ดาว 0–3 · **คะแนน Quiz เป็นคะแนนเดียวที่ส่งกลับ SchoolBright และที่ครูเห็นบนเว็บครู**

แหล่งความจริง: sketchbook (นำเข้าจากระบบเก่า 2026-10-21) · พึ่งพา `app-shell` (sidebar/หน้าหลัก ปุ่มเรียนต่อ ความสำเร็จ แถบหน้าต่างและสถานะ sync) · module ที่ใช้ข้อมูลจากที่นี่: `teacher-web` (ผล Quiz รายห้อง)
