## สิ่งที่ออกแบบ

**Tweaks:** `lang` · `kind` = quiz (แบบฝึก 6 ข้อ: `01` ข้อความ, `01` ภาพ, `02` สองทาง, `06` เรียง, `03` จับคู่, `11` สไลเดอร์) / mixed (เกม + 3 ข้อตัดสิน) / game (เกม 2) · `show` = live / choiceText / choiceImage / pick2 / order / match / slider / game / exit · `force` = answering / retry1 / retry2 / correct / fail · `hintLevel` (item เกม) · `view` = normal / updateNeeded / contentBad · `net` = ok / offline / sessionExpired · `drawSaved`

**กติกาลองซ้ำ (R3 · OQ66–OQ68, OQ76, OQ78, OQ80):**
- `01-choose-4` (ข้อความ/ภาพ): ตอบครั้งเดียว ไม่มีใบ้ ไม่มีตัวบอกครั้ง · ผิด = เฉลยแล้ว "ไปต่อ" (คำตอบที่ถูก + ที่เลือก) · ไม่มีคำ "ลองใหม่"
- กิจกรรมอื่น 3 ครั้ง (`02` 2 ครั้ง): ผิดแล้วยังเหลือครั้ง → **แถบล่างเปลี่ยนเป็นสถานะใบ้** (พื้น `action-primary-subtle` ขอบบน `border-raise` `action-primary` · ไม่ใช้แดง) มาสคอตหลอดไฟ (ท่า 6) + "ยังไม่ถูก ลองใหม่นะ ดูคำใบ้ก่อน" + ใบ้ที่เห็นแล้วทุกขั้น (ขั้นล่าสุดตัวหนา · ดูซ้ำได้) + AttemptDots + ปุ่ม "ตรวจ" · **ไม่มีปุ่มกดใบ้เอง ไม่มีปุ่มลองใหม่ระดับข้อ ไม่มี "ไม่แน่ใจ"** · เด็กแก้คำตอบเดิมแล้วกด "ตรวจ" ซ้ำ
- งานที่วางไว้ไม่ถูกล้างหลังผิด (เรียง/จับคู่/สไลเดอร์) · ข้อเลือก `02`: ตัวเลือกที่ตอบผิดแล้วขึ้นป้าย "ยังไม่ใช่" (ไอคอน `x` `text-secondary` ขอบเส้นประ) ยังกดได้ · **"ตรวจ" เป็น `aria-disabled` จนแก้คำตอบ** (ข้อเสนอ · OQ84)
- ผิดครั้งสุดท้าย → จบข้อ ไม่ถูก: แถบผิดเดิม + มาสคอตคิด (3) + "ไม่เป็นไรนะ ข้อนี้ยังไม่ถูก" + บรรทัด `lightbulb` "ใบ้ขั้นที่ 3 (เฉลย): …" (`02` = "เฉลย: …") + เฉลยเหตุผล + ช่อง/ตัวเลือกแสดงที่ถูก · ปุ่ม "ไปต่อ" (เด็กกดเอง ไม่ข้ามเอง)
- ถูกครั้งใดก็ได้ → แถบถูก + มาสคอตชูกำปั้น (2) + "เก่งมาก! ถูกต้อง" + เฉลยเหตุผลเสมอ (รวมถูกครั้งที่ 2–3)
- **AttemptDots (DS `sb-att`):** แสดงในข้อลองซ้ำทั้งตอนตอบครั้งแรกและหลังผิด · จุดทึบ = ครั้งที่ใช้รวมครั้งนี้ + "ครั้งที่ n จาก 3/2" · อยู่ข้างปุ่ม "ตรวจ" · ไม่แสดงใน `01` และ item เกม
- **progress x/n:** x นับเมื่อจบข้อ (ถูก/ใช้ครบ/`01` ตอบแล้ว/เกมถึงเป้า) · ผิดกลางทางไม่เพิ่ม x · นับทุก item รวมเกม · `14`/`15`/`16` นับใน x/n (ยังไม่มีแบบหน้าของกิจกรรมเหล่านี้ · ดูข้อเสนอแนะ)

**item เกม (R3 · OQ48 · DS GameHud):** แถบ `sb-hud` = เป้าหมาย │ ตัวนับบล็อก "4 / 6" (`blocks`) │ ปุ่มใบ้ `sb-btn-secondary sb-btn-sm` + `lightbulb` "ใบ้ (n/3)" (ครบ = `aria-disabled` "ใช้ใบ้ครบแล้ว") · ซ้าย = พื้นที่เกม `sb-card-media is-placeholder` + `gamepad-2` (ฉาก/จอยสติ๊ก = DS gap) · ขวา = แผงใบ้ 3 แถว `sb-notice` (เปิด = `lightbulb` + "ใบ้ขั้นที่ n: ชี้จุด/บอกแนวคิด/ทำให้ดู 1 ก้าว" · ยังไม่เปิด = พื้น `off-bg` + `lock`) + มาสคอตหลอดไฟ 64 เมื่อเปิดใบ้แล้ว + "กดปุ่มใบ้ได้เอง ใช้ได้ ไม่ทำให้ดาวลด" (ข้อความต่างจากใบ้ของข้อแบบฝึก) · แถบล่าง: ข้อความช่วย (aria-live) + "เริ่มใหม่" (`sb-btn-secondary sb-btn-lg`) + "รัน" (`sb-btn-primary sb-btn-lg` + `play` · น้ำเงินเพราะเกมจำลองไม่ใช่หุ่นจริง) · รันใหม่ได้ไม่จำกัด · ไม่มีข้าม · ถึงเป้าแล้ว = แถบถูก "ถึงเป้าหมายแล้ว!" + "ไปต่อ"

**ปุ่มสลับเสียง (R10 · OQ79):** `sb-ibtn` ปลายขวาของแถบบนในหน้าเล่น (ต่อจาก "ข้อ x/n") · เปิด = `volume-2` aria-label/tooltip "ปิดเสียง" · ปิด = `volume-x` "เปิดเสียง" · ไม่ใช้ `aria-pressed` (DS README §7) · ค่าเริ่มต้นเปิด · จำค่าต่อบัญชีเป็นงาน dev · ตำแหน่งในแถบเนื้อหา ไม่ใช่ในแถบหน้าต่าง N2 → OQ85
**จุดเรียกเสียง (event · ยังไม่ผูกไฟล์ OQ73):** `tap` เลือกตัวเลือก/หยิบบล็อก/กดใบ้ · `place` วางบล็อก/ป้าย (ทั้งลากและแตะ-แตะ) · `ok` ตอบถูก/เกมถึงเป้า · `retry` ผิดแล้วขึ้นใบ้ / รันไม่ถึงเป้า (เบา ไม่ตกใจ) · `end` จบข้อไม่ถูก · ปิดเสียงแล้วไม่เล่นทุกจุด · เสียงไม่ใช่ช่องทางเดียว (ทุกจุดมีข้อความ/ไอคอนคู่)

**สถานะระบบ (R8):** `updateNeeded` = DS EmptyState มาสคอตท่า 8 "อัปเดตโปรแกรมเพื่อเล่นภารกิจนี้" + "อัปเดตโปรแกรม" + "กลับไปแผนที่" (ไปแผนที่ทันที ไม่มี popover เพราะยังไม่เริ่มข้อแรก · OQ88) · `contentBad` (รวมข้อลองซ้ำที่ใบ้ไม่ครบ/ไม่มีเฉลย) = มาสคอตท่า 3 "โหลดภารกิจนี้ไม่สำเร็จ" + "ลองอีกครั้ง" + "กลับไปแผนที่" (ข้างกัน ไม่ติดทางตัน H3 · ไม่มี popover · ปุ่มนี้มีใน C1 v788 อยู่แล้ว รอบนี้ระบุกฎในไฟล์/คอมเมนต์) · `sessionExpired` = `sb-notice sb-notice-warning` ใต้แถบบน ไม่เด้งออก
**ออกกลางด่าน ST-14 (แก้ 2026-11-09 ตาม ST-14 ใหม่ · OQ87, OQ88):** popover ใต้ปุ่มที่กด (✕ หรือบ้าน) · "ถ้าออกตอนนี้ ความคืบหน้าในภารกิจนี้จะหาย (รวมเกมที่กำลังเล่น) ถ้าเข้ามาใหม่ จะเริ่มภารกิจนี้ตั้งแต่ข้อแรก ดาวและเป้าเสริมที่เคยได้ไม่หาย" + `drawSaved` · พูดเฉพาะผลต่อภารกิจนี้ (กฎ ruler 2026-11-06) · ปุ่ม "ออกจากภารกิจ" (รอง) / "อยู่ต่อ" (หลัก โฟกัสเริ่ม) · ✕ อยู่ซ้ายบน ห่างจาก "ตรวจ" (ruler H5)
- **ปลายทางของ "ออกจากภารกิจ" ต่างตามปุ่มที่เปิด popover:** ✕ → แผนที่ (`QuizMapV1`) · ปุ่มบ้านบนแถบหน้าต่าง → หน้าหลัก (`HomeV6A`) (artboard: `exitHref` ตามปุ่ม)
