## สิ่งที่ออกแบบ
- ดาว 3 ดวง (สูง 76/96/76) เต็ม/ว่างต่างกันด้วย **รูปทรง (ทึบมีขอบ vs โปร่งขอบเทา) + ข้อความ "ได้ x จาก 3 ดาว"** (role=img) · ดาวที่ได้ป๊อป **ครั้งเดียว** ทีละดวงห่าง 0.3s (≤3 ดวง ไม่กะพริบ · reduced-motion = แสดงทันที) · ไม่มีเหรียญ
- มาสคอต ≤150px ตามดาว: 3 ดาว = กระโดด+ดาว(9) · 1–2 ดาว = ยกนิ้ว(10) · 0 ดาว = คิด(3) (ไม่ใช้ท่าหลอดไฟ) · placeholder (OQ32)
- หัวข้อ: 3 ดาว "ครบ 3 ดาว! เก่งที่สุด" · 2 "เก่งมาก ผ่านแล้ว!" · 1 "ผ่านภารกิจแล้ว!" · 0 "ยังไม่ผ่านภารกิจนี้" (ไม่ใช้ "ลองใหม่นะ" · ใช้ "ไม่เป็นไรนะ เล่นอีกครั้งได้เลย" ในบรรทัดอธิบาย) · บรรทัดผล "ตอบถูก x จาก n ข้อ" (จำนวนเต็ม) · 0 ดาว บอก "ต้องตอบถูกอย่างน้อย m ข้อ" (m = ⌈0.6n⌉ เทียบจำนวนเต็ม)
- **การ์ดดาว:** "ดาวใหม่ +n" เฉพาะ n>0 (ส่วนเกินดาวสูงสุดเดิม · OQ12 Proposed) · n=0 แสดง "ดาวสูงสุดของภารกิจนี้ x จาก 3" แทน ไม่แสดง "+0"
- **ปุ่ม:** ผ่าน = "เล่นอีกครั้ง" (รอง) + "ภารกิจต่อไป" (หลัก น้ำเงิน) · **0 ดาว = "เล่นอีกครั้ง" เป็นปุ่มหลัก ไม่ชวนไปภารกิจล็อก** + ข้อความ "ภารกิจถัดไปยังล็อก ต้องตอบถูกอย่างน้อย 60% ก่อน" (ไอคอนล็อก) · ภารกิจสุดท้ายเทอม 1 = "ไปเทอม 2" · ภารกิจสุดท้ายเทอม 2 = "กลับไปที่แผนที่" + หัวข้อ "จบ Level นี้แล้ว!" · ลิงก์เสริม "กลับไปแผนที่" ทุกกรณี
- ผลไม่รอ cloud: แสดงทันที สถานะ sync ใช้ชิปบนแถบหน้าต่างเท่านั้น (Tweak `net = offline`) ไม่ซ้ำในหน้า (app-shell R3)
- **Tweaks:** `lang` · `n` 5–8 · `right` 0–8 (ตัดเป็น n) · `best` 0–3 (ดาวสูงสุดเดิม) · `pos` = normal / lastTerm1 / lastTerm2 · `net`

## Heuristics / UD / WCAG
- H1 บอกผลชัด (ดาว+ตัวเลข+คำ) · H2 ภาษาเด็ก · H3 ทางกลับแผนที่ · H4 คำปุ่มตรงกับ D2 · H5 ไม่ชวนไปภารกิจที่ล็อก · H8 เรียบ มีสิ่งทำต่อ 1 อย่าง (ปุ่มหลัก 1 ปุ่ม) · H9 0 ดาวใช้คำให้กำลังใจ
- UD: ผลสื่อได้ 3 ทาง (รูปทรงดาว/ข้อความ/ตัวเลข) · ไม่ลงโทษ
- WCAG: 1.4.1 · ขาวบน `action-primary` 5.55 · `text-secondary` บนพื้น 5.6 · ขอบดาวทึบ `#B07F00` บนขาว 3.57 · เป้ากด ≥44 (ลิงก์ล่าง 44, ปุ่ม 60) · 2.3.1 ไม่กะพริบ · 4.1.3 บรรทัดผล role=status
- **ยังไม่ได้ตรวจ:** render จริง · ท่ามาสคอตจริง (placeholder) · ข้อความยาว +40% EN/中文 · ผู้อ่านจอ
