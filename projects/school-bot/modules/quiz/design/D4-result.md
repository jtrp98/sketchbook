## สิ่งที่ออกแบบ

**Tweaks:** `lang` · `kind` = quiz / mixed (n = 3) / game (เกมล้วน) / explore (n = 0 ไม่มีเกม · OQ77) · `n` 5–8 (ข้อตัดสินเท่านั้น) · `right` · `best` · `prevPass` · `goalsDone` · `goalsNew` · `pos` · `net`

- **ดาว (R4 แก้ 2026-11-09):** "ข้อถูก" = ถูกภายใน 3 ครั้ง (`02`/`10` 2 ครั้ง · `01` ครั้งเดียว) · n = ข้อตัดสินเท่านั้น ไม่นับ `14`/`15`/`16` · สูตรจำนวนเต็มเดิม 60/80/100 · ด่านผสม ดาว = ข้อที่ถูก · บรรทัดผล "ตอบถูก x จาก n ข้อ" · **ไม่แสดงจำนวนครั้งที่ตอบหรือใบ้ที่ใช้ในหน้านี้เลย** (ไม่มี AttemptDots, ไม่มี "ใช้ใบ้ n ครั้ง" · ข้อมูลรายข้อเก็บใน ENT-10 อย่างเดียว · OQ74)
- **เกมล้วน (`game`) / สำรวจ (`explore`):** ไม่มีแถวดาว/จำนวนข้อ/ดาวใหม่/ดาวสูงสุด · หัวข้อ "ผ่านภารกิจแล้ว!" · game: "เล่นถึงเป้าหมายแล้ว" + "ภารกิจนี้เป็นเกม ไม่มีดาว ลองทำเป้าเสริมดูนะ" (ครบ = "ทำเป้าเสริมครบแล้ว เก่งมาก") · explore: "ทำครบทุกกิจกรรมแล้ว" + "ภารกิจนี้เป็นกิจกรรมสำรวจ ไม่มีดาว" · ไม่มีกรณีไม่ผ่าน
- **เป้าเสริม (OQ51):** การ์ด "เป้าเสริม" DS `GoalList` (`sb-goals`, ทำแล้ว `circle-check` `success` / ยัง `circle` + ข้อความ sr "ทำแล้ว/ยังไม่ได้ทำ") สะสม · ทำได้ใหม่รอบนี้ = `sb-notice sb-notice-success` "ทำเป้าเสริมได้ใหม่ n ข้อ" role=status · แยกจากดาวเสมอ · mixed/game เท่านั้น · มาสคอตลดเหลือ 120 เมื่อมีการ์ดเป้าเสริม
- **เล่นซ้ำ (OQ12):** `prevPass` + รอบนี้ไม่ผ่าน → "ภารกิจนี้ผ่านไว้แล้ว" + "รอบนี้ยังไม่ได้ดาวเพิ่ม ดาวสูงสุดเดิมยังอยู่ ไปต่อได้เลย" + การ์ดดาวสูงสุด · ปุ่มไปต่อเปิด · "ดาวใหม่ +n" เฉพาะส่วนที่เพิ่มจากดาวสูงสุดเดิม
- **0 ดาว (ยังไม่เคยผ่าน):** "เล่นอีกครั้ง" เป็นปุ่มหลัก · ไม่มีปุ่มไปภารกิจที่ล็อก + `lock` "ภารกิจถัดไปยังล็อก ต้องตอบถูกอย่างน้อย 60% ก่อน" (mixed: "อย่างน้อย 1 ข้อ")
- **ปุ่มสลับเสียง (OQ79):** `sb-ibtn` มุมขวาบนของพื้นที่ (ตำแหน่งเดียวกับปลายแถบบนของหน้าเล่น) · `volume-2` "ปิดเสียง" / `volume-x` "เปิดเสียง" · ไม่ใช้ `aria-pressed` · ค่าเริ่มต้นเปิด
- **เสียงเฉลิมฉลอง (R10 · ข้อเสนอ · OQ86):** เล่น 1 ครั้งตอนหน้าเปิดเมื่อผ่าน (ดาว ≥ 1, เกมล้วน, explore) · ไม่เล่นเมื่อ 0 ดาว และเมื่อเคยผ่านแต่รอบนี้ไม่ได้ดาวเพิ่ม · ไม่วน < 3 วินาที · ปิดเสียงแล้วไม่เล่น · เสียงไม่ใช่ช่องทางเดียว (ดาว + คำ + มาสคอตยังบอกผล) · ไฟล์เสียงรอ DS (OQ73)
- **ท่ามาสคอต (R9 · เสนอ OQ60/OQ82):** 3 ดาว = กระโดด+ดาว (9) · 1–2 ดาว / เกมล้วน / explore / เคยผ่าน = ยกนิ้ว (10) · 0 ดาว = คิด (3) · ไม่ใช้ท่าหลอดไฟในหน้านี้
- ผลไม่รอ cloud · สถานะ sync อยู่ที่แถบหน้าต่าง (`net`)

## DS gap

- `DS gap: ไฟล์เสียงเฉลิมฉลอง · ใช้ที่ QuizResultV1 ตอนเปิดหน้าเมื่อผ่าน · ใกล้เคียงที่สุดใน DS: ไม่มี (G20)` → OQ73
- `DS gap: ดาวว่าง (ยังไม่ได้) · ใช้ที่ QuizResultV1 แถวดาว · ใกล้เคียงที่สุดใน DS: off-bg + text-secondary (README §2 ระบุว่ายังไม่ตัดสิน)` · ค่าเดิม `#F4F6F8` / `#8A93A5` คงไว้
- `DS gap: motion ดาวป๊อป 0.6s ครั้งเดียว · ใช้ที่ QuizResultV1 ดาว · ใกล้เคียงที่สุดใน DS: dur-success 1.2s / dur-move 0.2s` → OQ31 (ค่าเดิม)
- **DS ไม่ครบในตัวเอง (ไม่ใช่ gap ของค่า):** `star-fill` / `star-border` มีใน `tokens.json` แต่ไม่มีใน `tokens.css` (README ว่า tokens.css สร้างจาก tokens.json) → artboard เรียก `var(--star-fill)` ไม่ได้ ต้องให้ session หลักเติมที่ DS
- ถ้อยคำเป้าเสริม/ "ทำได้ใหม่" / ข้อความเกมล้วน/สำรวจ ยังไม่ตัดสินใน brand §7 → OQ61, OQ83

## Heuristics / UD / WCAG

- H1 ผลชัด (ดาว + ตัวเลข + คำ) · H2 ภาษาเด็ก · H3 ทางกลับแผนที่ทุกกรณี · H4 คำปุ่มตรง D2 · ปุ่มเสียงตำแหน่งเดียวกับหน้าเล่น · H5 ไม่ชวนไปภารกิจล็อก · H8 ปุ่มหลัก 1 ปุ่ม · H9 0 ดาวใช้คำให้กำลังใจ
- UD: ผลสื่อได้ 3 ทาง (รูปทรงดาว / ข้อความ / ตัวเลข) + เสียงเสริม · ไม่ลงโทษ · ไม่แสดงจำนวนครั้ง/ใบ้ (ไม่กดดัน)
- WCAG: 1.4.1 · ขาวบน `action-primary` 5.55 · `text-secondary` บน `background` 5.61 · `star-border` บนขาว 3.57 · `success` บนขาว 5.13 (ไอคอนเป้าเสริม) · เป้ากด ≥ 44 (`sb-ibtn` 44, ลิงก์ 44, ปุ่ม 56) · 2.3.1 ไม่กะพริบ · 4.1.2 ปุ่มเสียงชื่อเปลี่ยนตามสถานะ · 4.1.3 บรรทัดผลและ "ทำได้ใหม่" role=status · 1.4.2 เสียงสั้นไม่วน ปิดได้
- **ยังไม่ได้ตรวจ:** render จริง · ไอคอนจาก `bundle.js` ตอนรัน · ความสูงรวม mixed + เป้าเสริม + ดาวใหม่ ในพื้นที่ 840 · EN/中文 +40% · ผู้อ่านจอ
