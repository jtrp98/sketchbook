### รอบ 2026-11-06: ตรวจซ้ำ

**ผ่านแล้ว:** ถ้อยคำ phase 1 "ไม่ส่งและไม่ดึง**คะแนน** · อ่านโปรไฟล์ชั้นตอน login ได้" ตรงกับ R5/OQ28 แล้ว (ข้อ 1 ของรอบ 2026-11-05) · ผลด่านเกม (OQ53) ไม่ขัด phase 1 เพราะเก็บที่ cloud School Bot

**ยังค้าง / ขัดกัน (ต้องแก้ requirement · ไม่ต้องถาม):**
1. **phase 2 ตัวเลือก (ข) "ล็อก level ให้เปิดเฉพาะช่วงชั้น" ทำแล้วใน phase 1 (R7)** แต่ R16 ยังเขียนเป็นตัวเลือกของ phase 2 (ค้างจากรอบ 2026-11-05 ข้อ 6) · แก้: phase 2 เหลือกติกาส่งคะแนน (ก) ส่งเฉพาะ level ที่ตรงชั้น หรือส่งทุก level ที่ access เปิด (OQ21) + ส่งเฉพาะด่านที่มีข้อแบบฝึก (OQ53 · ตรงกับ R5 แล้ว ให้ R16 อ้าง R5)
2. **access 1..N ทำให้ phase 2 OQ21 เปลี่ยนรูป:** เด็ก ป.3 เข้า Level 1–3 ได้ตามค่าเริ่มต้น (ไม่ใช่กรณีครูเปิดผิดชั้นอย่างเดียว) → คำถาม OQ21 (ก) ต้องรวมกรณี "เล่น level ต่ำกว่าชั้น" ด้วย (หมายเหตุใน OQ21 · ยังตัดสินตอน phase 2 ตามผู้ใช้สั่ง)
3. **การเตือนครูก่อนลด N ("มีนักเรียนเคยเล่น level ที่จะถูกปิด" · R7) ต้องให้เว็บครูอ่านผลบทเรียนจาก cloud School Bot ใน phase 1** (อย่างน้อยจำนวนนักเรียนที่มีผลใน level นั้นของชั้นนั้น) · ไม่ขัด "ไม่ดึงคะแนนจาก SchoolBright" แต่เป็นการอ่านผล Quiz บนเว็บครูใน phase 1 ซึ่ง OQ22 (ก) ยังเปิด → R16 ต้องระบุว่าเว็บครูอ่าน "มีผลหรือไม่" ได้ใน phase 1 แม้ OQ22 (ก) ตอบว่าไม่แสดงผล
4. **ครูที่สอนชั้นนั้น** (R7) ต้องรู้ห้อง/ชั้นที่ครูสอนจาก SchoolBright (school-bot-web R7, OQ5 ของ school-bot-web) · เป็นข้อมูลโปรไฟล์ ไม่ใช่คะแนน · เงื่อนไขก่อน dev คู่กับ OQ28 (login นักเรียนคืนชั้น)

**ผลต่อ module ที่พึ่งพา (school-bot-web · ชี้ผล ไม่แก้):** `school-bot-web/requirements.md` ยังเป็นฉบับ 2026-10-21: ไม่มี R# หน้าจัดการ access ต่อระดับชั้น, R2–R4 ยังพึ่งคะแนนจาก SchoolBright และสถานะส่ง (phase 2), R5 เปิด/ปิดหน่วยรายห้องทับซ้อน (OQ44), กฎ/Logic ดาวยังไม่มีด่านเกม (OQ53) และยังอ้าง "เกณฑ์เหรียญ" (ตัดแล้ว OQ4) · ต้องเพิ่ม/แก้ R# แล้วส่ง ruler ตรวจ school-bot-web · DS gap G9 (ตัวเลือก access) รอ req school-bot-web

**ช่องว่างที่ผู้ใช้ต้องตัดสิน:** OQ57 (เพิ่ม N มีผลเมื่อไร · กระทบข้อความบนเว็บครูหลังบันทึก) · เดิม OQ40 (ข้ามปีการศึกษา), OQ44, OQ22 (ก), OQ21 (phase 2)

### รอบ 2026-11-05 (ยังใช้ได้ ยกเว้นข้อ 1 ที่แก้แล้ว)
- ข้อมูลชั้นเป็นโปรไฟล์ ไม่ใช่คะแนน: ยอมรับได้ (OQ28) · dev ต้องยืนยันว่า login SchoolBright คืนชั้นจริง ถ้าไม่คืน กฎ R7 ใช้ไม่ได้ทั้งข้อ → **เงื่อนไขก่อนส่ง dev**
- เว็บครูเขียนค่า access ลง cloud School Bot (ไม่เขียนกลับ SchoolBright) · ระดับชั้น ป.1–6 เป็นรายการคงที่
- หน้าจัดการ level ต้องมี: ระดับชั้น, level ที่เปิด, บันทึกสำเร็จ/ไม่สำเร็จ (ST-38), ใครเปลี่ยนล่าสุด/เมื่อไร, ยืนยันก่อนเปลี่ยน (H5)

Heuristic: H5 (ครูเปลี่ยนทั้งชั้นต้องยืนยัน + เตือน), H4 (นิยามผ่าน/ดาวเดียวทั้งแอปและเว็บครู)
