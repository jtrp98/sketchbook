## R4: ดาว 0–3 ต่อด่าน (คิดจากข้อแบบฝึกเท่านั้น)

**ผล: ทำได้มีเงื่อนไข (2026-11-06) · พร้อม: Wait (ด่านผสม + ด่านเกมล้วน รอ OQ47–OQ50) / Yes (ด่านที่มีแต่ข้อแบบฝึก ผลเดิม)** (OQ12, OQ47, OQ48, OQ49, OQ50, OQ51, OQ52, OQ53, OQ54 · OQ45/OQ46 answered)

### รอบ 2026-11-06: แยกดาวออกจากเกม

**ทำได้:** ดาวคิดจาก item ประเภทแบบฝึก (Item Engine · R3 4 กลุ่ม) ในด่าน · item ประเภทเกม (Grid/Arm/Shape) ไม่เข้าตัวหาร n · config ของ game-platform รองรับแล้ว (`lesson.star_rule: "none"`, `reward_configuration.stars_max: 0`, `success_conditions` = เป้าหลัก, `bonus_goals` = เป้าเสริม · 06-config-schema §9.3) · Evaluator ตรวจเป้าหลัก/เป้าเสริมได้ทุก world (§9.2)

**ข้อบกพร่องของสูตร (ต้องแก้ requirement · ไม่ต้องถาม):**
- **n = 0 (ด่านเกมล้วน) สูตรเดิมให้ 3 ดาว:** `ถูก×100 ≥ 100×n` → `0 ≥ 0` เป็นจริง · ต้องระบุใน R4 ว่า **n = 0 ไม่คำนวณดาว เก็บดาวเป็น "ไม่มี" (null) ไม่ใช่ 0 และไม่ใช่ 3** · ทุกที่ที่รวม/เฉลี่ยดาว (R6, เว็บครู) ต้องข้ามค่า null ไม่ใช่นับเป็น 0 (ไม่งั้นค่าเฉลี่ยดาวของเด็กต่ำลงเพราะด่านเกม · H1 ตัวเลขหลอก)
- **"ต่ำกว่า 60% = 0 ดาว ไม่ผ่านด่าน"** ต้องจำกัดว่าใช้กับด่านที่มีข้อแบบฝึก · ด่านเกมล้วนผ่านตาม R7 (OQ46)
- **"ผลจบด่านแสดงดาวและจำนวนข้อถูก"** ใช้ไม่ได้กับด่านเกมล้วน (ไม่มีทั้งสองอย่าง) → ต้องนิยามหน้าผลของด่านเกม: "ผ่านแล้ว" + เป้าหลัก + เป้าเสริมที่ทำได้ · ไม่แสดง "ดาวใหม่ +n" · ไม่แสดง "ถูก 0/0"
- **ข้อมูลต่อการเล่น (ENT-10)** ต้องเพิ่ม: ประเภทด่าน (แบบฝึก / เกม / ผสม), เป้าหลักสำเร็จ (ใช่/ไม่ใช่ ต่อ item เกม), เป้าเสริมที่สำเร็จ (รายการ ID), n อาจเป็น 0 · เวอร์ชัน config ของเกม (เผื่อเป้าเปลี่ยน)

**ขัดกับ R# อื่นใน quiz (ต้องแก้ requirement · session หลัก):**
- **R3** "5–8 ข้อต่อด่าน" และ "หน้าด่านมีแบบฝึก 4 กลุ่ม" ไม่มีที่ให้ item เกม → ด่านเกมล้วน (0 ข้อ) และด่านผสมขัด R3 ตามตัวอักษร · ต้องแก้ R3 ให้ด่านประกอบด้วย item แบบฝึกและ/หรือ item เกม และระบุจำนวนข้อแบบฝึกตาม OQ50 · R3 "ไม่ลองซ้ำ ไม่มีใบ้" ใช้กับข้อแบบฝึก แต่ game-platform มีรันใหม่ (↺) และ `hint_configuration` + Hint ใน shared UI (05-ux-ui §8.1) → ต้องระบุว่าใช้กับ item เกมหรือไม่ (OQ48)
- **R3 แถบ progress "x/n"** นับอะไรในด่านผสม (item ทั้งหมดรวมเกม หรือข้อแบบฝึกเท่านั้น) → เสนอนับ item ทั้งหมด (เด็กเห็นว่าเหลือกี่อย่าง) ส่วนคะแนนนับเฉพาะแบบฝึก · ต้องระบุใน R3 (ไม่ต้องถาม · ไม่มีผลต่อกติกา แต่ Designer ต้องรู้)
- **R7** "ด่านถัดไปเปิดเมื่อ ... ได้ ≥1 ดาว (≥60%)" ขัดกับ R7 ส่วนที่แก้ (ด่านเกมผ่านไม่มีดาว) ใน R# เดียวกัน → ดู `R7.md`
- **R6** ดาวรวม: ด่านเกมไม่เพิ่มดาว · ดาวสูงสุดที่เป็นไปได้ของ level = 3 × จำนวนด่านที่มีข้อแบบฝึก (ไม่ใช่ 3 × ทุกด่าน) และเปลี่ยนเมื่อบริษัทเปลี่ยนชนิดด่านใน manifest → ถ้าแสดง "x/สูงสุด" ตัวหารเปลี่ยนได้ → OQ52 · ผูกข้อค้างเดิม (feasibility 2026-11-05 ข้อ 7: ดาวของ level ที่ถูกครูปิดนับไหม) รวมไว้ใน OQ52
- **R9** มาสคอตกำหนดท่าตามดาว (3 ดาว = กระโดด+ดาว) · ด่านเกมผ่านไม่มีดาวยังไม่มีท่า → Designer เสนอจาก 10 ท่าแล้วถามผู้ใช้ตอนออกแบบ (ไม่ block feasibility)
- **R13** แผงภารกิจ: แท็ก "แบบทดสอบ" ชนิดเดียว และ "รางวัล (ดาว)" · ด่านเกมไม่มีรางวัลดาว → ต้องมีแท็ก "เกม" (และผสม) + รางวัล = เป้าเสริม · node "ผ่าน" ต้องมีแบบไม่มีดาว (DS gap ข้อ 1–3)
- **R18** ดาวป๊อปบนหน้าผลไม่ใช้กับด่านเกม · ฉลองผ่านด่านเกมใช้อะไร → ตอนออกแบบ (motion token ต้องมาจาก DS)

**ขัดกับเอกสารระบบ (ชี้ผล ไม่แก้):**
- `system/game-platform/05-ux-ui.md` §8.1 Game HUD มี "ดาวที่กำลังจะได้" และ Result Card "ดาว/สถิติ" · ขัดกับ Q7 (ด่านเกมในบทเรียนไม่ให้ดาว) · ใช้ได้เฉพาะคลังเกม (ถ้าคลังเกมมีดาว) → session หลักแก้ข้อเสนอ
- `06-config-schema.md` ระดับ Challenge "budget เป็นเงื่อนไขผ่าน" = เป้าหลักต่างกันตาม config · R4/R7 ควรนิยาม "เป้าหลัก = `success_conditions` ของด่านนั้น" (ไม่ fix ว่าเป็น "ถึงเป้า") · `levels[]` (beginner/intermediate) ในเกมของบทเรียน: ด่านบทเรียนต้องตรึงระดับเดียว (เด็กไม่เลือกระดับในบทเรียน) → ข้อกำหนดของ module game-engine ที่จะเปิด

**Edge case:**
- **ด่านผสม (เกม + แบบฝึก):** ผ่านเมื่อไร (ดาวอย่างเดียว / ดาว + เป้าหลักของเกม) R4/R7 ไม่ได้ระบุ · ผลต่างกันมากต่อเด็กที่ทำเกมไม่สำเร็จ → **OQ47** (ห้ามใช้ข้อสมมติ)
- **ข้อแบบฝึกน้อยกว่า 5 ในด่านผสม** (game-platform 04-curriculum §6.2 เสนอ ป.1 U1 คาบ 1 = เลือกตอบภาพ + วาดหุ่น ซึ่งมีโอกาสได้ข้อน้อย): สูตรจำนวนเต็มกับ n ต่ำ · n=1: ถูก 1 = 3 ดาว ผิด = 0 · n=2: 1/2 = 50% = 0 ดาว, 2/2 = 3 ดาว · n=3: 2/3 = 1 ดาว, 3/3 = 3 ดาว · n=4: 3/4 = 1 ดาว, 4/4 = 3 ดาว → **n ≤ 4 ไม่มี 2 ดาว และ n ≤ 2 ผิดข้อเดียว = ไม่ผ่าน** (เข้มเกินสำหรับ ป.1 ที่ไม่มีลองซ้ำ · universal-design) → **OQ50**
- **เกมที่ทำไม่สำเร็จ (ติด):** ด่านเกมล้วนผ่านได้ทางเดียวคือถึงเป้าหลัก · ไม่มีข้ามด่าน (R7) ไม่มีใบ้ (R3) → เด็ก ป.1 ที่ติด grid puzzle ไม่มีทางไปต่อทั้ง level (H9 ทางตัน) → **OQ48**
- **วาดหุ่นอิสระ (Shape Editor) ไม่มีเป้าหลักที่ตรวจได้** (02-engines §4.3 "ผืนผ้าใบว่าง" · S4 ใบงานปลายเปิด "ตรวจอัตโนมัติไม่ได้") → ด่านเกมล้วนแบบวาดจะ "ผ่าน" ด้วยอะไร → **OQ49**
- **เล่นซ้ำ (OQ12 ยังเปิด):** กฎดาวสูงสุดต่อด่านใช้ได้กับด่านที่มีแบบฝึก · ด่านเกม: สถานะผ่าน = เคยถึงเป้าหลักครั้งใดก็ได้ · เป้าเสริมเก็บแบบสะสมหรือตามครั้งล่าสุด → **OQ51** · **แนะนำผู้ใช้ตอบ OQ12 พร้อมกัน** (Proposed เดิม: log ทุกครั้ง ดาวสูงสุด)
- **ผ่านแล้วเล่นซ้ำไม่ผ่าน:** ด่านแบบฝึกได้ 0 ดาวครั้งหลัง / ด่านเกมออกก่อนถึงเป้า → สถานะคง "ผ่าน" ดาวคงค่าสูงสุด ไม่ล็อกด่านถัดไป (ตาม R7 "ผ่านแล้วไม่ล็อกกลับ") · หน้าผลครั้งนั้นต้องบอกว่า "ผลครั้งนี้ยังไม่ผ่าน แต่ภารกิจนี้ผ่านไว้แล้ว" (H1 ไม่ให้เด็กเข้าใจว่าเสียของเดิม) · ทำได้ ไม่ต้องถาม
- **ออกกลางด่านที่มีเกม:** ST-14 "ความคืบหน้าในด่านหาย" ขัดกับ config `save.resume: true, store: my_work_cloud` (06 §9.3) และ "ผลงานบันทึกที่ my-work" ของวาดหุ่น (02 §4.3) → **OQ54**
- **ดาวรวมสูงสุดของ level เปลี่ยน:** บริษัทเปลี่ยนด่านแบบฝึก → เกม (หรือกลับกัน) ใน manifest ใหม่: ดาวที่เด็กได้ไว้จากด่านเดิมยังอยู่ใน log · ตามกฎ R2 (feasibility 2026-11-01) นับจาก manifest ปัจจุบัน → ดาวของด่านที่กลายเป็นเกมจะหายจากผลรวม · ต้องตัดสินพร้อม OQ52 (เสนอ: ID ด่านใหม่เมื่อเปลี่ยนชนิด ด่านเก่าเลิกใช้แต่ดาวที่ได้แล้วยังนับ)
- **ด่านเกมล้วนกับ phase 2 / เว็บครู:** DEC-18 "คะแนนที่ครูเห็น/ส่ง SchoolBright มาจาก Quiz อย่างเดียว" · ด่านเกมไม่มีคะแนน แต่ config มี `report_to_teacher: true` → ครูเห็นอะไร → **OQ53**

**DS gap (แจ้งเพื่อเติม DS · ไม่ใช่ข้อที่ทำให้ทำไม่ได้):** ดู `../feasibility.md` "ทั่วไป › รอบ 2026-11-06" ข้อ 1–4 (node ผ่านแบบไม่มีดาว · เครื่องหมายเป้าเสริม · ป้ายประเภทด่าน · หน้าผลด่านเกม)

### ผลรอบ 2026-11-01 (ยังใช้ได้กับด่านที่มีข้อแบบฝึก 5–8 ข้อ)
- **ตรวจครบทุก N แล้ว** (เทียบเลขจำนวนเต็ม `ถูก×100 ≥ 60×N` ห้ามใช้ทศนิยม): N=5 → 3/4/5 · N=6 → 4/5/6 · N=7 → 5/6/7 · N=8 → 5/7/8 ได้ครบ 3 ระดับและเรียงต่างกันทุก N · ถ้า cloud ส่งด่านนอกช่วง 5–8 ให้คำนวณด้วยสูตรเดียวกัน ไม่ล้ม (ยกเว้น n = 0 ตามรอบ 2026-11-06)
- **เล่นซ้ำ (OQ12):** ผลเป็น log เพิ่มอย่างเดียว · ดาวบนแผนที่ = สูงสุดต่อด่าน · "ผ่านแล้ว" = เคยได้ ≥ 1 ดาวครั้งใดก็ได้ · ผลใหม่ต่ำกว่าเดิมไม่ลดดาวและไม่ล็อกกลับ · "ดาวใหม่ +n" = ส่วนเกินดาวสูงสุดเดิม · n = 0 ไม่แสดงการ์ด "+0" แสดง "ดาวสูงสุดของด่านนี้ x/3" แทน (H1)
- **ปุ่ม "ภารกิจต่อไป":** 0 ดาว (ด่านถัดไปยังล็อก) → ไม่ชวนไปด่านล็อก ใช้ "เล่นอีกครั้ง" เป็นปุ่มหลัก + บอกว่าต้องได้ 60% ก่อน · ด่านสุดท้ายเทอม 1 → ไปด่านแรกเทอม 2 (ฉลองจุดพัก) · ด่านสุดท้ายเทอม 2 → กลับแผนที่ที่เส้นชัย
- ไอคอนแทน emoji ตาม brand §6 · คำปุ่มตาม OQ30 ("เล่นอีกครั้ง", "ภารกิจต่อไป")
- ผลจบด่านไม่รอ cloud: บันทึกลงเครื่องแล้วแสดงผลทันที ส่งขึ้น cloud เบื้องหลัง (R5)

Heuristic: H1 (ดาว null ≠ 0, ผ่านไว้แล้วแม้ครั้งนี้ไม่ผ่าน), H5 (สูตร n = 0), H9 (เกมติดไม่มีทางออก) · `knowledge/universal-design.md` (เด็กเล็กไม่ติดทางตัน, n ต่ำเข้มเกิน) · WCAG ไม่มีประเด็นใหม่ (เครื่องหมายผ่าน/เป้าเสริมต้องมีข้อความ ไม่ใช้สีหรือไอคอนอย่างเดียว 1.4.1)
