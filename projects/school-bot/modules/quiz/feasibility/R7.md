### รอบ 2026-11-06: ด่านเกมล้วนผ่านเมื่อถึงเป้าหลัก (OQ46)

**ทำได้:** สถานะด่านคำนวณจาก log (R5) ได้เหมือนเดิม · นิยามใหม่ "ผ่าน" ต่อด่าน = (ด่านมีข้อแบบฝึก: ดาวสูงสุด ≥ 1) หรือ (ด่านเกมล้วน: เคยถึงเป้าหลักครั้งใดก็ได้) · ไม่เพิ่มสถานะที่ 4 · "ผ่านแบบไม่มีดาว" เป็นรูปแบบหนึ่งของสถานะ "ผ่าน" บน node (ข้อความ/ไอคอนผ่านเหมือนกัน ต่างกันที่ไม่มีแถวดาว)

**ขัดกันเองใน R7 (ต้องแก้ requirement · ไม่ต้องถาม):**
- "ด่านถัดไปเปิดเมื่อ**ผ่านด่านก่อนหน้าใน level นั้น = ได้ ≥1 ดาว (≥60%)**" ขัดกับประโยคต้น R7 ที่ให้ด่านเกมล้วนผ่านโดยไม่มีดาว → ถ้าอ่านตามตัวอักษร ด่านหลังด่านเกมจะไม่ปลดเลย · แก้เป็น "ผ่านด่านก่อนหน้าตามนิยาม 'ผ่าน' ด้านบน (แบบฝึก ≥1 ดาว · เกมล้วน ถึงเป้าหลัก · ผสม ตาม OQ47)"
- กฎที่ใช้ได้ (ปรับจากรอบ 2026-11-01): ด่าน k เปิด ⇔ k = ด่านแรกของ level ที่เข้าได้ **หรือ** ด่าน k−1 "ผ่าน" (นิยามใหม่) **หรือ** ด่าน k เคยผ่านแล้ว · ด่านแรกเทอม 2 อิงด่านสุดท้ายเทอม 1 (ด่านนั้นเป็นเกมก็ใช้นิยามเดียวกัน)
- **"เป้าหลัก"** ไม่มีนิยามใน quiz · เสนอระบุใน R7/R4: "เป้าหลัก = เงื่อนไขผ่าน (`success_conditions`) ที่กำหนดไว้ในด่านนั้น" (ไม่ fix ว่าเป็นการเดินถึงจุดหมาย เพราะ Challenge ใช้ budget เป็นเงื่อนไข · Joystick ใช้วางวัตถุในโซน) · ข้อกำหนดตามมา: **ทุกด่านเกมในบทเรียนต้องมีเป้าหลักที่ระบบตรวจได้** (ข้อมูลด่านไม่มีเป้าหลัก = ข้อมูลผิด ห้ามเผยแพร่) → ผูก OQ49 (วาดหุ่น)

**ช่องโหว่ที่ต้องผู้ใช้ตัดสิน (เปิด OQ · ห้ามใช้ข้อสมมติ):**
- (ก) **ด่านผสม** ผ่านเมื่อไร → OQ47
- (ข) **ด่านเกมที่เด็กติด** ไม่มีข้าม/ใบ้ → ทั้ง level ค้างที่ด่านนั้น (H9) → OQ48
- (ค) **ด่านวาดหุ่นอิสระ** ไม่มีเป้าหลักที่ตรวจได้ → OQ49
- (ง) **แสดงเป้าเสริมบนแผนที่/แผงภารกิจ** และเก็บแบบสะสมไหม → OQ51

**edge case ที่ตรวจแล้ว (ทำได้ ไม่ต้องถาม):**
- **ผ่านแล้วเล่นซ้ำไม่ผ่าน:** สถานะคง "ผ่าน" (คำนวณจาก "เคยผ่าน" ใน log) · ด่านถัดไปไม่ล็อกกลับ · ใช้ได้ทั้งด่านแบบฝึกและด่านเกม
- **"กำลังเรียน"** ของด่านเกม = ด่านแรกที่ยังไม่ผ่านใน level (เหมือนเดิม) · เข้าเล่นแล้วออกก่อนถึงเป้า → ยังเป็น "กำลังเรียน"
- **เหตุผลล็อกด่าน (ST-11)** "ผ่านด่านที่ k−1 ก่อน" ใช้ได้กับด่านเกม แต่ถ้อยคำที่บอกเกณฑ์ ("ต้องได้ 60% ก่อน" บนหน้าผล 0 ดาว · R4) ต้องแยกตามชนิดด่านก่อนหน้า: แบบฝึก "ได้อย่างน้อย 1 ดาว" · เกม "ทำเป้าหมายของเกมให้สำเร็จ" (Designer เขียนตาม brand §7)
- **node บนแผนที่ (R13):** "ผ่าน" ต้องบอกด้วยไอคอน+ข้อความ ไม่ใช่ดาว (ด่านเกมไม่มีดาว · ถ้าใช้ดาวเป็นตัวบอกผ่าน ด่านเกมจะดูเหมือนยังไม่ผ่าน · 1.4.1/H1) · ดาวว่าง 3 ดวงบนด่านเกมห้ามแสดง (ดูเหมือนได้ 0 ดาว) → DS gap ข้อ 1
- **เว็บครู (`teacher-web`):** R3/R4 ใช้ "ดาว 0–3 ต่อด่าน + คะแนน + % ด่านที่ผ่าน" · ด่านเกมต้องแสดงเป็น "ผ่าน (ไม่มีดาว)" ไม่ใช่ 0 ดาว · % ด่านที่ผ่านนับด่านเกมได้ (นิยามผ่านเดียวกับแอป) · ค่าเฉลี่ยดาวคิดเฉพาะด่านที่มีแบบฝึก · ครูเห็นด่านเกมไหม → OQ53 · teacher-web กฎ/Logic "ดาว 0–3 ต่อด่าน: ≥60% ..." ต้องเพิ่มกรณีด่านเกม (แก้ตอนเพิ่ม R# teacher-web)

**ตรวจซ้ำส่วน R7 ที่ค้าง (ruler recheck R7/R8/R12/R16/AC-05 · รอบนี้ตรวจเฉพาะ R7 + AC-05 · R8/R12/R16 ยังไม่ได้ตรวจซ้ำ):**
- ผ่านแล้ว: "ด่านแรกของ level เปิดเสมอใน level ที่เข้าได้" (ข้อ 1 ของรอบ 2026-11-05) · แตะ level ล็อกเห็นเหตุผล ไม่เข้าแผนที่ (R7 + AC-05 ข้อ 2) · คำตอบ OQ38/OQ39/OQ43 ใส่ใน R7 แล้ว · ไม่รู้ชั้นเปิด Level 1 แต่ทุกด่านล็อก = ผู้ใช้ตัดสินแล้ว (ยอมรับทางตันพร้อมแถบแจ้งเตือน)
- ยังค้าง (ต้องแก้ requirement):
  1. **กฎ/Logic "ล็อกด่าน (ST-11)"** ยังมีเฉพาะเหตุผลระดับด่าน · ไม่มีเหตุผลระดับ level ("Level n เปิดถึงชั้นที่ครูกำหนด · ติดต่อครูเพื่อปลดล็อก"), ไม่รู้ชั้น, โหลดค่า access ไม่ได้ (ข้อ 4 ของรอบ 2026-11-05)
  2. "การตัดสินใจที่ผูกกับ module" 2026-10-31 ยังเขียน "Level 1–6 = ป.1–6 เข้าได้อิสระ" และ OQ9 คำตอบยังมี "ทุก level เข้าได้อิสระ" โดยไม่มีหมายเหตุว่าถูกแทน (ข้อ 3)
  3. R6 ดาวรวมนับ level ที่ถูกปิดไหม (ข้อ 7) → รวมใน OQ52
  4. `INDEX.md` quiz `depends_on` มี `teacher-web` แล้ว (ข้อ 8 เสร็จ)
- ความกำกวมใหม่ในถ้อยคำ R7: "access ถึง Level N = เข้าได้ Level 1 ถึง N" กับ "ค่าเริ่มต้น N = ชั้น" · ป.3 จึงเข้า Level 1–3 ได้ (เล่นย้อน level ต่ำกว่า) · "ด่านแรกของ level เปิดเสมอ" ใช้กับทุก level 1..N (ไม่ใช่แค่ level ตามชั้น) · ถูกต้องตามคำตอบ OQ38 แต่ R12/edge case "นักเรียนเข้า level ที่ไม่ใช่ชั้นตัวเอง: เข้าไม่ได้" ขัดกับคำตอบนี้สำหรับ level ที่ต่ำกว่าชั้น → แก้ edge case เป็น "level ที่สูงกว่า access" (ไม่ต้องถาม · คำตอบ OQ38 ชัดแล้ว)

### รอบ 2026-11-05: ล็อกระดับ level ตามชั้น (ยังใช้ได้ · OQ38/39/41/43 ตอบแล้ว)
- **ทำได้ทางเทคนิค:** ชั้นมาจาก login (login ต้องออนไลน์ app-shell R6) · level ที่เปิด = f(ชั้นจาก login, ค่าที่ครูตั้งให้ระดับชั้นนั้นของโรงเรียน) · ค่าที่ครูตั้งเก็บที่ cloud School Bot ดึงพร้อม manifest ตอน login/เปิดหน้าเลือก Level แคชแยกตามบัญชี · ตัดสินฝั่ง client ได้ แต่ **cloud ต้องตรวจซ้ำตอนรับผล** ถ้าต้องการให้ล็อกมีผลจริง · ผลจาก level ที่ไม่เปิดให้: รับไว้เสมอ (OQ38 answered)
- **กฎสองชั้นแยกกัน:** (1) ล็อกระดับ level (ชั้น/ครู) (2) ล็อกระดับด่านภายใน level ที่เปิด · เหตุผลคนละข้อความ
- ช่องโหว่ที่ยังเปิด: ข้ามปีการศึกษา (OQ40) · level ที่เปิดให้ยังไม่มีเนื้อหา (OQ42) · หน้าจัดการ level กับ teacher-web R5 (OQ44)
- ขัดกับ module อื่น: `app-shell` R6 ต้องระบุว่าได้ชั้นจาก SchoolBright · R7 "เรียนต่อ" ไป level ที่เปิดอยู่ · `teacher-web` ยังไม่มี R# หน้าจัดการ level (R16)
- R14 (3) "แตะเทอม 2 ตอนยังล็อก → เลื่อนดูได้" ใช้กับ level ที่เปิดเท่านั้น · level ที่ล็อกไม่เข้าแผนที่
- D1 ต้องแก้: การ์ดล็อก + เหตุผล (DS `Card` state ปิดใช้ · ds-build) · ป้าย "เล่นล่าสุด" อาจชี้ level ที่ล็อกแล้ว

### กฎล็อกระดับด่านภายใน level (รอบ 2026-11-01 · ยังใช้ได้ ยกเว้นนิยาม "ผ่าน" ที่ปรับในรอบ 2026-11-06)
- **checkpoint ไม่ใช่ด่าน** เป็นเครื่องหมายบนแผนที่ที่ปลดตามด่านสุดท้ายเทอม 1
- **"ทางลัด"** R14 เรียก "ปุ่มเลื่อน" · แตะ "เทอม 2" ตอนยังล็อก: เลื่อนไปดูได้ + เหตุผลในแผง (H1)
- **เหตุผลล็อก:** ใช้ข้อความตามความคืบหน้าเท่านั้น ("ผ่านด่านสุดท้ายของเทอม 1 ก่อน" / "ผ่านด่านที่ k−1 ก่อน") · "ครูปิด" ไม่ใช้ใน phase 1 (OQ22)
- ล็อกด้วย `aria-disabled` + แตะแล้วเปิดแผงอธิบาย เข้าถึงได้ด้วยคีย์บอร์ด ลำดับ Tab ตามลำดับด่าน
- **OQ9 (answered ≥1 ดาว):** เด็ก ป.1 ที่ได้ <60% ต้องเล่นซ้ำจนผ่าน · ถ้าโจทย์ชุดเดียวกัน ผู้เล่นจะจำคำตอบ → สลับลำดับตัวเลือก/ข้อ เป็นข้อเสนอ dev · ด่านเกมมีความเสี่ยงทางตันแบบเดียวกันแต่หนักกว่า (ไม่มีทางผ่านด้วยการจำ) → OQ48
- **OQ26:** 1 ด่าน = 1 คาบ แต่ทำเสร็จในไม่กี่นาที → เด็กทำจบทั้งเทอมในครั้งเดียวได้ · รอผู้ใช้ยอมรับ

Heuristic: H1 (ผ่านไม่ใช้ดาวเป็นตัวบอก), H4 (นิยาม "ผ่าน" เดียวทั้งแอปและเว็บครู), H9 (เกมติด/วาดไม่มีเป้า) · WCAG 1.4.1 · `knowledge/universal-design.md`
