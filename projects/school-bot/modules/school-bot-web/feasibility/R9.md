## เงื่อนไข/ช่องว่าง
1. **"ไม่เก็บความคืบหน้า" ต้องนิยามขอบเขต:** ชัดว่าไม่มีตัวนับ/เครื่องหมาย "เรียนแล้ว" และไม่บันทึกลงบัญชี · ไม่ชัดว่าสถานะชั่วคราวในหน้า (ขั้นต่อสายของบท, บทที่เปิดล่าสุด) จำไว้ระหว่างที่ยังเปิดเว็บหรือไม่ → OQ35 (ดู `R12.md`)
2. **ที่อยู่ของหน้า (URL):** แต่ละหัวข้อ/หมวด/บทควรมีที่อยู่ของตัวเอง เพื่อให้รีเฟรชแล้วอยู่บทเดิม ครูส่งลิงก์บทให้นักเรียนได้ และปุ่มย้อนกลับของเบราว์เซอร์ทำงานถูก (H3) · ไม่ใช่การเก็บความคืบหน้า · เป็นเงื่อนไขส่งต่อ dev
3. **โครงเมนู:** นักเรียนมีเมนูเดียว (Guideline) ที่มี 3 หัวข้อ · ครูมี 5 เมนู · ออกแบบได้ทั้งคู่ด้วยโครงเดียว (H4) ให้ Designer เสนอ
4. **สถานะที่ต้องมีทุกหน้า Guideline:** กำลังโหลดเนื้อหา · โหลดเนื้อหาไม่สำเร็จ + ลองใหม่ (ST-35 เดิมเขียนสำหรับ SchoolBright ต้องขยายให้ครอบคลุมเนื้อหา Guideline) · ไม่มีเน็ต (เว็บต้องออนไลน์)
5. **ภาพอ้างอิง learn-esp32:** ใช้เป็นรูปแบบการใช้งานเท่านั้น · เว็บอ้างอิงไม่มีขั้นต่อสาย (R12) และไม่มีบทบาท/ login จึงไม่มีตัวอย่างสำหรับสถานะ "ยังรันไม่ได้" ต้องออกแบบเอง
6. **ผลต่อ module อื่น:** `block-lab` เป็นแหล่งชื่อหมวด/บล็อก/เซนเซอร์ → block-lab ควรลงทะเบียนว่า school-bot-web พึ่งพา และ CHANGELOG ของ block-lab R18/ตารางหมวด/`sensor-list.md` ต้องใส่ "กระทบ: school-bot-web R10, R11" ทุกครั้ง (รายงาน session หลัก)
7. OQ24 (เก็บความคืบหน้า) ยังเปิด: ไม่ block phase 1

**H1/H5/H9:** ครอบคลุมเมื่อเพิ่มข้อ 4
