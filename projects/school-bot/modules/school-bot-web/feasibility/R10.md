# school-bot-web feasibility · R10: หัวข้อ Block (การ์ดบล็อก + animation)

**ผล: ทำได้มีเงื่อนไข** (2026-11-11 · ruler)

## เทียบกับ `block-lab` R18 + ตารางหมวด (ฉบับ 2026-11-02 · 14 หมวด + ตัวละคร)

| ระดับ (R10) | หมวด | มีบล็อกใน MVP | ว่างใน MVP |
|---|---|---|---|
| Basic (8) | เริ่มต้น, ควบคุม, ตรรกะ, คณิต, ตัวแปร, ฟังก์ชัน | 6 | ข้อความ, รายการ |
| Advanced (6) | Sensor, Display, Serial | 3 | Car Control, มอเตอร์, Remote Control |
| ไม่อยู่ในระดับใด | ตัวละคร (Stage) | มีบล็อก (ขยับ, พูด, เปลี่ยนท่า) | - |

ชื่อหมวดใน R10 ตรงกับ R18 ครบ 14 หมวด

## ช่องว่าง
1. **หมวดว่าง 5 หมวด (Advanced ว่างครึ่งหนึ่ง):** → OQ27 (เปิดอยู่) · Block Lab เองแสดงหมวดว่างพร้อมข้อความชี้ไปหมวด Sensor (block-lab OQ169 Proposed) · ถ้า Guideline ทำต่างจาก Block Lab ผู้ใช้จะเห็นจำนวนหมวดไม่เท่ากัน (H4)
2. **หมวด "ตัวละคร" ไม่อยู่ใน Basic/Advanced:** R10 ไม่กล่าวถึง → OQ39
3. **หมวด Sensor ซ้ำกับหัวข้อ Sensor (R11):** หมวด Sensor ของ Block Lab มีบล็อกของทั้ง 33 รายการ + ปุ่มกด + potentiometer · ถ้าทำการ์ด "ทีละตัว" จะได้การ์ด 35 ใบที่เนื้อหาซ้อนกับบท 3D และ R13 สั่งไม่แสดงบล็อกในบท 3D → ต้องตัดสินว่าการ์ดหมวด Sensor ทำครบไหม และลิงก์ไปบท 3D ไหม → OQ40
4. **จำนวนบล็อกยังไม่นิ่ง:** block-lab ยังต้อง "จับคู่บล็อกรายตัวจาก 126 บล็อกกับ dev" · เนื้อหาการ์ดสุดท้ายทำได้เมื่อรายการบล็อกนิ่ง · ออกแบบรูปแบบการ์ดได้ก่อนด้วยหมวดที่นิ่งแล้ว (เริ่มต้น, ควบคุม, ตรรกะ)
5. **รูปบล็อกต้องมาจากแหล่งเดียวกับ Block Lab:** ถ้าทำเป็นรูปภาพแยก จะไม่ตรงทันทีที่ block-lab แก้หน้าตา/สี/ชื่อ (หมวดเปลี่ยนมาแล้ว 16 → 15 → 14) · เงื่อนไขส่ง dev: วาดจากนิยามบล็อกชุดเดียวกับแอป · เงื่อนไขเอกสาร: ดู `R9.md` ข้อ 6
6. **"ช่องที่ต้องใส่ค่า":** บล็อกอุปกรณ์ของ Block Lab ใช้ "เลือกอุปกรณ์" ไม่ใช้เลขขา (block-lab R16) · คำอธิบายในการ์ดต้องตรงตามนี้ แม้บท Sensor (R11–R13) จะพูดถึงเลขขาในโค้ด C++
7. **animation (OQ29 เปิดอยู่):** ต้องกำหนดเมื่อ OQ29 ตอบ · เงื่อนไขที่ไม่ขึ้นกับคำตอบ: ไม่เล่นพร้อมกันทุกใบในหน้า · ที่เล่นวนเกิน 5 วินาทีต้องหยุดได้ (WCAG 2.2.2) · เคารพ prefers-reduced-motion (แสดงภาพนิ่งขั้นสุดท้าย) · ค่า duration/easing ต้องมาจาก DS
8. **การหาบล็อก:** ไม่มีค้นหาชื่อบล็อกข้ามหมวด (ประมาณร้อยกว่าใบ) · ไม่ทำให้ทำไม่ได้ · บันทึกเป็นข้อเสนอ (H7)
9. **สถานะ:** โหลดการ์ด (H1) · หมวดว่าง (ตาม OQ27) · โหลดไม่สำเร็จ + ลองใหม่ (H9) · ระดับ/หมวดที่เลือกควรอยู่ใน URL (ดู `R9.md` ข้อ 2)

**DS gap:** รูปบล็อก + สีหมวดบล็อก (ds-build ระบุ "บล็อก" ยังไม่มี component · block-lab INDEX ระบุ token สีหมวดยังไม่มีใน DS) · ใช้ที่การ์ดบล็อก · ใกล้เคียงที่สุด: `Card` (กรอบการ์ด) · ป้ายสถานะ "เร็ว ๆ นี้" ถ้า OQ27 เลือกแสดง → OQ46
