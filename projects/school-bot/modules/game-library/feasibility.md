## สรุป

- ไม่มีข้อที่ทำไม่ได้ในระดับ UI · ความเสี่ยงหลักคือขอบเขต (13 เกม × engine ~10 ตัว + ตัวสร้างด่านวันนี้ 13 ชุด · RSK-11 สูง/สูง · CON-08 ไม่ทราบเวลา/ทีม) ไม่ใช่ความเป็นไปได้ของหน้าจอ
- **ข้อขัดในตัว requirement 1 ข้อ:** กฎสถานะ "โหลดความคืบหน้าจาก cloud ไม่ได้ → ห้ามแสดงเหมือนยังไม่เคยเล่น ให้ลองอีกครั้ง" กับ R8 "เล่นได้เมื่อออฟไลน์" ชนกันเมื่อเปิดบนเครื่องใหม่ขณะออฟไลน์ → OQ8
- **ข้อขัดกับ module อื่น 1 ข้อ:** R7 ออกกลางด่านไม่ถามยืนยัน แต่ด่านเกมในบทเรียน (quiz ST-14) ถามยืนยัน บนหน้าเล่นและ engine เดียวกัน → OQ9
- **ช่องว่างที่ต้องมีก่อนออกแบบ:** ชั้นแนะนำต่อเกม (OQ6) · เกมที่ยังไม่พร้อมแสดงอย่างไร (OQ7) · สถิติดีสุดเก็บระดับไหน (OQ10) · กติกาด่านวันนี้ (OQ11) · จำนวนด่านต่อเกม (OQ13) · ทางเข้า "เกมแนะนำ" จากหน้าหลัก (OQ14 · คู่กับ app-shell OQ20) · หน้าเกมเป็น N3 หรือ N2 (OQ15)
- **ไม่มีเจ้าของ R# ของ engine:** R6 และ quiz R3 อ้าง `02-engines.md` ซึ่งเป็น Proposed · 07-priority เสนอ module `game-engine` แต่ยังไม่มี → ใบ้ 3 ขั้น, Run Controls, HUD, หน้าจบ ถูกนิยามซ้ำใน 2 module เสี่ยงเพี้ยน · เสนอ session หลักเปิด module/spec กลาง (ดู "ทั่วไป")
- DS gap: Skeleton (ตัดสินแล้ว ยังไม่เติม) · การ์ดเกม + ตัวกรองหมวด (G7) · ภาพเกม 13 ภาพ + ไอคอนทักษะ · แถวรายการด่าน · ชุดหน้าเล่น (HUD, Run Controls, ใบ้+มาสคอต, หน้าจบไม่มีดาว, Joystick, ตัวนับ budget, sprite ของ world, node flowchart, เฟือง) · รายละเอียดใน "ทั่วไป › DS gap"

## R1: หน้าคลังเกม 13 เกม · เรียงตามชั้น · กรองหมวด

**ทำได้มีเงื่อนไข** · รายละเอียด `feasibility/R1.md`
- เกมส่วนใหญ่มีช่วงความยาก ★ → ★★★ ใน 03 (G1, G2, G4, G6, G10 ครอบ ป.1–6) แต่ R4 ให้ "ความยากระดับเดียว = ชั้นแนะนำ" → ต้องกำหนดชั้นแนะนำต่อเกมและรูปแบบที่แสดง (ชั้นเดียว / ช่วง) · ถ้าใช้ระดับเริ่มของ 03 **ไม่มีเกมใดเริ่มที่ ★★★ → นักเรียน ป.5–6 ไม่มีกลุ่ม "ตรงชั้น"** → OQ6
- "13 เกม" ตายตัว แต่ G14 ต้องมี sub-engine ใหม่ (07 ระบุว่าตัดได้) และ RSK-11 สูง → ต้องตัดสินว่าเกมที่ยังไม่พร้อมแสดงอย่างไร (ห้ามทำ "เร็ว ๆ นี้" เองตาม app-shell feasibility R7 ข้อ 1) → OQ7
- กรองหมวด: ตัด G12 แล้ว Creative Workshop เหลือ G13, G14 (ยัง ≥ 2) · ถ้า G14 ไม่มา (OQ7) หมวดนี้เหลือ 1 เกม · ผลกรองว่างเกิดไม่ได้ถ้าทุกหมวดมีเกม · ไม่มีช่องค้นหา (13 เกมไม่จำเป็น)
- ไม่รู้ชั้น → OQ3 (ไม่ block ออกแบบ)

## R2: การ์ดเกม

**ทำได้มีเงื่อนไข**
- ภาพเกม 13 ภาพ: CON-05 ไม่จ้างนักวาด + กฎ DS → ทุกภาพเป็น DS gap (asset) ต้องให้ผู้ใช้อนุมัติแหล่งภาพก่อนออกแบบการ์ด
- ไอคอนทักษะ 1–2 ตัว: ต้องมีชุดไอคอนต่อทักษะ (หุ่นยนต์, AI, บล็อก, วงจร, flowchart, สร้างระบบ) ใน DS · ตามที่ ds-build บันทึกมีแค่ `bot` ที่ตรง → DS gap
- ป้ายหมวด `Tag` และ "ยังไม่ได้เล่น" ใช้ DS `Tag` ได้ (v19) · ชั้นแนะนำ "เห็นชัด" ขึ้นกับ OQ6
- "ผ่าน x/y": y ขึ้นกับชุดด่านของรุ่นโปรแกรม (ดู R8 / OQ12)
- คำบนการ์ด (ชื่อเกม 13 ชื่อ, 6 หมวด, "ยังไม่ได้เล่น", "ผ่าน x/y ด่าน") ยังไม่อยู่ใน brand §7 ทั้ง 3 ภาษา · ชื่อหมวดใน requirement เป็นภาษาอังกฤษ ต้องตัดสินคำไทย/中文 (session หลักลง brand §7 ก่อน crayon)

## R3: หน้าเกม (ก่อนเล่น)

**ทำได้มีเงื่อนไข**
- ชนิดแถบนำทางไม่ระบุ: brand §11.21 ระบุคลังเกมเป็น N3 แต่ไม่ระบุหน้าเกม · ปุ่มกลับระบุว่าไปหน้าคลังเสมอ แต่ถ้าเข้าจาก "เกมแนะนำ" ของหน้าหลัก (app-shell R7/OQ20) ปลายทางกลับต้องตัดสิน → OQ15
- "สถิติดีสุดของฉัน" ระดับเกมหรือระดับด่าน ไม่ระบุ (สถิติตาม R6 เป็นค่าต่อด่าน เช่น เวลา/จำนวนบล็อก) → OQ10
- "เล่นต่อ": นิยามครบ (ด่านแรกที่ยังไม่ผ่าน · ผ่านครบ → ด่านสุดท้าย) · เมื่อเลือกด่านอิสระ (R4) ด่านแรกที่ยังไม่ผ่านอาจอยู่ก่อนด่านที่เพิ่งเล่น ตั้งใจหรือไม่ — รับได้ (ตรงกับ "ไม่ต้องผ่านด่านก่อน") ไม่เปิด OQ
- รายการด่าน: ความยาวไม่ทราบ (OQ13) · ต้องมีแถวรายการด่านพร้อมสถานะ = DS gap
- ทักษะ "ภาพ + คำสั้น ไม่เป็นภาษาบทเรียน" ต้องมีเนื้อหาต่อเกม 3 ภาษา (ทีมเนื้อหา)

## R4: ความยากระดับเดียว · เลือกด่านอิสระ · ด่านแรกสอนวิธีเล่น

**ทำได้มีเงื่อนไข**
- ไม่ขัดกันเอง · ขึ้นกับ OQ6 (ชั้นแนะนำ) และ OQ13 (จำนวนด่าน)
- "ยอมรับว่าเกมของชั้นสูงอาจยากเกินสำหรับเด็กเล็ก": ด่านสอนวิธีเล่นช่วยแค่ด่านแรก · ด่านถัดไปที่ยากเกินจะใช้ใบ้ 3 ขั้น (R6) เป็นทางออกเดียว ไม่มีข้าม (เลือกด่านอื่นได้แทน) → ไม่มีทางตัน (H3 ผ่าน) · ไม่เปิด OQ เพราะผู้ใช้ยอมรับแล้ว
- ด่านสอนวิธีเล่นต้องรองรับ ป.1 ที่อ่านไม่คล่อง (DEC-19 ไม่มีเสียงอ่าน) → ภาพนำตาม R10 · เป็นข้อกำหนดเนื้อหา

## R5: ด่านวันนี้

**ทำได้มีเงื่อนไข** · รายละเอียด `feasibility/R5.md`
- สร้างจากวันที่โดยไม่ใช้เน็ตทำได้ (seed = วันที่) แต่ "ทุกคนได้ด่านเดียวกัน" ต้องให้ตัวสร้างด่าน/คลังด่านหมุนเวียน **คงที่ข้ามรุ่นโปรแกรม** (เพื่อนใช้คนละรุ่นได้) → ข้อกำหนด dev
- ใบ้ขั้น 3 "ทำให้ดู 1 ก้าว" ต้องรู้ทางแก้ → ถ้าสุ่มสร้างด่าน ตัวสร้างต้องคืนทางแก้อ้างอิงและรับรองว่าแก้ได้ · ทางที่ OQ1 แนะนำ (หมุนจากคลังด่านที่เตรียมไว้) ตัดปัญหานี้ และเหมาะกับ 07-priority ที่วางตัวสร้างด่านไว้ขั้นสุดท้าย
- ขอบวันและหน้าจบด่านวันนี้ไม่ระบุ (เขตเวลา, ปุ่ม "ด่านถัดไป" ใช้ไม่ได้กับด่านวันนี้, เป้าเสริม/สถิติของด่านวันนี้สะสมไหม) → OQ11
- "วันที่ผ่านไปย้อนเล่นไม่ได้" บังคับไม่ได้จริงตอนออฟไลน์ (เด็กเปลี่ยนนาฬิกาได้) · ไม่มีอันดับ/รางวัลจึงไม่มีผลเสีย · OQ5 ครอบคลุมเรื่องนาฬิกา

## R6: การเล่น

**ทำได้มีเงื่อนไข (เขียนทับ 2026-11-09)** · รายละเอียด `feasibility/R6.md` (ผลรอบ 2026-11-06 ที่ยังใช้ได้)
- **รอบ 2026-11-09:** ไม่ขัด quiz R3 (item เกม = รันใหม่ไม่จำกัด + ใบ้ 3 ขั้น เหมือนกัน) · "ไม่มีเฉลยแบบแบบฝึก" ไม่ขัดใบ้ขั้น 3 (ทำให้ดูแค่ 1 ก้าว ไม่ใช่เฉลยทั้งหมด · ควรเขียนให้ชัดว่าห้ามแสดงคำตอบเต็ม) · PR-G10 (เงื่อนไขรับเข้าคลัง: แกนไม่ซ้ำ + ด่านสุ่ม/สถิติ/ผลงานอย่างน้อยหนึ่ง) ผ่านทุกเกมด้วยสถิติ (R6) ไม่ต้องแก้
- **ปุ่มควบคุมตำแหน่งเดียวกันทุกเกม:** ทำได้ (ช่องปุ่ม/ใบ้/ออกอยู่ที่เดิมในโซน D และแถบบน) แต่ชุดปุ่มต้องเป็น "ชุดย่อยที่เกมนั้นมี" ไม่ใช่ครบ 4 ปุ่มทุกเกม · G2 ต้องมี "หยุด" (โลกเคลื่อนต่อเนื่อง · WCAG 2.2.2) แต่ไม่มี "ทีละก้าว" · ซ่อนหรือทำปุ่มจาง (disabled) ต้องตัดสิน (OQ19 · H4 สม่ำเสมอ vs ปุ่มหลอก) · ปุ่มออกในหน้าเล่นเป็น N2 (บ้าน + กลับหน้าเกม) อยู่ที่เดิมอยู่แล้ว
- DS gap เดิมเรื่องชุดหน้าเล่นยังอยู่ (quiz OQ63 ใช้ร่วม) ไม่เพิ่ม
- ใบ้ 3 ขั้นแบบเดียวกันทุกเกมใช้ตรง ๆ ไม่ได้กับเกมควบคุมสด (G2) และเกมสอน AI (G4, G5) ("ทำให้ดู 1 ก้าว" ต้องนิยามต่อ world) → ข้อกำหนดเนื้อหา/engine ไม่ใช่ OQ
- สถิติดีสุด: ทิศ "ดีกว่า" (น้อยกว่า/มากกว่า) ต่อสถิติ, ใช้ใบ้แล้วนับไหม, ระดับด่าน/เกม → OQ10
- a11y ที่ตามมาจาก R10 (ไม่ใช่การตัดสินใหม่): เป้าหลักห้ามจำกัดเวลา (WCAG 2.2.1 · เวลาเป็นสถิติเท่านั้น) · โลกที่เคลื่อนต่อเนื่อง (สายพาน G10, ไฟจราจร G11) ต้องหยุดได้ (2.2.2) · กติกาที่ใช้สี (ตะกร้าสี G2, "สีแดง?" G10, ถัง G4) ต้องมีรูปทรง/ป้ายคู่ (1.4.1) · G6 จังหวะดนตรีต้องมีจังหวะแบบภาพ (เสียงไม่เป็นช่องทางเดียว · ห้องคอมอาจปิดเสียง)
- หน้าจบด่าน: "ด่านถัดไป" ที่ด่านสุดท้ายของเกม และที่ด่านวันนี้ ไม่ระบุ → ด่านสุดท้าย: ซ่อน/เปลี่ยนเป็นกลับหน้าเกม (Designer เสนอแล้วถาม) · ด่านวันนี้ → OQ11
