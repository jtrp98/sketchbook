# game-library · Feasibility R8: บันทึก ออฟไลน์ และสถานะระบบ (ruler 2026-11-06)

**ผล R8: ทำได้มีเงื่อนไข** · สรุปอยู่ใน `../feasibility.md` หัวข้อ R8

## ข้อขัด: โหลดความคืบหน้าไม่ได้ ↔ เล่นออฟไลน์ได้ (OQ8)

- กฎ "สถานะ": "โหลดความคืบหน้าจาก cloud ไม่ได้ → ห้ามแสดงเหมือนยังไม่เคยเล่น ให้ 'ลองอีกครั้ง' (แบบ quiz R8)"
- R8: "เล่นได้เมื่อออฟไลน์หลัง login"
- เครื่องเดิม: มีผลในเครื่อง → แสดงจากเครื่องได้ ไม่ชน
- **เครื่องใหม่/บัญชีที่ไม่เคยใช้เครื่องนี้ + ออฟไลน์หรือ cloud ล้ม:** ไม่มีผลในเครื่อง โหลดจาก cloud ไม่ได้ → ถ้าทำตามกฎสถานะ เด็กเห็นแต่ "ลองอีกครั้ง" และเล่นไม่ได้ (ขัด R8) · ถ้าให้เล่น การ์ดต้องแสดงอะไรแทน "ยังไม่ได้เล่น"/"ผ่าน x/y"
- บทเรียน (quiz) ไม่ชน เพราะด่านบทเรียนล็อกตามลำดับ (ต้องรู้ผล) · คลังเกมไม่ล็อก จึงเล่นได้โดยไม่ต้องรู้ผลเดิม และ log เพิ่มอย่างเดียวรวมทีหลังได้ไม่ชน
- ช่วง login ต้องออนไลน์ (app-shell R6) ทำให้กรณีนี้เกิดน้อย (เน็ตหลุดหลัง login ก่อนดึงผล หรือ cloud ผลล้ม) แต่เกิดได้

## ช่องทางอัปเดตด่าน (OQ12)

- R8 "เกมทั้งหมดมากับตัวติดตั้ง" vs quiz R2 "เนื้อหาดึงจาก cloud" · edge case "ทีมแก้/ลบด่านหลังเด็กผ่าน" เกิดได้เฉพาะเมื่อมีทางส่งด่านใหม่
- ถ้ามากับรุ่นโปรแกรมเท่านั้น: y ของ "ผ่าน x/y" ต่างกันระหว่างเครื่องที่อัปเดตไม่พร้อมกัน · ผลจากเครื่องรุ่นใหม่กว่าอ้าง ID ด่านที่เครื่องรุ่นเก่าไม่มี → ต้องไม่นับใน x และไม่ error (ข้อกำหนด dev · ควรระบุใน R8)
- ถ้าดึงจาก cloud + แคช: ต้องเพิ่มสถานะแบบ quiz R8 ("ต้องใช้โปรแกรมรุ่นใหม่", ไม่มีแคชตอนออฟไลน์)

## สถานะที่ขาด (ควรเพิ่มในกฎ "สถานะ")

- session หมดอายุกลางด่าน: เล่นต่อได้ ผลเขียนลงเครื่อง ขอ login ตอนส่งขึ้น cloud ห้ามเด้งออกจากด่าน (ตามแบบ quiz R8)
- ไฟล์เกมในเครื่องเสีย/หาย (เกมมากับตัวติดตั้ง): "ลองใหม่" ไม่ช่วย → ข้อความให้ติดตั้งโปรแกรมใหม่/บอกครู + รหัส error (app-shell กฎข้อความ error มีรหัส)
- ผลจากเครื่องรุ่นใหม่กว่า (ด้านบน)

## sync และ my-work

- log เพิ่มอย่างเดียว + ID ฝั่ง client (แบบ quiz R5) → ส่งซ้ำไม่เกิดแถวซ้ำ · สถิติดีสุด = ค่าดีสุดจาก log · เป้าเสริม = union → รวมข้ามเครื่องได้ ✔
- ไม่ใช้ "ฉบับใหม่กว่าชนะ" (my-work R8) ✔ ถูกต้อง เพราะไม่มีผลงานให้แทนที่
- my-work R7 (ความหมายสถานะ sync) ยังพูดถึงงาน Lab เท่านั้น · ผลเกมค้าง sync ต้องทำให้แถบแสดง "ออฟไลน์/ไม่สำเร็จ" เหมือนผลบทเรียน → session หลักแก้ถ้อยคำ my-work R7 (ไม่ใช่ OQ)
- ปริมาณ log: เล่นซ้ำไม่จำกัด + ด่านวันนี้เล่นได้ทั้งวัน → log ต่อการเล่นที่จบ (R7 ไม่เก็บด่านที่ออกกลางทาง) ไม่น่ากังวลในระดับ UI · dev ประเมินขนาด
