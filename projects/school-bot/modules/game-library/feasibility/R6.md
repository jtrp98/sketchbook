## สถิติดีสุด (OQ10)

- ต่อเกมต้องระบุ: สถิติชื่ออะไร (เวลา, จำนวนบล็อก, จำนวนการเคลื่อน, ภาพที่ใช้สอน ฯลฯ), ทิศดีกว่า (น้อย/มาก), เก็บต่อด่านหรือรวม · ข้อกำหนดเนื้อหา (ตาราง 13 เกม)
- ที่ต้องให้ผู้ใช้ตัดสิน: หน้าเกม (R3) แสดงสถิติระดับไหน · ใช้ใบ้ขั้น 3 แล้วสถิตินับไหม (quiz R3 กำหนดว่าใบ้ไม่กระทบดาว แต่ไม่มีข้อเทียบสำหรับสถิติ) → OQ10
- ผ่านไม่ได้ = ไม่มีสถิติ (สถิติเก็บเฉพาะรอบที่ผ่าน) · Proposed ให้ระบุใน R6

## หน้าจบด่าน

- "ด่านถัดไป" ที่ด่านสุดท้ายของเกม: ไม่มีด่านถัดไป → Designer เสนอ (เช่น ซ่อน/กลับหน้าเกม) แล้วถามผู้ใช้
- "ด่านถัดไป" ของด่านวันนี้ → OQ11
- รอบที่ไม่ผ่าน: ปุ่ม "เล่นอีกครั้ง" เป็นหลัก · ด่านถัดไปยังกดได้ (R4 เลือกอิสระ) ✔
- "ผ่านไว้แล้ว" เมื่อเล่นซ้ำแล้วรอบนี้ไม่ผ่าน: ใช้แบบ quiz edge case (สถานะคงผ่าน) · ควรระบุใน R6
