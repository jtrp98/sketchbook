# game-library (เมนู "เกม"): Requirements (จาก role 1)

> แหล่ง: ผู้ใช้ตอบใน `/pencil` 2026-11-06 (session หลัก) · แนวทางจากข้อเสนอ `../../system/game-platform/` (Proposed · ผู้ใช้อนุมัติแนวทาง) · ที่นี่ทับข้อเสนอเมื่อขัดกัน · ป้ายหลักฐานดู `../../context.md`

## เป้าหมาย
นักเรียน ป.1–6 เลือกเล่นเกมฝึกทักษะ (หุ่นยนต์, AI, บล็อก, วงจร, flowchart, สร้างระบบ) ได้อิสระจากเมนู "เกม" ไม่ต้องเรียนตามบทเรียนก่อน ไม่รู้สึกเหมือนทำแบบทดสอบ และอยากกลับมาเล่นซ้ำ (ด่านวันนี้, สถิติดีสุดของตัวเอง, เป้าเสริม) · เกมใช้ engine เดียวกับด่านเกมในบทเรียน (quiz R3)

## Requirements
- R1 (M): **หน้าคลังเกม** เข้าจากเมนู "เกม" (sidebar รายการที่ 3 · `app-shell` R7) เป็นหน้า N3 มี sidebar · **สูงสุด 13 เกม** = G1–G11, G13, G14 · **แสดงเฉพาะเกมที่พร้อม** จำนวนแปรผันได้ ไม่มีการ์ดว่าง/"เร็ว ๆ นี้" (OQ7 · 2026-11-06) ตาม `../../system/game-platform/03-game-library.md` (**ตัด G12 หุ่นในฝัน** · ผู้ใช้ 2026-11-06) · **เห็นทุกเกมเสมอ** เกมที่ช่วงชั้นแนะนำครอบชั้นของนักเรียนอยู่ก่อน · ช่วงที่ไม่มีเกมตรง → เกมของช่วงที่ใกล้ที่สุดขึ้นก่อน แล้วตามด้วยเกมอื่น · กรองตาม 6 หมวด (Robot Adventure, AI Playground, Block Coding, Circuit Lab, Flowchart & Logic, Creative Workshop · 1 เกมอยู่ได้หลายหมวด) · **ไม่ล็อกตามบทเรียนหรือชั้น** · ชั้นของนักเรียนมาจากโปรไฟล์ตอน login (`quiz` R7 · ไม่รู้ชั้น → OQ3)
- R2 (M): **การ์ดเกม** (DS `Card` + `sb-card-media` · ตัวกรองหมวด = DS `FilterChip` · ไอคอนทักษะ `bot`/`brain`/`blocks`/`zap`/`workflow`/`cog`): ภาพเกม (**ภาพจากฉากเกมจริงที่ engine วาด** · ระหว่างยังไม่มีใช้ไอคอนหมวดแทน · ผู้ใช้ 2026-11-06) · ชื่อ · ไอคอนทักษะ 1–2 ตัว · ป้ายหมวด (DS `Tag`) · ชั้นแนะนำเป็น**ช่วง 2 ชั้น** (ป.1–2 / ป.3–4 / ป.5–6 · ทีมกำหนดต่อเกม · OQ6) เห็นชัด · ความคืบหน้า "ผ่าน x/y ด่าน" · **ยังไม่เคยเล่น = "ยังไม่ได้เล่น" ไม่แสดงตัวเลข** (OQ2 · แบบเดียวกับ quiz R12) · ทั้งการ์ดกดได้ (เป้ากด ≥ 44)
- R3 (M): **หน้าเกม (ก่อนเล่น):** กดการ์ดแล้วมาหน้านี้ก่อน · ทักษะที่ฝึก (ภาพ + คำสั้น ไม่เป็นภาษาบทเรียน) · สถิติดีสุดของฉัน · รายการด่านพร้อมสถานะ (ผ่าน/ยังไม่ผ่าน) · ปุ่ม **"เล่นต่อ"** (ด่านแรกที่ยังไม่ผ่าน · ผ่านครบแล้ว → ด่านสุดท้าย) และ **"ด่านวันนี้"** (R5) · สถิติดีสุด**เก็บต่อด่าน** แสดงในแถวรายการด่าน หัวหน้าเกมแสดงแค่ "ผ่าน x/y" (OQ10) · **หน้าเกมเป็น N3 มี sidebar highlight "เกม" · ปุ่มกลับไปหน้าคลังเสมอ** (OQ15) · ด่าน 10–20 ด่านต่อเกม รายการเดียวเลื่อนในแผง (OQ13)
- R4 (M): **ความยากและด่าน:** แต่ละเกมมี**ความยากระดับเดียว** (ช่วงชั้นแนะนำของเกม ตามตารางที่ทีมส่ง 13 เกม · ไม่มีตัวเลือก Basic–Expert) · ด่านที่ทีมทำไว้เรียงจากง่ายไปยาก · **เลือกด่านได้อิสระ** ไม่ต้องผ่านด่านก่อนหน้า · **ด่านแรกของทุกเกมเป็นด่านสอนวิธีเล่นที่ง่ายที่สุดของเกมนั้น** (ผู้ใช้ 2026-11-06 · ยอมรับว่าเกมของชั้นสูงอาจยากเกินสำหรับเด็กเล็ก)
- R5 (M): **ด่านวันนี้ (ด่านสุ่มรายวัน):** ทุกเกมมี · ทุกคนได้ด่านเดียวกันในวันเดียวกัน (สร้างจากวันที่ · ไม่ต้องใช้เน็ต) · เล่นซ้ำได้ตลอดวัน · วันที่ผ่านไปย้อนเล่นไม่ได้ · **ขอบวันตามเวลาประเทศไทย** ไม่ขึ้นกับเขตเวลาเครื่อง · หน้าจบมี "เล่นอีกครั้ง" + กลับหน้าเกม (ไม่มี "ด่านถัดไป") · เป้าเสริม/สถิติเป็นของวันนั้น ไม่รวมสถิติของเกม (OQ11) · ไม่นับใน "ผ่าน x/y ด่าน" · เกมที่สร้างด่านสุ่มไม่ได้ → OQ1
- R6 (M): **การเล่น:** engine/กติกาตาม `../../system/game-platform/02-engines.md` · **จำลองบนจออย่างเดียว ไม่ต่อหุ่นหรือบอร์ดจริง** (ไม่มีหน้าเชื่อมหุ่น) · **ใบ้ 3 ขั้น** (ชี้จุด → บอกแนวคิด → ทำให้ดู 1 ก้าว) + รันใหม่ไม่จำกัด เหมือน item เกมในบทเรียน (`quiz` R3) · **ไม่มีดาว** · ด่านผ่านเมื่อถึงเป้าหลัก (ระบบตรวจได้) · เป้าเสริมแสดงด้วย DS `GoalList` เก็บแบบสะสม · **สถิติดีสุดเทียบกับตัวเองเท่านั้น** (ต่อด่าน · ใช้ใบ้ไม่กระทบสถิติ · OQ10) (ค่าที่เก็บตามเกม เช่น เวลา, จำนวนบล็อก, จำนวนการเคลื่อน) · หน้าจบด่านบอก ผ่าน/ยัง + เป้าเสริมที่ทำได้ใหม่ + สถิติใหม่ (ถ้ามี) + ปุ่ม "ด่านถัดไป" / "เล่นอีกครั้ง" / กลับหน้าเกม
- R7 (M): **ออกกลางด่าน:** ยังไม่ได้ทำอะไรในด่าน = ออกทันที · **แก้อะไรไปแล้ว = ถามยืนยัน** (OQ9 · 2026-11-06 · แทน "ไม่ถามยืนยัน") · ด่านที่กำลังเล่นเริ่มใหม่ครั้งหน้า · เก็บเฉพาะผลของด่านที่จบแล้ว
- R8 (M): **บันทึกและออฟไลน์:** เกมทั้งหมดมากับตัวติดตั้ง เล่นได้เมื่อออฟไลน์หลัง login · ผล (ด่านที่ผ่าน, เป้าเสริม, สถิติดีสุด) เขียนลงเครื่องทันทีแล้ว sync ขึ้น cloud School Bot ผูกบัญชีเมื่อออนไลน์ (แบบ log เหมือน `quiz` R5) · รายการ "เกม" ใน sidebar ไม่หายตอนออฟไลน์ (`app-shell` OQ22) · **โหลดผลเดิมไม่ได้ (เครื่องใหม่ขณะออฟไลน์/cloud ล้ม): เล่นได้ตามปกติ** การ์ด/หน้าเกมแสดง "ยังโหลดผลเดิมไม่ได้" + ลองอีกครั้งแทนความคืบหน้า · ผลใหม่เข้าคิวแล้วรวมกับผลเดิมตอน sync (OQ8)
- R9 (M): **ความเป็นส่วนตัวและขอบเขตข้อมูล:** ผลอยู่กับเจ้าของบัญชีเท่านั้น · **ไม่แชร์ ไม่มีตารางอันดับ** · **ครูไม่เห็น** (เว็บครูไม่มีข้อมูลคลังเกม) · ไม่ส่ง SchoolBright (DEC-18) · ไม่ขึ้นใน "งานล่าสุด" ของหน้าหลัก (`app-shell` OQ24)
- R10 (M): **ภาษาและการเข้าถึง:** UI และเนื้อหาเกม (ชื่อเกม, คำสั่ง, ใบ้, ชื่อบล็อก) 3 ภาษา ไทย / EN / 中文 เผื่อยาวขึ้น 40% · UI เดียว ป.1–6 (DEC-06) · WCAG 2.2 AA + เกณฑ์เด็ก · ภาพนำ ข้อความน้อย · การลากต้องมีทางเลือกที่ไม่ต้องลาก (WCAG 2.5.7) · จอยสติ๊กมีคีย์บอร์ดแทนได้ (WCAG 2.1.1) · ค่าและ component จาก DS เท่านั้น
- R11 (M): **มาสคอต:** ใช้ในใบ้และตอนผ่านด่านตาม `../../brand.md` §8 (10 ท่าเท่านั้น · DEC-30) · ท่าที่ใช้ให้ Designer เสนอแล้วถามผู้ใช้
- R13 (M): **"เกมแนะนำ" บนหน้าหลัก** (การ์ดข้าง "เรียนต่อ" · `app-shell` R7/OQ20): แนะนำเกมที่ใช้ engine เดียวกับด่านบทเรียนล่าสุด · ยังไม่เคยเรียน → เกมแรกที่ช่วงชั้นแนะนำตรงชั้น · กดแล้วไปหน้าเกม (R3) และ sidebar highlight "เกม" (OQ14 · 2026-11-06)
- R12 (Future): **นอกรอบแรก:** ตารางอันดับเทียบกับคนอื่น (ผู้ใช้ 2026-11-06: อนาคตจะมี → OQ4) · โหมดสร้างด่านเอง · โหมดอิสระ · แชร์ผลงาน · ของรางวัลจากบทเรียน (สกิน/ชิ้นส่วน) · ต่อหุ่นจริง (ต้องตอบ arm-lab OQ1 เรื่อง Pi อ่านตำแหน่ง) · G12 หุ่นในฝัน

## กฎ/Logic
- **UJ-G1 เล่นเกม:** หน้าหลัก → เกม (หน้าคลัง) → กรองหมวด (ถ้าต้องการ) → การ์ด → หน้าเกม → เล่นต่อ / เลือกด่าน / ด่านวันนี้ → เล่น → หน้าจบด่าน → ด่านถัดไป / เล่นอีกครั้ง / หน้าเกม
- **sidebar:** หน้าคลังเกม highlight "เกม" · หน้าเล่นเกมเป็น N2 ไม่มี sidebar (ปุ่ม home + ปุ่มกลับหน้าเกม) · เกมในด่านบทเรียน highlight "บทเรียน" (`app-shell` R7)
- **"ผ่าน x/y ด่าน"** นับเฉพาะด่านที่ทีมทำไว้ ไม่นับด่านวันนี้
- **ลำดับการ์ด:** กลุ่มที่ชั้นแนะนำตรงชั้นก่อน · ภายในกลุ่มเรียงตามลำดับที่ทีมกำหนด (ไม่เรียงตามการเล่นล่าสุด · Proposed)
- **ผลที่เก็บต่อการเล่น:** นักเรียน, เกม, ด่าน (ID คงที่ หรือวันที่ของด่านวันนี้), ผ่าน/ไม่ผ่าน, เป้าเสริมที่ทำได้, ค่าสถิติ, เวลาที่เล่น · แก้ไขไม่ได้ (log)
- **สถานะ:** กำลังโหลดหน้าคลัง/ความคืบหน้า (DS `Skeleton` v22) · โหลดความคืบหน้าจาก cloud ไม่ได้ → ห้ามแสดงเหมือนยังไม่เคยเล่น แสดง "ยังโหลดผลเดิมไม่ได้" + ลองอีกครั้ง **แต่ยังเล่นได้** (R8 · OQ8) · โหลดเนื้อหาเกมไม่สำเร็จ → ข้อความ + ลองใหม่ · ออฟไลน์/กำลัง sync แสดงที่แถบหน้าต่าง (`app-shell`)
- ถ้อยคำภาษาเด็ก ไม่ลงโทษความผิดพลาด ไม่ใช้คำบทเรียน ("แบบทดสอบ", "คะแนน") · ตาราง "คำที่ตัดสินแล้ว" `../../brand.md` §7

## การตัดสินใจที่ผูกกับ module (ผู้ใช้ 2026-11-06 · `/pencil`)
- เพิ่ม (หลัง ruler 2026-11-06): ช่วงชั้นแนะนำ 2 ชั้น · แสดงเฉพาะเกมที่พร้อม · โหลดผลเดิมไม่ได้ยังเล่นได้ · ออกกลางด่านถามเมื่อแก้แล้ว
- ครูไม่เห็นการเล่นในคลังเกม · ไม่มีของรางวัลจากบทเรียนในรอบแรก · ไม่แชร์ · เทียบสถิติกับตัวเอง · โหมดรอบแรก = เล่นตามด่าน + ด่านวันนี้ · เกมละความยากระดับเดียว · เลือกด่านอิสระ · ออกกลางด่านเก็บเฉพาะด่านที่จบ (ถามยืนยันเมื่อแก้แล้ว · OQ9) · จำลองบนจออย่างเดียว · ใบ้ 3 ขั้น · ด่านวันนี้เหมือนกันทุกคน · 3 ภาษา · ตัด G12 · ยังไม่มี canvas (ถามก่อนออกแบบ)

## Edge cases
- เด็กชั้นเล็กเปิดเกมของชั้นสูง: เล่นได้ ด่านแรกเป็นด่านสอนวิธีเล่น · ชั้นแนะนำเห็นชัดบนการ์ดและหน้าเกม (R4)
- เน็ตหลุดระหว่างเล่น: เล่นต่อได้ ผลเข้าคิว sync (R8)
- เปลี่ยนเครื่อง: เห็นความคืบหน้าเดิมหลัง sync · ผลที่ยังไม่ sync จากเครื่องเก่าอยู่ในคิวของเครื่องนั้น
- เครื่องห้องคอมใช้ร่วม: ผลแยกตามบัญชี · logout ตอนมีผลค้าง sync ต้องเตือน (แบบ quiz R5)
- ข้ามเที่ยงคืนระหว่างเล่นด่านวันนี้: เล่นด่านเดิมจนจบ ผลนับเป็นด่านของวันที่เริ่ม (Proposed)
- นาฬิกาเครื่องผิด: ด่านวันนี้อาจไม่ตรงกับเพื่อน → OQ5
- ด่านใหม่/ด่านที่ทีมแก้มาถึงเครื่องทางไหน → OQ12 (รอถาม dev)
- ทีมแก้/ลบด่านหลังเด็กผ่านแล้ว: ผลเดิมเก็บไว้ · y ใน "ผ่าน x/y" เปลี่ยนตามชุดด่านปัจจุบัน (Proposed)
- ไม่รู้ชั้นของนักเรียน → OQ3

คำถามที่ยังไม่ตัดสินอยู่ใน `oq.md`
