# Block Lab · Feasibility R11: โครงหน้า พื้นที่เล่นอิสระ และการจัดการงาน

**ผล: ทำได้มีเงื่อนไข** (2026-10-21 · ruler) · ส่วนอื่นนอกจาก §ผลตรวจ ruler เป็นข้อมูลอ้างอิงจาก Architect ระบบเก่า (00_START_HERE v3 §Canvas C · DEL-08)

## ผลตรวจ ruler (2026-10-21)
โครงหน้าชัด ทำได้ มีเงื่อนไข:
- **พื้นที่ 1440×856 ต้องจุของ 7 อย่างโดยไม่เลื่อนทั้งหน้า:** ชื่องาน+สถานะบันทึก+งานใหม่/งานของฉัน+เริ่ม/หยุด · แผงบล็อก · พื้นที่ต่อบล็อก · แผงโค้ด · แท็บตัวจำลอง/stage (ต้องใหญ่พอสำหรับ breadboard) · แผงข้อความ · แถบล่าง → ต้องตัดสินว่าอะไรย่อ/ซ่อนได้ (แผงโค้ด แผงข้อความ) → OQ33
- **ปุ่มหยุดซ้ำ 2 ที่** → OQ31 · **งานใหม่/งานของฉันระหว่างจำลองหรือกำลังส่ง** ต้องหยุดจำลองก่อนหรือกันไว้ + leave guard → OQ32 (ตำแหน่งปุ่ม OQ7)
- **ST-10 (ว่าง) ขึ้นกับว่าวาง setup/loop ไว้ให้หรือไม่** → OQ26
- **สถานะบันทึกตัวหนังสือเขียวใต้ชื่องาน:** มีเฉพาะ "บันทึกแล้ว" / "· มีแก้ไขใหม่" (my-work EDIT-09) · เป็นตัวหนังสือจึงไม่พึ่งสีอย่างเดียว แต่ contrast ของตัวหนังสือสีเขียวต้องให้ highlighter ตรวจ
- **ข้อกำหนดก่อน Canvas C:** แถบหน้าต่างต้องแก้ตาม CR-10 และสำเนาจาก B (ไม่ block การตรวจ logic)
- OQ5 (รูปแบบไฟล์ Block) ไม่ block ออกแบบ แต่ต้องตอบก่อน dev ทำ export/import (R10 ของ my-work)

## โครง Canvas C (จาก START_HERE Architect → Designer)
1. SCR-16 พื้นที่ต่อบล็อก + ดูโค้ด · แท็บ SCR-17 ตัวจำลอง / SCR-18 stage · SCR-26 แผงข้อความอยู่ใต้พื้นที่แท็บ เห็นทั้งสองแท็บ · แถบล่าง หยุดทั้งหมด (ซ้าย) / ส่งลงบอร์ด (ขวา) · **ไม่มีแถบภารกิจ** (DEC-25) · พื้นที่ 1440×856 (CR-09) · มี งานใหม่ (Ctrl+N) + งานของฉัน (CR-07)
2. จำลอง: กดเริ่มครั้งเดียว ตัวจำลอง + stage รันพร้อมกัน · แก้ระหว่างจำลอง → หยุดอัตโนมัติ (ARC-I28)
3. ตัวจำลอง: งานใหม่ = Uno + breadboard เปล่า (ST-40) · ลากอุปกรณ์ ต่อสาย ย้าย หมุน ลบ เลิกทำ · ชุดอุปกรณ์ ARC-I09 · วงจรบันทึกกับงาน · ปุ่มกด/potentiometer โต้ตอบได้ด้วยเมาส์และคีย์บอร์ด (ST-41)
4. อุปกรณ์เสีย (ST-29): หยุดจำลอง · นิ่ง ไม่กะพริบ ไม่ระเบิด · สาเหตุ + วิธีแก้ภาษาเด็ก · "เปลี่ยนอุปกรณ์ใหม่"
5. ส่งลงบอร์ด: ST-46 → ST-32 → ST-33 (+ ST-45)
6. มาสคอต: ตัวละคร stage + ช่วงเวลาสำคัญ · 10 ท่าเท่านั้น · มีข้อความกำกับเสมอ · ไม่ใช้บนเว็บครู
7. แถบหน้าต่าง (CR-08): ชิปอุปกรณ์เฉพาะใน lab (Block = Uno) · รับ prop ชนิด/ชื่อ/พอร์ต · ST-39 · **ต้องทำตาม CR-10 (ต่ำกว่า z-stop) ก่อนใส่ใน Canvas C**
8. CR-11 (Arm Lab) ไม่เกี่ยวกับ Block Lab
