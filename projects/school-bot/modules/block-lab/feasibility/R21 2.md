## (1) เมนูบล็อก/hat/พื้นที่ว่าง: ความขัดกับ requirement เดิม

- **X53 · ทำสำเนา/วาง/ใส่กระเป๋าของ hat ชน R2:** R21 (1) ให้ทำสำเนา "ทั้งคำสั่ง ค่า และ hat" แต่ R2 กำหนด setup/loop อย่างละ 1 บล็อกต่อโปรแกรม (BUG-15) และชื่อ hat ฟังก์ชันห้ามซ้ำ · "วางทั้งหมดจากกระเป๋า" วางหลายก้อนพร้อมกัน เสี่ยงซ้ำเช่นกัน · **Proposed (OQ214 ก):** รายการ ทำสำเนา/ใส่กระเป๋า/คัดลอก ของ setup/loop = `aria-disabled` + บอกเหตุผล "มีได้อย่างละ 1" (brand D-03) · hat ฟังก์ชัน: ทำสำเนาได้ ตั้งชื่ออัตโนมัติ "ฟังก์ชัน2" (ชื่อห้ามซ้ำตาม R2/OQ182 อ้างด้วย id) · วางจากกระเป๋าที่มี setup/loop อยู่แล้ว = ข้ามตัวนั้นและบอกผู้ใช้ (toast)
- **X54 · "ปิดใช้บล็อก" ซ้อนกับสถานะลายเทาเดิมของ R2 (4) (OQ101):** R2 มีบล็อกลายเทา+ขอบประ+ไอคอน สำหรับ "ไม่ได้ต่อใต้หัว/ในช่อง" (คำนวณจากตำแหน่ง · ไม่นับเป็นปัญหา R17 · ข้ามตอนจำลอง/ส่ง/แปลง) · R21 เพิ่มสถานะ "ผู้ใช้สั่งปิดใช้" ที่หน้าตาลายเทาเหมือนกัน (Mixly) → เด็กแยกไม่ออกว่าทำไมเทา (H1) · **Proposed (OQ214 ข):** เก็บเป็น 2 สถานะ (flag `disabled` ที่ผู้ใช้ตั้ง · `orphan` คำนวณ) · ลายเทา+ขอบประเหมือนกันได้ แต่ aria-label/tooltip บอกเหตุผลต่างกัน ("ปิดใช้อยู่" / "ยังไม่ได้ต่อ") · รายการเมนูของบล็อกกำพร้า: "ปิดใช้บล็อก" = `aria-disabled` + บอก "ยังไม่ได้ต่อ ไม่ทำงานอยู่แล้ว" · บล็อกลูกในตัวแม่ที่ปิดใช้ = เทาตาม (ไม่เก็บ flag ที่ลูก) · บล็อกที่ต่อท้ายตัวที่ปิดใช้ **ไม่ปิดตาม** (ตรง "ไม่รวมบล็อกที่ต่อต่อท้าย" ของข้อทำสำเนา · ข้ามเฉพาะตัวที่ปิด)
- **X55 · กล่องเฟือง: "ไม่มีเมนู" ขัดกับ "กดค้าง = เมนูเดียวกัน" และ OQ184:** R21 (4) บอกไม่มีเมนูคลิกขวา แต่อ้าง OQ184 ว่ากดค้างบล็อกที่วางแล้ว = เมนู "ลบค่านี้" · (5) บอกจอสัมผัสกดค้างคือเมนูเดียวกับคลิกขวา · ผลคือเมาส์คลิกขวาไม่มีอะไร แต่นิ้วกดค้างมีเมนู 1 รายการ (3.2.4 ความสม่ำเสมอ) · **Proposed (OQ215 ค):** รับความต่างนี้ไว้และเขียน R21 (4) ว่า "ไม่มีเมนู **ยกเว้น** เมนู 'ลบค่านี้' จากกดค้าง/คีย์บอร์ดตาม OQ184 (เป็นทางสำรองไม่ลาก 2.5.7 ไม่ใช่เมนูแบบ Mixly)" · ถ้าผู้ใช้ไม่ต้องการ ต้องเลือกทางสำรอง 2.5.7 อื่นแทน
- **X56 · "คัดลอก/วางข้ามแท็บ" ไม่มีความหมายใน Block Lab:** tab ของ R19 คือโหมด บล็อก | โค้ด ไม่ใช่งานหลายชิ้น (1 หน้าต่าง = 1 งาน) · Mixly "ข้ามแท็บ" = ข้ามโปรเจกต์ที่เปิดพร้อมกัน · OQ211 Proposed (ก) "กระเป๋าเก็บกับงาน" ทำให้นำบล็อกไปงานอื่นไม่ได้ (ขัดจุดประสงค์) แล้ว (ข) "คลิปบอร์ดข้ามงาน" ก็ซ้อนกับกระเป๋า = 2 กลไกหน้าตาคล้ายกัน เด็ก ป.3 งง (H4/H6) · **Proposed ใหม่ (OQ211 ก/ข):** เหลือ **กระเป๋าอย่างเดียว** (ใช้แทน "คัดลอก/วางข้ามแท็บ") · เก็บต่อบัญชีในเครื่อง ไม่ขึ้น cloud และล้างตอนออกจากระบบ (กันของเด็กคนหนึ่งโผล่ให้อีกคนบนเครื่องโรงเรียนที่ใช้ร่วมกัน · ไม่ต้องแก้ my-work) · ถ้าผู้ใช้ต้องการเหมือน Mixly ทั้งสองรายการ ต้องบอกว่า "แท็บ" คืออะไร (ผู้ใช้ตัดสิน)
- **X57 · R17 รายการตรวจฟังก์ชัน (X37) ไม่ครอบ 3 กรณีใหม่:** เรียกฟังก์ชันที่ hat ถูกปิดใช้ · ช่องค่า/เงื่อนไขที่มีบล็อกที่ปิดใช้ (ช่องว่างจริง → `if ()` ไม่ใช่ C++) · hat ถูกลบแล้วมี "เรียก" ค้าง (ตรง X37 "เรียกไม่พบ" อยู่แล้ว) · **Proposed (OQ214 ค):** ดูหัวข้อ (2)
- **ลบ N บล็อก "ทันทีไม่ถามยืนยัน" (H5):** ยอมรับได้เพราะเลิกทำทั้งชุด 1 ขั้น (R2 60 ขั้น) แต่บนจอสัมผัสกดค้างพลาดแล้วลบ hat ทั้งโปรแกรมได้ในแตะเดียว → **เงื่อนไข:** ลบแล้วต้องมี toast "เลิกทำ" (brand §11.9 มีรูปแบบอยู่แล้ว) · ลบ hat ที่มีลูก ≥ 1 แสดงจำนวนในชื่อรายการ ("ลบ 12 บล็อก") ตามที่ R21 ระบุแล้ว
- **X58 · "ค้นหาบล็อก" มุมขวาบนอาจชนที่จับแผงขวา/ตัวบอก "กำลังจำลอง" (R10 · OQ113):** D1 วางที่จับ ▶ และตัวบอกที่มุมขวาบนของพื้นที่ · **ยังไม่ได้ตรวจ layout จริง** → ให้ `crayon` ยืนยัน · ค้นหาครอบคลุมอะไร (ข้อความบล็อก 3 ภาษา · ค่าในช่อง · คอมเมนต์) และมี Esc/โฟกัสกลับ ดู OQ216

## (2) ผลต่อการจำลองและการออกโค้ด C++

| ฟีเจอร์ | จำลอง | โค้ด C++ | เงื่อนไข/ความเสี่ยง |
|---|---|---|---|
| ปิดใช้ (คำสั่ง) | ข้ามเฉพาะตัวนั้น + ลูกข้างใน · ตัวต่อท้ายทำงานต่อ | ไม่ออกบรรทัดของตัวนั้น/ลูก · ไม่ออก `#include`/ประกาศอุปกรณ์ที่ใช้เฉพาะบล็อกที่ปิด (คำนวณจากบล็อกที่ใช้งานเท่านั้น) | R17 ไม่นับเป็นปัญหา (ตรง R2 (4)) · อุปกรณ์ที่ใช้เฉพาะบล็อกปิดใช้ต้องไม่ติดเตือนข้อ (1)/(2) |
| ปิดใช้ (ค่า/เงื่อนไขที่เสียบในช่อง) | ช่องกลายเป็นว่าง | **ช่องว่าง = `x = ;` / `if () {}` compile ไม่ผ่าน** | ต้องเลือกหนึ่ง: ช่องว่างใช้ R17/R2 กฎเดิม (บล็อกแม่ถูกข้ามพร้อมเตือนเหลือง) · **Proposed:** แม่ที่มีช่องบังคับว่างเพราะลูกปิดใช้ = ข้ามทั้งแม่ + ป้ายเหลือง "ช่องว่าง" (ไม่ปิดกั้นส่ง) |
| ปิดใช้ hat setup/loop | ไม่จำลองส่วนนั้น | ต้องยังออก `void setup(){}`/`void loop(){}` เปล่า ไม่งั้น link error บน Arduino | ไม่ใช่ error ของเด็ก ห้ามโผล่เป็นข้อความ compile |
| ปิดใช้ hat ฟังก์ชัน | "เรียก" ที่ชี้ไปตัวที่ปิด = ข้ามพร้อมเตือน | ไม่ออกฟังก์ชัน → ต้องไม่ออกบรรทัดเรียก (undefined reference) | **Proposed:** เพิ่มข้อ R17 "เรียกฟังก์ชันที่ปิดใช้อยู่" (ป้ายเหลือง ไม่ปิดกั้นส่ง) · ฟังก์ชันที่คืนค่าแล้วถูกปิด → ช่องที่รับค่าว่าง ใช้กฎแถวบน |
| ย่อบล็อก | ไม่มีผล (ทำงานตามปกติ) | ไม่มีผล | **ห้ามซ่อนปัญหา (H1/H9):** ป้ายเตือน/บล็อกกำพร้า/"ชนิดไม่ตรง"/ไฮไลต์ตอนจำลองต้องโผล่ที่แถบย่อ · R17 "กดรายการแล้วพาไป" ต้องขยายบล็อกที่ย่ออัตโนมัติ · แถบย่อใช้คำของบล็อกจริงตัดด้วย … มี `aria-label` ข้อความเต็ม (OQ212) |
| คอมเมนต์ | ไม่มีผล | `//` เหนือบล็อก (ตามระดับเยื้อง) | (ก) ข้อความหลายบรรทัด → `//` ทุกบรรทัด (ห้ามใช้บรรทัดเดียวยาว) (ข) **ข้อความที่ลงท้ายด้วย `\` ต่อบรรทัดถัดไปเข้าคอมเมนต์ทำให้กลืนโค้ดจริง** → ตัด/แทนที่ท้ายบรรทัด (ค) คอมเมนต์บนบล็อกค่า (ที่เสียบในนิพจน์) ย้ายขึ้นเหนือคำสั่งที่ครอบ ไม่แทรกกลางบรรทัด (ง) บรรทัดคอมเมนต์ทำให้เลขบรรทัดเลื่อน → การชี้ error compile กลับไปบล็อก (R3/H9) ต้องใช้เครื่องหมายอ้างบล็อก ไม่ใช่เลขบรรทัดเปล่า ๆ (จ) เป็นข้อความอิสระของเด็ก = ข้อมูลใหม่บน cloud/.ini (my-work R11 เท่าที่จำเป็น) → จำกัดความยาว ≈ 200 ตัว |
| จัดเรียงบล็อก | ไม่มีผล | ลำดับการออกโค้ด**ห้ามเปลี่ยนตามตำแหน่ง**ที่จัดใหม่ (เรียงตาม hat คงที่) | เลิกทำ 1 ขั้น |
| กระเป๋า/สำเนา/วางทั้งหมด | ไม่มีผล | บล็อกที่วางแล้วเป็นกำพร้า (เทา) จนกว่าจะต่อ · ต้องไม่ซ้ำ hat (X53) · อ้างอุปกรณ์/ตัวแปร/ฟังก์ชันด้วย id: วางข้ามงานแล้ว id ไม่มี = ช่องว่าง/บล็อกกำพร้าตาม R16/X37 | ต้องบอกชัด ("อุปกรณ์ของบล็อกนี้ไม่มีในงานนี้") |

**my-work รับสถานะเพิ่ม (ขยาย X26):** ต่อบล็อก = `disabled` · `collapsed` · ข้อความคอมเมนต์ (+ เปิด/ปิดบับเบิล) · ตำแหน่งหลังจัดเรียง · ถ้ากระเป๋าไม่ขึ้น cloud (Proposed) ไม่ต้องเพิ่ม ENT · **.ini/export ต้องมีเลขเวอร์ชันสคีมา:** แอปรุ่นเก่าเปิดไฟล์ใหม่แล้วทิ้ง `disabled` เงียบ ๆ = บล็อกที่ปิดไว้ทำงานจริง (ผลกับขาอุปกรณ์) → ต้องเตือนเมื่อเวอร์ชันไม่รู้จัก (H9) · โหมดโค้ด: ไม่เกี่ยวกับเมนูนี้ (R3 แก้ข้อความอิสระ · เมนูใช้ในโหมดบล็อกเท่านั้น · ในโหมดโค้ดคลิกขวา = เมนูของตัวแก้โค้ด ไม่ใช่เมนูนี้)

## (3) กดค้างบนจอสัมผัส ชนกับลากบล็อก · WCAG 2.5.7 / 2.5.8 / 2.1.1

ใช้ได้เมื่อมีเงื่อนไขต่อไปนี้ (อ้าง Blockly/Chromium ตามความรู้ทั่วไป · **ต้องให้ dev ลองบนจอสัมผัส Windows/Electron จริง**) · รายละเอียดเป็นเงื่อนไขใน OQ215:
