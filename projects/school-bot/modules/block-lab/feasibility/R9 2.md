# Block Lab · Feasibility R9: เชื่อม Uno + ส่งลงบอร์ด + หยุดทั้งหมด

**ตรวจเพิ่ม 2026-10-26 (OQ105 · ผลของการย้ายปุ่มเริ่มจำลอง): ทำได้มีเงื่อนไข** · R9 ไม่บังคับให้จำลองก่อนส่ง ส่งลงบอร์ดโดยไม่เคยจำลองได้ (UJ-04 มีจำลองเป็นขั้นแนะนำ ไม่ใช่เงื่อนไข) · เงื่อนไข: (1) ตรวจ R17 และชิป "ปัญหา N ข้อ" ต้องทำงานตอนแผงขวาซ่อน/ไม่เคยเริ่มจำลอง (2) ■ "หยุดทั้งหมด" ในแถวลิ้นชักต้องคงอยู่ (เป็นปุ่มหยุดเดียวที่เห็นตลอดเมื่อแผงซ่อน) (3) ลำดับ R17 → เชื่อม → ST-46 → ส่ง ไม่เปลี่ยน · ข้อสังเกต: หยุดทั้งหมดระหว่างส่งยังตาม OQ30 (6) · รายละเอียด `R10.md`

**ผล: ทำได้มีเงื่อนไข** (2026-10-22 · ruler · ตรวจใหม่หลัง R9 เปลี่ยน) · ส่วนอื่นนอกจาก §ผลตรวจ ruler เป็นข้อมูลอ้างอิงจาก Architect ระบบเก่า (DEL-08)

## ผลตรวจ ruler (2026-10-22: ส่งลงบอร์ดถูกปิดกั้นโดย R17)
- **ลำดับเมื่อกดส่ง (ข้อเสนอ):** R17 ตรวจ → ST-30 ตรวจการเชื่อม → ST-46 เตือนต่อสาย → ST-32 compile/ส่ง · R17 ก่อนเพราะแก้ได้ในจอโดยไม่ต้องมีบอร์ด · ซ้อนกัน 3 dialog ได้ในครั้งเดียว (R17 ผ่านแล้วค่อยเจอ ST-46) → ระวังความเมื่อยของเด็ก ป.3 (ข้อความสั้น ปุ่มต่อเนื่องชัด)
- **ปุ่ม "ส่งลงบอร์ด" ปิดกั้นแต่ต้องไม่ disabled เงียบ:** R17 ให้กดแล้วเห็นป๊อปอัป ("ส่งไม่ได้") + ต้องบอกเหตุผลที่ปุ่ม → ปุ่มกดได้ (`aria-disabled` + อธิบายตาม `brand.md` D-03) หลังปิดป๊อปอัปแสดงสถานะ "ยังส่งไม่ได้ · ปัญหา N ข้อ" ที่ปุ่ม/ข้างปุ่ม
- **ผลตรวจค้าง (stale):** requirement ให้ตรวจใหม่ตอนกดส่งเท่านั้น ระหว่างที่เด็กแก้ ตัวเลข "N ข้อ" ที่ปุ่มจะไม่ตรงความจริง (H1) · ทางเลือก: (ก) ตรวจนิ่งซ้ำอัตโนมัติเมื่อแก้ (ทำได้ถ้าการตรวจนิ่งเร็วพอ · dev ยืนยัน) หรือ (ข) ติดป้าย "ตรวจล่าสุดตอนกดส่ง" → ผู้ใช้ตัดสิน OQ55
- **ทางตัน:** ส่งไม่มีทางข้าม ถ้าผลตรวจผิด (false positive) เด็กส่งไม่ได้ตลอด (H9) → OQ55
- **AC-18 ปรับ:** "กดส่งแล้วเห็นเตือนต่อสายจริง" ใช้เมื่อ R17 ผ่านแล้วเท่านั้น (ความหมายของ AC เปลี่ยน) · ข้อความ ST-33/ST-46 ห้ามสื่อว่าวงจรผ่านการตรวจแล้วปลอดภัย (ตรวจเฉพาะวงจรในจอ)
- **สถานะที่ต้องเพิ่ม:** ST-R17-B/E (ดู `R17.md`) · ST ปุ่มส่งยังส่งไม่ได้ · ส่งที่ขา 0/1 ชนการอัปโหลด (ข้อ (3d) ของ R17) ลดความเสี่ยง "ส่งไม่สำเร็จ" ที่ต้นเหตุเป็นวงจร
- **ระหว่างกำลังส่ง:** ผลตรวจไม่รันซ้ำ ปุ่มปิดชั่วคราวตาม OQ30 (ไม่เปลี่ยน)
- ST-47 / OQ3 / OQ31 ไม่เปลี่ยน

## ผลตรวจ ruler (2026-10-21 · ยังใช้ได้)
ออกแบบได้ครบ (ส่วนบอร์ดหยุดจริงรอ OQ3) ข้อขัดแย้งและช่องโหว่:
- **AC-11 ขัดกับ Flow:** AC-11 ว่า "ส่งลงบอร์ดและหยุดใช้ได้เมื่อเชื่อมต่อ Uno แล้ว" แต่ Flow/ST-30 ให้กดส่งตอนยังไม่เชื่อมแล้วเจอ "ไม่พบบอร์ด" → ถ้าปุ่มปิดใช้เงียบ ๆ ตอนไม่เชื่อม เด็กไม่รู้เหตุผล (H1) · Proposed: ปุ่มกดได้เสมอ ถ้ายังไม่เชื่อมแสดง ST-30 → OQ30
- **ลำดับ ST-46 กับตรวจการเชื่อม:** ถ้าเตือนต่อสายก่อน แล้วค่อยบอก "ไม่พบบอร์ด" เด็กยืนยันฟรี (Proposed: ตรวจการเชื่อมก่อน) · ต้องนิยาม "วงจรเปลี่ยน" ที่ทำให้เตือนใหม่ (การต่อ/ชนิด/ค่าอุปกรณ์ ไม่นับย้ายตำแหน่ง/หมุน) · วงจรว่างเตือนทำไม (Proposed: ข้ามหรือข้อความอื่น) · ปุ่ม "ดูวงจร" ใน dialog ต้องปิด/ย่อ dialog หรือสลับไปแท็บตัวจำลอง ไม่บังวงจรที่จะให้ดู → OQ30
- **หยุดทั้งหมดระหว่างกำลังส่ง (ST-32):** ยกเลิกกลางทางไม่ปลอดภัยต่อบอร์ด · Proposed: หยุดจำลอง + stage และบอกว่าการส่งทำต่อจนเสร็จ ไม่สื่อว่ายกเลิกการส่ง → OQ30
- **ถอด USB ระหว่างส่ง / ปิดแอประหว่างส่ง:** ST-34 ครอบกรณีหลุด · แต่ app-shell R5 ครอบเฉพาะ "หุ่นกำลังขยับ" ไม่ครอบ "กำลังส่งลงบอร์ด" → OQ32 (กระทบ app-shell R5)
- **ปุ่ม "หยุดทั้งหมด" ชื่อสื่อว่าหยุดทุกอย่างรวมบอร์ด ทั้งที่ผลต่อ Uno ยัง Unknown (OQ3)** → ST-47 ต้องระบุชัด "หยุดตัวจำลองและตัวละครแล้ว" ไม่ใช้ถ้อยคำ "บอร์ดหยุดแล้ว" จนกว่าได้คำตอบ และเรื่องปุ่มซ้ำกับ "หยุดจำลอง" → OQ31
- **แปลงโค้ดไม่ผ่านเพราะบล็อกไม่ครบ:** ข้อความต้องชี้บล็อกที่ผิดให้เด็กแก้ได้ (H9) → OQ26
- ST-30/ST-34 ต้องมีรหัสข้อผิดพลาด (E-USB เป็นต้น ตาม context.md)

## หน้าจอ
**SCR-19 Block Lab: เชื่อม Uno + ส่งลงบอร์ด** · ผู้ใช้: นักเรียน · วัตถุประสงค์: อัปโหลดและหยุด · FR-20, AC-11, AC-18, EC-07, EC-09
- ข้อมูลที่แสดง: ENT-19 พอร์ต สถานะ (ชนิด Uno)
- การกระทำ: เชื่อมต่อ, ส่งลงบอร์ด, หยุดทั้งหมด · **ก่อนส่ง:** dialog เตือนต่อสายจริงตามวงจรในจอ (ทุกครั้ง + ตัวเลือก "ไม่ต้องเตือนอีกในงานนี้" · เตือนใหม่เมื่อวงจรเปลี่ยน · ผู้ใช้ 2026-10-21) · **หลังส่งและมีบล็อก Stage:** แจ้งว่า "บล็อกตัวละครทำงานเฉพาะในจอ"
- สถานะ: ST-30, ST-32–34, ST-45, ST-46, ST-47 · **พร้อมออกแบบ: Yes** · "หยุดทั้งหมด" บน Uno จริง = Assume (DEV-Q16)

## ข้อมูล
ENT-19 การเชื่อมต่ออุปกรณ์: ชนิด (แขน Pi / Uno), พอร์ต, ชื่อหุ่น, สถานะ · แสดงที่ SCR-02 (เฉพาะอุปกรณ์ของ lab ที่เปิดอยู่), SCR-19 · สร้างโดยแอปเมื่อเสียบ USB · Uno ไม่ต้อง driver (DEV-Q03 Answered)
ข้อมูลจากระบบภายนอก: Arduino Uno รับโปรแกรมที่ compile แล้ว (ข้ามบล็อก Stage · DEC-23) ออก เมื่อกดส่ง ล้มเหลว ST-34 (Answered DEV-Q03) · Uno หยุดโปรแกรมที่รันอยู่ ออก เมื่อกดหยุดทั้งหมด ล้มเหลว ST-47 (**Unknown DEV-Q16**)
