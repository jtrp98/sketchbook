# Block Lab · Feasibility R8: แผงข้อความจากบอร์ด (Serial)

**ผล: ทำได้มีเงื่อนไข** (2026-10-27 · ruler · ตรวจใหม่ส่วน terminal พิมพ์ได้ OQ143 · ส่วนอ่านข้อความใช้ผล 2026-10-21) · ส่วนอื่นนอกจาก §ผลตรวจ ruler เป็นข้อมูลอ้างอิงจาก Architect ระบบเก่า (DEL-08)

## ผลตรวจ ruler (2026-10-27 · terminal · OQ143, OQ149)

**ทำได้:** ส่งข้อความเข้า UART ของตัวจำลอง AVR ทำได้ในตัวแอป · ส่งเข้า Uno จริงผ่านพอร์ต USB เดียวกับที่อ่าน (ทางมาตรฐานของ Serial Monitor) · ยังเป็น DEV-Q (OQ143) แต่ไม่มีเหตุผลทางเทคนิคที่ทำไม่ได้

**ข้อขัด (X24 · OQ153 · block `approved`)**
- **โหมดบล็อกไม่มีบล็อกอ่าน Serial:** R8 บอกว่าโปรแกรมอ่านข้อความที่พิมพ์ด้วย `Serial.read` แต่ R18/§ตารางหมวด หมวด "สื่อสาร (Serial)" มีแค่ Serial print → ในโหมดบล็อก (ค่าเริ่มต้น · กลุ่มเป้าหมายหลัก ป.3–4) ช่องพิมพ์ส่งได้แต่ไม่มีโปรแกรมใดรับ = ฟีเจอร์ที่ดูใช้ได้แต่ไม่มีผล (H1/H2) · ทางเลือก: (ก) เพิ่มบล็อก "ข้อความที่ได้รับ" (มน) + "มีข้อความเข้ามา" (หกเหลี่ยม) ในหมวดสื่อสาร (แก้ R18/ตาราง) (ข) ช่องพิมพ์ใช้ได้ในโหมดโค้ดเท่านั้น โหมดบล็อกซ่อน/ปิดใช้พร้อมเหตุผล (ค) คงไว้ทั้งสองโหมดและแสดงคำใบ้เมื่อโปรแกรมไม่มีการอ่าน · ข้อเสนอ: (ก) เพราะ terminal ไม่มีความหมายสำหรับเด็กที่ใช้บล็อกถ้าไม่มีบล็อกรับ

**เงื่อนไข (H1/H5/H9 · ไม่ block)**
1. **ปลายทางเมื่อมีทั้งสองแหล่ง:** OQ149 (ข) "ส่งได้เมื่อเชื่อม Uno **หรือ** กำลังจำลอง" ไม่บอกว่าถ้าเป็นทั้งสองพร้อมกัน ข้อความไปไหน · ข้อเสนอ: ไปแหล่งเดียวกับป้ายแหล่งที่แสดงอยู่ (ST-43) คือกำลังจำลอง → ตัวจำลอง · ไม่จำลอง → Uno · ช่องพิมพ์มีป้ายปลายทาง "ส่งไป: ตัวจำลอง / บอร์ด Uno" (ไอคอน + ข้อความ) → OQ153
2. **ตอนกำลังแปลงโค้ด/ส่งลงบอร์ด พอร์ตถูกใช้:** ช่องพิมพ์ต้อง `aria-disabled` + เหตุผล "กำลังส่งลงบอร์ด" · ข้อความที่พิมพ์ค้างไม่หาย · ส่งไม่สำเร็จ (พอร์ตหลุด) → บรรทัด error ในบันทึก + รหัส E-USB (ST-44)
3. **เปิดพอร์ต = reset Uno (มีอยู่แล้วใน OQ2):** ถ้าแอปเปิดพอร์ตตอนกดส่งข้อความครั้งแรก โปรแกรมบนบอร์ดเริ่มใหม่และข้อความแรกอาจหาย (bootloader) · ข้อเสนอ: เปิดพอร์ตค้างไว้ตั้งแต่เชื่อมบอร์ด/หลังส่งสำเร็จ (ผูก OQ2) → dev
4. **ตัวจบบรรทัดและการเข้ารหัส:** ไม่มีตัวเลือก line ending (ป.3) → ข้อเสนอ: ต่อท้าย `\n` เสมอ และใส่ในโค้ดตัวอย่าง/บล็อกอ่านให้ตรงกัน · ภาษาไทย UTF-8 = 3 ไบต์ต่อตัว · บัฟเฟอร์รับ Uno 64 ไบต์ → จำกัดความยาวเป็น**ไบต์** (≤ 60 ไบต์ ≈ ไทย 20 ตัว) ไม่ใช่ 60 ตัวอักษร (OQ149 (ก)) และบอกตัวนับที่เหลือ · baud ตรงกับ `Serial.begin` ที่ตัวสร้างโค้ดใส่ · โหมดโค้ดเด็กเปลี่ยน baud เองได้ → ต้องอ่านค่าจากโค้ดหรือบอกว่าใช้ 9600 เท่านั้น
5. **บันทึกแยกแหล่งไม่พึ่งสี:** บรรทัดที่ส่ง / ที่ได้รับ / error ต่างกันด้วยสัญลักษณ์นำหน้า (เช่น ›, ‹, ⚠) + ข้อความ · aria-live ไม่ประกาศทุกบรรทัด (OQ10 เดิม) · ช่องพิมพ์มี label · ปุ่ม "ส่ง" ≥ 44px
6. **คีย์ลัดชน:** โฟกัสอยู่ในช่องพิมพ์ ต้องไม่ส่งปุ่มไปพื้นที่ต่อบล็อก (+ − 0 · Delete · Ctrl+Z เลิกทำบล็อก) · ลูกศรขึ้น/ลง = ประวัติ (OQ149 (ง)) ไม่ชนกับเลื่อนบันทึก
7. **ล้าง/ไม่บันทึก:** ข้อความที่ส่งไม่บันทึกกับงาน (ตาม R8 เดิม · my-work R10) · ประวัติลูกศรขึ้นหายเมื่อปิดงาน (ข้อเสนอ)

## ผลตรวจ ruler (2026-10-21)
ทำได้ตอนจำลอง · ตอนต่อ Uno จริงขึ้นกับ OQ2 (ออกแบบเผื่อ 2 แบบแล้ว) ช่องโหว่:
- **ข้อความปนแหล่ง:** จำลองกับ Uno จริงอาจส่งข้อความพร้อมกัน (Uno รันโปรแกรมเดิมอยู่ ขณะเริ่มจำลอง) → ต้องกำหนดป้ายต่อบรรทัดหรือแยกชุด/ล้างเมื่อสลับ → ผนวกใน OQ10
- **ข้อความมาถี่เกิน** (Serial ใน loop ไม่มี delay) → ต้องจำกัดอัตราแสดงผล + หยุดเลื่อนอัตโนมัติ + ไม่ประกาศ `aria-live` ทุกบรรทัด (กระทบ 2.3.1 และการอ่าน) → ผนวกใน OQ10
- **หยุดแล้วข้อความต้องคงอยู่** (เช่น หยุดเพราะอุปกรณ์เสีย) ล้างเมื่อเริ่มใหม่เท่านั้น ตรงกับ Proposed ปัจจุบัน
- **ขึ้นบรรทัดใหม่:** บล็อก Serial print ขึ้นบรรทัดเสมอ (println) หรือเลือกได้ (Proposed: ขึ้นบรรทัดใหม่เสมอ) → ผนวกใน OQ10
- **Uno จริง (OQ2):** การเปิดพอร์ตอ่านอาจ reset บอร์ด (โปรแกรมเริ่มใหม่) · พอร์ตเดียวกับตอนส่ง ต้องปิดอ่านก่อนส่ง · baud ต้องตรงกับที่ตัวสร้างโค้ดใส่ใน `Serial.begin` (ตัวสร้างโค้ดกำหนดค่าคงที่) → ผนวกใน OQ2
- ST-44 ต้องมีรหัสข้อผิดพลาด (เช่น E-USB ตาม context.md)

## หน้าจอ

## DEV-Q14 (Open)
**คำถาม:** Serial จาก Uno จริง: หลังส่งลงบอร์ด แอปเปิดพอร์ตอ่านข้อความต่อได้เองไหม (พอร์ตเดียวกับที่ใช้อัปโหลด) · baud rate คงที่ไหม · ตัวสร้างโค้ดใส่ `Serial.begin` อัตโนมัติเมื่อมีบล็อก Serial print ได้ไหม
- **A (อ่านได้อัตโนมัติ):** แผงเดียวกัน ป้ายแหล่ง "Uno จริง"
- **B (ต้องกดเปิด/ปิดอ่าน หรือพอร์ตชนกับการอัปโหลด):** เพิ่มปุ่ม "อ่านข้อความจากบอร์ด" + ST-44
