# Block Lab · Feasibility R1: หมวดบล็อกสำหรับ Uno

**ผล: ทำได้มีเงื่อนไข** (2026-10-21 · ruler) · ส่วนอื่นนอกจาก §ผลตรวจ ruler เป็นข้อมูลอ้างอิงจาก Architect ระบบเก่า (GO WITH CONDITIONS)

## ผลตรวจ ruler (2026-10-21)
ครบ 10 หมวด ตารางเก็บ/ตัดชัด ไม่ขัดกับ R2 · ทำเป็น UI ได้ ช่องโหว่ที่ต้องปิดก่อนออกแบบแผงบล็อกรายตัว:
- **ไม่มีการตั้งโหมดขา:** หมวด "ขาสัญญาณ" ไม่มี pinMode (OUTPUT / INPUT / INPUT_PULLUP) · บน Uno digitalWrite/digitalRead ใช้ไม่ถูกถ้าไม่ตั้งโหมด และตัวจำลอง "สมจริง" ต้องทำตามนั้น → ต้องเลือกบล็อก pinMode หรือใส่ให้อัตโนมัติ (แสดงในแผงโค้ด) → OQ25
- **ตัวแปรใน C++ มีชนิด** (int/float) ตารางหมวด "ตัวแปร" ไม่ระบุ · int บน Uno 16 บิตล้นได้ · ชื่อตัวแปรภาษาไทย/จีนใช้เป็นชื่อใน C++ ไม่ได้ ต้องกำหนดการแปลงชื่อหรือจำกัดชื่อ → OQ25
- **ช่อง dropdown ขาต้องกรองตามความสามารถของขา** (analogWrite เฉพาะ PWM, analogRead A0–A5, เตือนขา 0/1 ชนกับ Serial) ไม่ใช่ช่องพิมพ์ (H5 · BUG-17) → ผนวกใน OQ4
- **digitalRead เป็นบล็อกมน (ค่า) แต่ "ถ้า" รับหกเหลี่ยม** → ปุ่มกดต้องต่อ 2 ชั้น (เปรียบเทียบกับ สูง/ต่ำ) ป.1 อาจติด · ถ้าจะเพิ่มบล็อกหกเหลี่ยมสำเร็จรูปเป็นการเปลี่ยนตารางหมวด ต้องผ่านผู้ใช้ → ผนวกใน OQ4
- **เสียง:** บล็อก tone ต้องมีผลในตัวจำลอง ต้องตัดสินว่ามีเสียงจริงไหม ปิดเสียงได้ไหม → OQ35
- **สีหมวด 10 หมวด** ต้องมีชื่อ/ไอคอนกำกับ ไม่แยกด้วยสีอย่างเดียว (UD4) → ผนวกใน OQ11
- ป้ายบนบล็อก 3 ภาษา เผื่อยาว +40% (ช่องในบล็อกไม่ล้น)

**SCR-16 Block Lab: พื้นที่ต่อบล็อก + ดูโค้ด** (ผู้ใช้: นักเรียน · FR-15–17, UJ-04, AC-10, AC-11) · ข้อมูลที่แสดง: ENT-17 บล็อก ตัวแปร, โค้ด C++ (อ่านอย่างเดียว) · การกระทำ: ลาก วาง ลบ เลิกทำ ซูม เลื่อน · งานใหม่ (Ctrl+N) · งานของฉัน → my-work SCR-09 Block · เริ่มจำลอง/หยุด (ควบคุมร่วม SCR-17 + SCR-18) · หยุดทั้งหมดและส่งลงบอร์ดที่แถบล่าง · ตัวกรอง: หมวดบล็อก 10 หมวด (DEC-20), ของโปรด · สถานะ: ST-27, ST-10, ST-28 · **พร้อมออกแบบ: Yes** (หมวดบล็อก Confirmed DEC-20 · แก้ BUG-13–20 · จับคู่บล็อกรายตัว Delegated → Designer + dev)

## หลักฐานที่สังเกตได้ของ Main-1D (EV-04 · อ่านโค้ด ไม่ได้รัน/ลาก)
- Layout: แถบภารกิจด้านบน (**ต้องตัด** DEC-25) · ราง 13 เมนูกับ "ของโปรด" · แผงบล็อก · พื้นที่ต่อบล็อก · แผงโค้ดอ่านอย่างเดียว · แถบล่าง "หยุดทั้งหมด" ซ้าย และ "ส่งลงหุ่น" ขวา (ต้องเปลี่ยนเป็น "ส่งลงบอร์ด")
- บล็อกทั้งหมด **126 บล็อก** จัดสีชุด B เป็น **8 กลุ่ม** · โน้ตบน canvas บอกว่าสีหมวดบล็อกยังไม่มี token (EV-05)
- บล็อกเริ่ม 2 แบบ ("เริ่มต้น" และ "โปรแกรมหลัก วนทำซ้ำ") · บล็อกที่ไม่ได้ต่อถูกปิดใช้ (ลายเทา)
- **ข้อที่ต่างจากที่ยืนยัน:** บล็อกมาจาก ESP32/MixGo/pioneer และสร้างโค้ดเป็น **Python (MicroPython)** · บล็อกส่วนใหญ่ได้โค้ด `blk_r…  # ❓` → ต้องทำรายการบล็อกและตัวสร้างโค้ดใหม่สำหรับ Uno + C++ (CF-01, RSK-01)
- ไม่ได้ตรวจ: ฮาร์ดแวร์ Uno, source code Mixly
