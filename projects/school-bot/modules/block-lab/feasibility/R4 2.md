# Block Lab · Feasibility R4: ตัวจำลองบอร์ดต่อสายอิสระ

**ผล: ทำได้มีเงื่อนไข** (2026-10-22 · ruler · ตรวจใหม่หลัง R4 เปลี่ยน) · ส่วนอื่นนอกจาก §ผลตรวจ ruler เป็นข้อมูลอ้างอิงจาก Architect ระบบเก่า (DEL-08 ทบทวน 2026-10-21)

## ผลตรวจ ruler (2026-10-22: ตัวช่วยต่อสาย + ชื่ออุปกรณ์อัตโนมัติ)
- **ARC-I34 ด้านล่าง ("ไม่เพิ่มตัวช่วยใหม่ DEC-19") ถูกแทนที่แล้ว** สำหรับ block-lab โดย OQ46 (ผู้ใช้ 2026-10-22: ต่อสายอิสระ + ตัวช่วย) · ข้อ "ตัวช่วยไม่ใช่การเพิ่ม" ของ ST-40 ใช้ไม่ได้อีก
- **ตัวช่วยต่อสายทำได้** ถ้ามี "ตารางขั้ว" ต่อชนิดอุปกรณ์ (ชุดเดียวกับ R16 `R16.md` ข้อ 7) ใช้ได้ทั้งเรืองขาที่ยังไม่ต่อ และกรองปลายทางที่ต่อได้หลังแตะขาแรก (เช่น แตะขาแรกของ LED แล้วเรืองขา Uno ดิจิทัล/GND ที่ต่อได้) · เงื่อนไข: ขาสัญญาณ Uno เด็กยังเลือกเอง (ต่างจากช่องเสียบตายตัว) ตัวช่วยบอกได้แค่ "ขาดิจิทัลขาใดก็ได้" สำหรับขาสัญญาณ ไม่ชี้ขาเดียว · ขา 5V/GND ชี้ตรงได้
- **ตัวช่วยต้องไม่พึ่งสีอย่างเดียว (UD4):** เรือง + ป้ายชื่อขา/ไอคอน · ป้ายชื่อขาบน breadboard ที่ซูมได้ต้องอ่านได้ (ขนาดตัวอักษร ≥ 16px ตาม `brand.md` สำหรับสิ่งที่ต้องอ่านเพื่อทำงาน) ขัดกับระยะรูแน่น → OQ33 · ไม่กะพริบ (เรืองคงที่ ไม่เต้น)
- **แตะขาแรก-แตะขาที่สอง** ตอบ OQ29 เฉพาะ "ต่อสาย" · ยัง **ไม่ครอบ** วางอุปกรณ์/ย้ายอุปกรณ์/ต่อบล็อก → OQ29 ยังเปิด · ต้องมียกเลิกกลางคัน (Esc/แตะซ้ำ/พื้นที่ว่าง) และแสดงว่ากำลังอยู่ในโหมดต่อสาย (H1) → OQ52
- **ชื่ออุปกรณ์อัตโนมัติ + แก้ได้ (popover R15):** ต้องกำหนดกติกา: ชื่อไม่ซ้ำ · ตัวนับไม่ใช้เลขซ้ำหลังลบ (หรือซ้ำได้เพราะบล็อกอ้าง ID) · ชื่ออัตโนมัติตามสีที่เปลี่ยนไหม · ชื่อว่างย้อนเป็นอัตโนมัติ · จำกัดความยาว + ตัด/ล้นใน 3 ภาษา · ชื่อ 3 ภาษาของชื่ออัตโนมัติ → OQ56
- **วางอุปกรณ์ชนิดเดียวกันได้หลายตัว:** ไม่ระบุจำนวนสูงสุดและพื้นที่ breadboard จำกัด → ต้องมีข้อความเมื่อเต็ม (H5) หรือกำหนดเพดาน (Designer/dev)
- **ผลต่อ netlist:** ต้องเป็นข้อมูลจริงให้ R16/R17 ใช้ (ดู `R16.md` ข้อ 1) → OQ1/OQ21 เปลี่ยนจากเรื่องระดับค่ากระแสเป็นเรื่อง "netlist + กฎนิ่ง ต้องมี"
- **วงจรจริง = Uno + breadboard + อุปกรณ์สายแตะจริง ตรงกับตัวจำลอง:** ช่วยให้ EC-09 ชัดขึ้น แต่แอปยังตรวจสายจริงไม่ได้ (DEC-27 ไม่เปลี่ยน)

## ผลตรวจ ruler (2026-10-21 · ยังใช้ได้ ยกเว้นที่ระบุข้างบน)
ส่วนที่ใหญ่และเสี่ยงที่สุดของ module (RSK-06) ทำได้ถ้าชัดเจนว่าระดับการคำนวณวงจรคืออะไร (OQ1/OQ21) ช่องโหว่และข้อขัดแย้ง:
- **ค่าปุ่ม/potentiometer มาจากไหน:** จากวงจรจริง (ต้องต่อสายถูกจึงอ่านค่าได้) หรือจากค่าที่ผู้ใช้ตั้งโดยไม่ขึ้นกับสาย → เปลี่ยนความหมายของ "ต่อสายผิด" ทั้งระบบ → ผนวกใน OQ1
- **LED บนบอร์ด (ขา 13) ไม่ระบุ:** Blink แรกของเด็กไม่ต้องต่อสาย ถ้าไม่มี LED บนบอร์ดจะไม่เห็นอะไรเลย (H1) · RGB common anode/cathode → ผนวกใน OQ13
- **"ดูเหมือนจริง" ขัดกับเป้าสัมผัส 44×44** (รูบน breadboard เล็ก) และพื้นที่ 856 → ต้องซูม/เลื่อน, snap ระยะกว้าง, ระยะรูแบบ stylized → OQ33
- **ต่อสายด้วยการลากอย่างเดียว** ไม่มีทางเลือก/คีย์บอร์ดตอนสร้างวงจร (R6 ครอบคลุมเฉพาะตอนจำลอง) → OQ29
- **ฟีดแบ็กเมื่อสายไม่ตรงกับขาในบล็อก** (บล็อกสั่งขา 9 สายต่อขา 10 → เงียบ) ไม่มีสถานะ (H1) · Proposed: แสดงสถานะขา Uno ระหว่างจำลอง (สูง/ต่ำ/ค่า) เป็นข้อความ + สัญลักษณ์ ซึ่งเป็นสถานะระบบ ไม่ใช่ตัวช่วยเพิ่ม (DEC-19)
- **ผลจำลองผ่าน ≠ ปลอดภัยบนบอร์ดจริง** (แบบจำกัด OQ1-B) ข้อความ ST-46 ต้องไม่สื่อว่าวงจรที่จำลองผ่านปลอดภัย (H5)
- **เสียง buzzer** → OQ35 · **LED/ไฟกะพริบตามโปรแกรมเด็ก** ขัดกับ "ไม่กะพริบ" → OQ34
- **เลิกทำ/สลับงานระหว่างจำลอง** → OQ32
- dev: บันทึกอัตโนมัติขณะลากอุปกรณ์ต้องไม่ถี่เกิน (ดู my-work R7)

## หน้าจอ
**SCR-17 Block Lab: ตัวจำลองบอร์ด (แท็บ)** · ผู้ใช้: นักเรียน · วัตถุประสงค์: ต่อวงจรอิสระแบบ Tinkercad และทดสอบโดยไม่มีบอร์ด · FR-18, FR-31, UJ-04, EC-08, AC-12, AC-16
- ข้อมูลที่แสดง: ENT-17 วงจร (อุปกรณ์ ตำแหน่ง สาย ค่าอุปกรณ์), ENT-26 สถานะจำลอง (ค่าไฟ/กระแส ระดับที่แสดงได้ตาม DEV-Q13, อุปกรณ์ที่เสีย, ค่าอุปกรณ์รับค่า)
- การกระทำ — **วงจร:** ลากอุปกรณ์จากแผงอุปกรณ์ (ชุด ARC-I09) · ต่อสายจากขาถึงขา · ย้าย หมุน ลบอุปกรณ์/สาย · ตั้งค่าอุปกรณ์ (เช่น ค่าตัวต้านทาน สี LED · Delegated → OQ13) · เลิกทำ · **จำลอง:** เริ่ม หยุด (ร่วมกับ SCR-18) · **อุปกรณ์รับค่า (FR-31):** ดู R6 · **เมื่อเสีย:** ดู R5
- สถานะ: ST-28, ST-29, ST-40, ST-41 · **พร้อมออกแบบ: Yes สำหรับวงจร + โต้ตอบ · Assume สำหรับชนิดความเสียหายและค่ากระแส** (DEV-Q13 · ออกแบบ LED ไม่มีตัวต้านทาน + ลัดวงจรก่อน)
