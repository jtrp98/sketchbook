# Block Lab · Feasibility R10: จำลองพร้อมกันและแก้ระหว่างจำลอง

**ผล: ทำได้มีเงื่อนไข** (2026-10-26 · ruler · ตรวจใหม่เฉพาะส่วนที่แก้ 2026-10-26: ปุ่มเริ่ม/หยุดจำลองย้ายไปแผง stage + เปิดหน้าไม่เริ่มเอง · ส่วนที่เหลือใช้ผล 2026-10-21) · ส่วนอื่นนอกจาก §ผลตรวจ ruler เป็นข้อมูลอ้างอิงจาก Architect ระบบเก่า

## ผลตรวจ ruler (2026-10-26 · OQ105 · ผูก R7, R9, R17, OQ102)
**ผล: ทำได้มีเงื่อนไข** · ไม่ block ออกแบบ · มีเรื่องที่ผู้ใช้ควรตัดสิน → OQ113 (มีค่า Proposed ใช้ออกแบบได้ จึงไม่ถามผ่าน AskUserQuestion · tool ถามไม่พร้อมใช้ในรอบนี้)

**ข้อขัดแย้งใหม่**
- **X18 R10/OQ105 กับ OQ102:** OQ102 ให้แผงขวา (ตัวจำลอง + stage) **ซ่อนเป็นค่าเริ่มต้น** · OQ105 ให้ปุ่มเริ่ม/หยุดจำลอง **อยู่ในแผง stage เท่านั้น** (ไม่มีบนแถบ/ลิ้นชัก) → เปิดหน้ามา (หยุด + แผงซ่อน) **ไม่มีปุ่มเริ่มจำลองบนจอเลย** เด็กต้องรู้ก่อนว่าต้องเปิดแผงเอง (H6/H7 · ซ้ำปัญหา "ไม่รู้ว่าซ่อนได้") · ขั้นตอนทดสอบ UJ-04 ("ทดสอบในตัวจำลอง") มี 2 ขั้นที่มองไม่เห็นทาง
- **ถ้อยคำภายใน R10:** ประโยคเดิม "ปุ่มเริ่ม/หยุดร่วมที่ SCR-16 · ปุ่มหยุดเห็นตลอด" ยังอยู่ก่อนประโยคแก้ 2026-10-26 → ต้องให้ session หลักตัดประโยคเดิมออกให้ไม่อ่านขัดกัน (ไม่แก้ requirements.md เอง)
- **R10 "เห็นพร้อมกัน/ไม่มีแท็บ" กับแผงซ่อนได้:** บอร์ด A2 ขัดโดยตั้งใจอยู่แล้ว (OQ72) · ตอนนี้ปุ่มเริ่มผูกกับแผงที่ซ่อนได้ ทำให้ "จำลองพร้อมกัน" ใช้ได้เฉพาะเมื่อแผงเปิด

**เงื่อนไข / ข้อเสนอ (ใช้เป็น Proposed ใน OQ113)**
1. **เมื่อแผงซ่อน ต้องมีทางเริ่มจำลอง:** ข้อเสนอ: แผง stage ตอนหุบยังเหลือแถบเล็ก/ที่จับ (collapsed) ที่มี ▶ เริ่มจำลอง + ปุ่มแสดงแผง · หรือกดเริ่มจากปุ่มที่เปิดแผง (กดเดียว = เปิดแผง + เริ่ม) · ไม่ควรมีปุ่มเริ่มอยู่ในลิ้นชักอีก (ผู้ใช้สั่งเอาออก) · ทางเลือกที่ผู้ใช้ต้องเลือก = OQ113
2. **สถานะ "กำลังจำลอง" ต้องเห็นตอนแผงซ่อน (H1):** รอบ 3 ตัด pill สถานะจำลองออกจากหัวหน้า → ถ้าเริ่มแล้วซ่อนแผง จะไม่มีตัวบอกว่ากำลังจำลอง (และเสียง buzzer ยังดัง R14) · เสนอ: ตัวบอก (ไอคอน + ข้อความ) บนที่จับของแผง และ/หรือที่ปุ่ม ■ "หยุดทั้งหมด"
3. **ปุ่มหยุด:** ■ "หยุดทั้งหมด" (R9 · OQ86) คงอยู่ในแถวแท็บลิ้นชักตลอด จึงหยุดได้แม้แผงซ่อน (R10 "ปุ่มหยุดเห็นตลอด" ผ่านด้วย ■) · ปุ่มหยุดจำลองในแผง = ปุ่มสลับเดียวกับเริ่ม (OQ31 ยังยืนตามเดิม: 2 ปุ่มแยกหน้าที่ ทำงานเท่ากันที่ตัวจำลอง/stage) · **ป้ายปุ่มต้องบอกว่าควบคุมทั้ง stage และตัวจำลอง** (ปุ่มอยู่ในแผง stage แต่สั่งตัวจำลองด้วย · ป้าย "เริ่มจำลอง" ไม่ใช่ "เล่น stage")
4. **แถบแจ้ง "หยุดเพราะแก้ไข" (OQ8/EC-10):** ปุ่ม "เริ่มใหม่" ในแถบแจ้ง = ทางเริ่มที่สองนอกแผง → ข้อเสนอ: เปลี่ยนเป็น "ไปที่ตัวจำลอง" (เปิดแผง) หรือให้นับเป็นข้อยกเว้นที่ผู้ใช้ยืนยัน (OQ113)
5. **เปิดหน้าไม่เริ่มเอง:** ทำได้และถูกต้อง (ไม่มีแอนิเมชัน/เสียงเริ่มเองตาม WCAG 2.2.2/1.4.2) · สถานะเริ่มต้น = หยุด ตัวจำลอง/stage แสดงภาพนิ่ง (LED ดับ · มาสคอตท่าเริ่มต้น) · ไม่บันทึกกับงาน (my-work R10 · ตรงกับ "สถานะจำลองไม่บันทึก") · งานใหม่/เปิดงานเดิม/สลับงาน = หยุดเสมอ · ข้อความ "กดเริ่มจำลองก่อน" (OQ15) และ ST-40 ต้องชี้ตำแหน่งใหม่ (แผง stage) และใช้เมื่อแผงเปิดเท่านั้น
6. **ตรวจก่อนรัน (R17) ไม่ขึ้นกับแผง:** netlist/ตารางกฎต้องอยู่ที่ชั้นข้อมูลของโปรแกรม ไม่อยู่ใน SimPane (เพราะแผงซ่อนอาจไม่ถูกสร้าง · เด็กอาจกดส่งลงบอร์ดโดยไม่เคยเปิดแผง) · ชิป "ปัญหา N ข้อ" ต้องคำนวณได้ตอนแผงซ่อน (dev)
7. **R7 (stage):** ไม่ขัดกับการย้ายปุ่ม (stage ยังรันพร้อมตัวจำลองตามเดิม) · ผลข้างเคียง: หมวด "ตัวละคร" ต้องเลือก stage (R1) แต่ stage ซ่อนเป็นค่าเริ่มต้น และ A2 เอาตัวสลับออก (OQ80) → เข้าหมวดตัวละครไม่ได้โดยค่าเริ่มต้น (ค้างจาก OQ80 · ไม่ใช่ปัญหาใหม่ของรอบนี้)

**AC ที่ต้องเติมเมื่อ session หลักแก้ requirement:** Given เปิดงาน When หน้าโหลดเสร็จ Then สถานะ = หยุด ไม่มีเสียง/ภาพเคลื่อนไหวจากตัวจำลอง · Given แผงซ่อน When ต้องการเริ่มจำลอง Then มีทางที่เห็นได้และใช้คีย์บอร์ดได้ภายใน 1–2 ขั้น · Given กำลังจำลองและแผงซ่อน Then เห็นสถานะ "กำลังจำลอง" และหยุดได้ด้วย ■

## ผลตรวจ ruler (2026-10-21)
ตัดสินแล้วว่ารันพร้อมกัน (OQ17) ทำได้ ST-28 มีแค่ "กำลังจำลอง / หยุด" ซึ่งไม่ครอบคลุมวงจรชีวิตจริง (H1/H9):
- **ขาดสถานะ:** กำลังแปลงโค้ดก่อนจำลอง (ถ้าตัวจำลองรันโค้ดที่ compile แล้ว ต้องใช้ toolchain ซึ่งมีเวลาและอาจไม่ผ่าน) · แปลงไม่ผ่าน · จบโปรแกรม (บล็อก "หยุดโปรแกรม") · หยุดเพราะอุปกรณ์เสีย · หยุดเพราะแก้ · ตัวแปร/ตัวนับรีเซ็ตเมื่อเริ่มใหม่ → OQ26
- **นิยามคำว่า "แก้" (OQ8):** ย้าย/หมุนอุปกรณ์ที่ไม่เปลี่ยนการต่อ นับไหม · ปรับค่าอุปกรณ์/ชื่อตัวแปรนับ · กดปุ่ม/หมุน potentiometer ไม่นับ · ข้อความหยุดต้องไม่หายเอง (อ่านทัน ~5 วินาที) พร้อมปุ่ม "เริ่มใหม่"
- **ปุ่มหยุดมี 2 ตัว** (R10: "ปุ่มเริ่ม/หยุดร่วมที่ SCR-16" กับ R9/R11: "หยุดทั้งหมด" ที่แถบล่าง) ความต่างไม่ชัด (H4) → OQ31
- **stage กับตัวจำลองใช้เวลาร่วมกัน** → OQ27
- **ลูปไม่มี delay / วนไม่จบ:** ปุ่มหยุดต้องตอบสนองเสมอ ตัวจำลองต้องไม่ทำให้ UI ค้าง (เงื่อนไขกับ dev · ลำดับความสำคัญ UX ข้อ 1)
- **สลับงาน/งานใหม่/งานของฉัน ระหว่างจำลอง** → OQ32
