## ลำดับและกฎ
กด "ส่งลงบอร์ด" → ตรวจการเชื่อมก่อน (ไม่พบ = ST-30 · ปุ่มไม่ปิดใช้เงียบ ๆ แก้ X1) → **ST-46 dialog เตือนต่อสายจริง** (ทุกครั้ง · ติ๊ก "ไม่ต้องเตือนอีกในงานนี้" · เตือนใหม่เมื่อวงจรเปลี่ยน = เพิ่ม/ลบ/เปลี่ยนค่าอุปกรณ์หรือสาย ไม่นับย้าย/หมุน · "ดูวงจร" ปิด dialog แล้วสลับไปแท็บตัวจำลอง) → ST-32 (แปลงโค้ด → ส่ง · ไม่มีปุ่มยกเลิก) → ST-33 (+ST-45 ถ้ามีบล็อก Stage แสดงเป็นข้อมูล ไม่ใช่ error) / ST-34
- dialog มีรายการวงจรที่ต้องต่อ (LED ขา 9 ผ่านตัวต้านทาน 220 Ω · ปุ่มขา 2 · ลูกบิดขา A0) + แถบเตือน "จำลองผ่านในจอ ไม่ได้แปลว่าปลอดภัยกับบอร์ดจริง" (H5, ตาม ruler R4)
- ข้อความ error: ภาษาเด็ก ไม่โทษ + เช็กลิสต์ + รหัส (E-USB, E-BUILD · ชื่อชั่วคราว) · มาสคอตตามตาราง §8: แว่นขยาย (ไม่พบ) · วิ่ง (กำลังทำ) · ยกนิ้ว (สำเร็จ) · คิด "ลองใหม่นะ" (ไม่สำเร็จ)
- **ปุ่มหยุดทั้งหมด**: ซ้ายสุด ปุ่มกลม 60 สีแดง ไอคอน square · อยู่ในชั้น z-stop 70 · การ์ดทุกใบเปิดขึ้นด้านบน ไม่ทับ · dialog ฉากหลังเว้นแถบล่าง · ห่างจาก "ส่งลงบอร์ด" ด้านขวาสุด (ระยะ > 900px) · ข้อความใต้ปุ่ม "หยุดตัวจำลองและตัวละคร" (ไม่สื่อว่าหยุดบอร์ด)
- **ST-47 (OQ3 ยังเปิด)**: ค่าตั้งต้น = บอกเฉพาะที่หยุดแน่นอน + "โปรแกรมบนบอร์ดอาจยังทำงานอยู่ ถ้าต้องการให้หยุดให้ถอดสาย USB" · ทำ Tweak 2 แบบรอ dev: A "หยุดทั้งหมดแล้ว (รวมบอร์ด)" · B มีความคืบหน้า + "โปรแกรมเดิมบนบอร์ดจะหาย"
- ระหว่างส่ง: "หยุดทั้งหมด" หยุดตัวจำลอง+stage และบอกว่าการส่งทำต่อจนเสร็จ (Proposed OQ30) · งานใหม่/ปิดแอประหว่างส่ง = กัน (OQ32 · ต้องเพิ่มกรณีใน app-shell R5 ผ่าน session หลัก)

## การตัดสินใจ (OQ36 ใหม่)
- **ปุ่ม "ส่งลงบอร์ด" ใช้ส้ม action-robot (#FF8A00) + text-primary + ขอบล่าง #B85E00** (ปุ่มที่กดแล้วฮาร์ดแวร์ทำงาน D-06 · contrast 6.59) · เหตุผล: ตรงกับความหมายสีเดิม · มาสคอตส้มอยู่ในจอ stage ฝั่งตรงข้ามจึงลดความสับสน (RSK/OQ9 app-shell) · **ให้ผู้ใช้ยืนยัน** → OQ36
- ปุ่ม "ส่งต่อ" ใน dialog ใช้ส้มเดียวกัน · ปุ่มรองใช้ขอบ border-strong
