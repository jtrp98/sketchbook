## Heuristics / UD / WCAG AA ที่ตรวจในการออกแบบ (ยังไม่ตรวจบน canvas โดย role อื่น)

## ข้อเสนอแนะ / ข้อจำกัด
1. **ยังไม่ได้ตรวจการเรนเดอร์**: ตรวจบน canvas ว่า dc-import ซ้อน 3 ชั้น (Main → ชิ้นส่วน → Mascot) ทำงาน, เส้นทับ/ป้ายซ้อน (ป้าย "ยังไม่ได้ต่อ" กับ hat, ป้าย LED กับสาย), การตัดภาพมาสคอตจากแผ่น, ฟอนต์โหลด
2. แถบหน้าต่างเป็นสำเนาชั่วคราว ต้องแทนด้วยสำเนาจาก Canvas B หลังแก้ CR-10/AUD-F04–F06 (ขึ้นกับ app-shell)
3. ขอให้ผู้ใช้ตัดสิน **ค่าเริ่มต้นแผงโค้ด** (ขยาย/ย่อ) และสีหมวดบล็อก (DSG-13)
