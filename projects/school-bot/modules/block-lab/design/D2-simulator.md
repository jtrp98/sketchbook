## โครง
- ถาดอุปกรณ์ 72: LED · ตัวต้านทาน · ปุ่มกด · บัซเซอร์ · ลูกบิด · เซอร์โว · ไฟ RGB (ชุดขั้นต่ำ ARC-I09 ครบ 7 + Uno + breadboard) + ซูมเข้า/ออก 44×44 · ป้ายข้อความ ≥ 16px ทุกปุ่ม
- ผืนผ้าใบ 442: Uno (ขาดิจิทัล GND,13…2 + A0/5V/GND ระยะ 28) บน · breadboard stylized ล่าง (22 คอลัมน์ × รางไฟ 2 แถว + 3+3 แถว คั่นร่อง) · แผง "สถานะขา" (ขา 9, 2, A0 เป็นข้อความ สูง/ต่ำ/ค่า) ขวาบน · แถบล่าง 86: คำแนะนำโต้ตอบ + ลูกบิด A0 (slider จริง + ตัวเลข)
- วงจรตัวอย่าง (ไฟกะพริบเมื่อกดปุ่ม): ขา 9 → ตัวต้านทาน 220 Ω → LED → รางลบ · ปุ่มกด ขา 2 → ลบ · ลูกบิดกลาง → A0, ปลาย → 5V/ลบ
- ST-40: การ์ดกลางจอ มาสคอตท่าถือแท็บเล็ต + 2 ขั้นสั้น ๆ "แตะอุปกรณ์แล้วแตะรู" / "แตะรูของ Uno แล้วแตะอีกรู" (ลด RSK-09 ไม่เพิ่มตัวช่วยตาม DEC-19)

## ความเสียหาย (R5 · ST-29) — ออกแบบเผื่อตาม Proposed (OQ1/OQ28 ยังเปิด)
- รูปแบบเดียว: หยุดจำลอง · วัตถุที่เสียนิ่ง (กรอบประ + ไอคอน + ข้อความ ไม่กะพริบ ไม่ระเบิด) · แถบสาเหตุ 3 บรรทัด (ชื่อ+รหัส / สาเหตุ / วิธีแก้) + มาสคอตหลอดไฟ + ปุ่มเดียว
- 2 กรณี: **LED ไม่มีตัวต้านทาน** (E-SIM-01 · "เปลี่ยน LED ใหม่" ใช้ตำแหน่งและสายเดิม ต้องกดเริ่มจำลองเอง · ไม่บันทึกสถานะเสียกับงาน OQ9) · **ลัดวงจร 5V–GND** (E-SIM-02 · ไฮไลต์สายแดง + "เอาสายนี้ออก" ไม่ใช่ "เปลี่ยนอุปกรณ์ใหม่" OQ28) — รหัสเป็นชื่อชั่วคราว
- เห็นจากแท็บ stage: ป้ายบน stage + แถบแจ้ง "ไปดูที่ตัวจำลอง" + pill ที่แถบแท็บ (D1/D3)
- ค่ากระแส: ไม่แสดงตัวเลข (ตามแบบ B "ระดับ ปกติ/เกิน") เพราะ OQ1 ยังไม่ตอบ · ห้ามแสดงตัวเลขที่ไม่ได้คำนวณจริง

## การโต้ตอบ (R6 · ST-41)
ปุ่มกด = `<button>` โฟกัสได้ · กดค้างด้วยเมาส์/สัมผัส/Space/Enter · aria-pressed · ไม่ใช่การลาก · ลูกบิด = `<input type=range>` 0–1023 มี label + ตัวเลข + aria-valuetext · ลูกศรหมุน (Shift/PageUp ก้าวใหญ่ = ข้อเสนอ OQ15) · ก่อนเริ่มจำลอง: ใช้ aria-disabled + ข้อความ "กดเริ่มจำลองก่อน" ไม่ใช่ปุ่มจางเงียบ ๆ · ตรรกะปุ่ม "กด = สูง" (OQ25) แสดงในช่องสถานะขา "สูง (กด)" · ค่าเริ่ม: ลูกบิดกลาง (512), ปุ่มปล่อย

## ความถี่แสง (OQ34 ผู้ใช้รับแล้ว)
LED/ไฟอยู่พื้นที่เล็ก (วงกลม 32px + halo 68px) · เกิน 3 ครั้ง/วินาที → แสดงแสงคงที่ระดับกลาง (สี+halo ลดลง) + ป้าย "สลับเร็ว · แสงกลาง ๆ" · ไม่มีเอฟเฟกต์ทั้งหน้า · ไม่มี animation ในตัวจำลอง (ทุกการเปลี่ยนเป็นการสลับสถานะทันทีครั้งเดียว) ส่วนการนับ/จำกัดความถี่จริงเป็นของ dev

## เสียง (OQ35 · Delegated → Designer · ยังเปิด)
ปุ่ม "เสียง ปิด/เปิด" อยู่ที่แถบแท็บ (เห็นจากทั้งสองแท็บ ห้องเรียน 45 คน) 44 สูง aria-pressed · ถาด "บัซเซอร์" มีแล้ว · ภาพแทนเสียง (ไอคอนลำโพง + ข้อความ "บัซเซอร์ดัง") ยังไม่วาดบนผืนผ้าใบเพราะวงจรตัวอย่างไม่มีบัซเซอร์ → **ต้องเพิ่มเมื่อเริ่มวางบัซเซอร์** (ค้างจากรอบนี้) · ปุ่มหยุดทั้งหมดและหยุดจำลองต้องหยุดเสียงทันที · **ค่าเริ่มต้นใน tweak `sound` = ปิด** (เหตุผล: ห้องเรียนหลายคน, WCAG 1.4.2) — **ให้ผู้ใช้เลือกค่าเริ่มต้นจริง**

## ข้อเสนอแนะ / ข้อจำกัด
1. **ต้องตัดสินแล้วบันทึก**: เป้ากดของรู breadboard/ขา Uno **ต่ำกว่า 44** (28×24) — เหตุผล: แสดงอุปกรณ์สมจริงในพื้นที่ 680 กว้าง · ลดความเสี่ยงด้วย snap รัศมี 28px + แตะแล้วแตะ + ซูม · ให้ highlighter/ผู้ใช้ยืนยัน (OQ33)
2. **LED บนบอร์ด Uno (ขา 13)** ตาม Proposed OQ13 **ยังไม่ได้วาด** (Blink แรกของเด็กจะไม่เห็นอะไร) — เพิ่มในรอบแก้ · ไฟ RGB ใช้ชนิดเดียว (ยังไม่วาดบนผืนผ้าใบ)
3. ยังไม่ได้ออกแบบ: ก้านค่าตัวต้านทาน/สี LED (OQ13 ชุดค่าที่เลือก), ตัวอย่างบัซเซอร์/เซอร์โว/RGB บนผืนผ้าใบ, การเลือกอุปกรณ์ (tap-to-place) เป็น state จริง — มีเฉพาะถาด + ข้อความใน Spec
4. ตรวจการทับของป้ายและสายบนผืนผ้าใบด้วยตา (พิกัดคำนวณมือ ไม่ได้ render)
