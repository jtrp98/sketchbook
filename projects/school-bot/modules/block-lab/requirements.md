# Block Lab: Requirements (จาก role 1)

> นำเข้าจากระบบเก่า (`Handoff/01_REQUIREMENT` v3.1 + CHG-07 + CHG-08 + FEASIBILITY_REPORT v3 ถึง 2026-10-21) · **sketchbook เป็นแหล่งความจริงแล้ว** ไม่ต้องเปิดโฟลเดอร์เดิม · ID เดิม (FR/NFR/EC/AC/DEC/ST/SCR/ARC-I/DEV-Q) เก็บไว้ในวงเล็บเพื่อ grep · ป้ายหลักฐานดู `../../context.md` · ถ้อยคำดู `../../brand.md` §7
> module อื่นอ้างด้วยชื่อ module + ID เดิม (เช่น my-work · FR-22)

## เป้าหมาย
นักเรียน ป.1–6 (UI เดียวกันทุกชั้น) ต่อบล็อกสั่งบอร์ด **Arduino Uno** บอร์ดเดียว ดูโค้ดเป็น Arduino C++ (อ่านอย่างเดียว) ทดสอบโดยไม่ต้องมีบอร์ดด้วยตัวจำลองบอร์ดแบบต่อสายอิสระ (แนว Tinkercad) และ stage มาสคอต School Bot (แนว mBlock) แล้วส่งลงบอร์ดจริง · พื้นที่เล่นอิสระ ไม่มีภารกิจ (บทเรียนอยู่ใน Quiz) · รีดีไซน์จาก Mixly · frame ฐาน: Main-1D (ร่าง ต้องทำใหม่ตามรอบ CHG-07)

## Requirements
ลำดับ: M = Must · ? = ยังไม่ยืนยัน · Future = นอก MVP

- R1 (M): เขียนโปรแกรมแบบบล็อกให้บอร์ด **Arduino Uno บอร์ดเดียว** ตัด รวม หรือเพิ่มบล็อกให้เหมาะกับบอร์ดนี้โดยไม่ custom ลึกเกิน · หมวดบล็อก **10 หมวด Confirmed**: เริ่มต้น · ควบคุม · ตรรกะ · คณิต · ตัวแปร · ขาสัญญาณ · เสียง · มอเตอร์ (servo) · สื่อสาร (Serial) · Stage · **ไม่มีหมวดแขนกล** · รายการเก็บ/เพิ่ม/ตัดต่อหมวดอยู่ใน §ตารางหมวดบล็อก ด้านล่าง · บล็อกที่ต้องใช้อุปกรณ์ (servo, buzzer ฯลฯ) ต้องมีอุปกรณ์ตรงกันในตัวจำลอง · การจับคู่บล็อกรายตัวจาก 126 บล็อกของ Main-1D → OQ4 · (FR-15, DEC-10, DEC-20, CON-02, AC-10)
- R2 (M): หลักการต่อบล็อก: UI คลีนแบบ mBlock · รูปทรงมีความหมายแบบ micro:bit (**มน = ค่า, หกเหลี่ยม = เงื่อนไข**) · ช่องหกเหลี่ยมรับเฉพาะบล็อกหกเหลี่ยม · "ถ้า" มีปุ่ม ⊕/⊖ · เลิกทำได้ 60 ขั้น · มี hat 2 แบบ แต่ **setup ("เริ่มต้น") และ loop ("วนทำซ้ำ") อย่างละ 1 บล็อกต่อโปรแกรม** (แก้ BUG-15) · บล็อกที่ไม่ได้ต่อใต้ setup/loop แสดงลายเทาปิดใช้ แต่ต้องอ่านได้ (BUG-14) · หลักรูปทรงต้องรักษาไว้ (context.md §สิ่งที่ต้องรักษา) · (FR-16, AC-10, EV-04, EV-05)
- R3 (M): แผง "ดูโค้ด" แสดง **Arduino C++** แบบอ่านอย่างเดียว ตรงกับบล็อก แก้ไม่ได้ · ตัวสร้างโค้ดของ frame เดิม (Python/MicroPython, `blk_r… # ❓`) ต้องทำใหม่ทั้งชุดสำหรับ Uno + C++ (CF-01, RSK-01) · ใส่ `Serial.begin` ใน `setup` ให้อัตโนมัติเมื่อมีบล็อก Serial print (ARC-I27 · Proposed → DEV-Q14 · OQ16) · (FR-17, DEC-10, AC-11)
- R4 (M): **ตัวจำลองบอร์ดแบบ Tinkercad ต่อสายอิสระ** ดูเหมือนจริง ต่อง่าย แสดงค่าไฟ/กระแส · งานใหม่เริ่มจาก **Uno + breadboard เปล่า** · ชุดอุปกรณ์ขั้นต่ำ (Confirmed ARC-I09): Uno, breadboard, LED, ตัวต้านทาน, ปุ่มกด, buzzer, potentiometer, servo 1 ตัว, ไฟ RGB · การกระทำ: ลากอุปกรณ์จากแผงอุปกรณ์ · ต่อสายจากขาถึงขา · ย้าย หมุน ลบอุปกรณ์/สาย · ตั้งค่าอุปกรณ์ (เช่น ค่าตัวต้านทาน สี LED · Delegated → OQ13) · เลิกทำ · ใช้ไลบรารีจำลอง AVR (ไม่สร้างเอง · DEV-Q04) · **วงจรบันทึกกับงานบน cloud** และเป็น "แบบให้ดู" (แอปตรวจสายจริงบนบอร์ดไม่ได้) · งานว่าง (ST-40) ต้องมีข้อความบอกวิธีเริ่ม · (FR-18, DEC-11, DEC-21, DEC-27, AC-12, RSK-06)
- R5 (M): **จำลองความเสียหายสมจริง** (เช่น LED ไม่มีตัวต้านทาน, ลัดวงจร) · เมื่ออุปกรณ์เสีย: **หยุดจำลอง · อุปกรณ์ที่เสียแสดงสถานะนิ่ง · บอกสาเหตุ+วิธีแก้ภาษาเด็ก · ปุ่ม "เปลี่ยนอุปกรณ์ใหม่"** · **ห้ามกะพริบ ห้ามเอฟเฟกต์ระเบิด** (WCAG 2.3.1) · ชนิดความเสียหายที่ทำได้จริงและระดับค่ากระแส (ปกติ/เกิน หรือรายอุปกรณ์) Unknown → OQ1 (DEV-Q13) · ออกแบบเผื่อ: รูปแบบ "อุปกรณ์เสีย" ทั่วไป 1 ชุด + ข้อความ 2 กรณี (LED ไม่มีตัวต้านทาน, ลัดวงจร) · (DEC-22, EC-08, AC-16, ST-29, ARC-I22)
- R6 (M): ระหว่างจำลอง **โต้ตอบอุปกรณ์รับค่า** ได้: คลิกค้างที่ปุ่มกด, ลากหมุน potentiometer · ใช้คีย์บอร์ดได้ (Proposed ARC-I30: โฟกัสอุปกรณ์ได้ · Space/Enter ค้าง = กดปุ่ม · ลูกศร = หมุน potentiometer · เห็นค่าปัจจุบันเป็นตัวเลข) · ผลเปลี่ยนตามทันที · (FR-31, DEC-28, AC-16, ST-41)
- R7 (M): **Stage** แอนิเมชันที่ขยับตามโปรแกรมแบบ mBlock · ตัวละคร = **มาสคอต School Bot 1 ตัว** (10 ท่าเท่านั้น ห้ามวาดเอง · DEC-30) ขยับ พูด และเปลี่ยนท่า · บล็อก "เปลี่ยนท่า" เลือกได้จาก 10 ท่า · บล็อก "พูด" ต้องจำกัดความยาว/ตัดบรรทัด (3 ภาษา · ARC-I33 Delegated → Designer · OQ14) · รีเซ็ตตำแหน่งตัวละครได้ · ข้อความกำกับท่าเสมอ ไม่สื่อด้วยภาพอย่างเดียว ไม่กะพริบ (AC-19) · **บล็อก Stage ทำงานเฉพาะในจอ** · การจับคู่ท่ากับสถานการณ์ใช้ตาราง `../../brand.md` §8 (Proposed) · (FR-19, FR-32, DEC-23, DEC-26, DEC-29, DEC-30, AC-12, AC-18, AC-19, ENT-27)
- R8 (M): **แผง "ข้อความจากบอร์ด"** ใต้ตัวจำลอง/stage (เห็นทั้งสองแท็บ) แสดงผลจากบล็อก Serial print ทั้งตอนจำลองและตอนต่อ Uno จริง · ป้ายบอกแหล่ง (จำลอง / Uno จริง) · ล้างข้อความได้ · เลื่อนดู · หยุดเลื่อนอัตโนมัติ + ย่อ/ขยายแผง (Delegated) · ล้างเมื่อเริ่มจำลองใหม่หรือส่งลงบอร์ดใหม่ (Proposed) · **ไม่บันทึกกับงาน** (Proposed) · จำกัดจำนวนบรรทัดล่าสุด (Delegated → dev · OQ10) · ตอนต่อ Uno จริงอ่านอัตโนมัติหรือต้องกดเปิดอ่าน Unknown → OQ2 (DEV-Q14) · (FR-30, DEC-24, AC-17, SCR-26)
- R9 (M): **เชื่อม Uno + ส่งลงบอร์ด + หยุดทั้งหมด** · ส่งโปรแกรมที่ compile แล้วผ่าน USB (ฝัง toolchain ใน installer ไม่ต้องติดตั้ง driver · DEV-Q03 Answered) · สถานะครบ: ไม่พบบอร์ด / กำลังแปลงโค้ด / กำลังส่ง / ส่งสำเร็จ / ส่งไม่สำเร็จหรือแปลงโค้ดไม่ผ่าน (ข้อความภาษาง่าย + ลองใหม่) · **ก่อนส่งทุกครั้งเตือนให้ต่อสายจริงตามวงจรในจอ** (มีตัวเลือก "ไม่ต้องเตือนอีกในงานนี้" · เตือนใหม่เมื่อวงจรเปลี่ยน) · ส่งได้แม้มีบล็อก Stage (ข้ามบล็อก Stage ไม่แปลงเป็นโค้ด) แล้วแจ้ง **"บล็อกตัวละครทำงานเฉพาะในจอ"** (ไม่ใช่ error) · **"หยุดทั้งหมด"** หยุดตัวจำลองและ stage ทันที · ผลต่อโปรแกรมบน Uno ที่รันอยู่ Unknown → ห้ามสื่อว่าบอร์ดหยุดแล้ว (OQ3 · DEV-Q16) · ปุ่มแถบล่าง: **หยุดทั้งหมด (ซ้าย)** / **ส่งลงบอร์ด (ขวา)** · (FR-20, DEC-23, DEC-27, AC-11, AC-18, EC-07, EC-09, ST-30, 32–34, 45–47)
- R10 (M): **เริ่มจำลองครั้งเดียว ตัวจำลองและ stage ทำงานพร้อมกัน** แท็บแค่สลับมุมมอง (Confirmed ผู้ใช้ 2026-10-21 · ARC-I24) · ปุ่มเริ่ม/หยุดร่วมที่ SCR-16 · ปุ่มหยุดเห็นตลอด · แก้วงจรหรือบล็อกระหว่างจำลอง → หยุดจำลองอัตโนมัติแล้วแจ้งให้เริ่มใหม่ (Proposed ARC-I28 · OQ8) · (ST-28, FR-18, FR-19)
- R11 (M): **โครงหน้าและพื้นที่เล่นอิสระ:** SCR-16 พื้นที่ต่อบล็อก + ดูโค้ด · แท็บ ตัวจำลอง (SCR-17) / stage (SCR-18) · แผงข้อความ (SCR-26) อยู่ใต้พื้นที่แท็บ · แถบล่าง หยุดทั้งหมด / ส่งลงบอร์ด · **ไม่มีแถบภารกิจ** (DEC-25 · ตัดแถบภารกิจของ Main-1D) · พื้นที่หน้าจอ **1440×856** (แถบหน้าต่าง 44 · CR-09) · ใส่แถบหน้าต่างที่มีชิปอุปกรณ์ "Uno" เฉพาะใน lab (CR-08 Confirmed · ต้องทำตาม CR-10 ก่อน) · **ต้องมี "งานใหม่" (Ctrl+N สร้างในหน้าเดิม งานเดิมบันทึกก่อนสลับ · ถ้าบันทึก/sync ไม่สำเร็จใช้ leave guard เดียวกับ "งานของฉัน") และ "งานของฉัน" (→ my-work · SCR-09 Block) แบบเดียวกับ Arm Lab** · ตำแหน่งปุ่มงานใหม่ Delegated → OQ7 · สถานะบันทึกงาน = ตัวหนังสือเขียวใต้ชื่องานแบบ Arm Lab ไม่มีป้ายคลาวด์ในหน้า (ผู้ใช้ 2026-10-21 · EDIT-09) · งานบันทึกบน cloud (my-work · FR-22–24) · (FR-15, DEC-25, CR-07, SCR-16)
- R12 (M): UI เดียวกัน ป.1–6 · เป้า WCAG 2.2 AA + เกณฑ์เด็ก (`../../context.md`) · ไม่มีตัวช่วยเพิ่มสำหรับ ป.1–3 (DEC-19) · ความเสี่ยงที่ผู้ใช้ทราบแล้ว (RSK-09): ต่อสายอิสระ + ความเสียหายโดยไม่มีตัวช่วย อาจทำให้เด็กเล็กท้อ → ลดด้วยข้อความว่างบอกวิธีเริ่ม (ST-40) และข้อความสาเหตุเสียที่บอกวิธีแก้ เท่านั้น (ARC-I34) · ลากต้องมีทางเลือกที่ไม่ต้องลาก (เกณฑ์ตรวจ WCAG 2.5.7) · (NFR-02, DEC-06, DEC-19, RSK-09)
- R13 (Future): สั่งแขนกลจาก Block Lab ผ่านการแปลงโค้ด **นอก MVP เลื่อนไปรอบถัดไป** · MVP ไม่มีหมวดบล็อกแขนกล (FR-21, DEC-17, DEC-12 Superseded) · คำถามค้างสำหรับรอบหน้า: จะแปลงโค้ดสั่งแขนผ่าน Uno หรือส่งตรงไป Raspberry Pi → OQ12

## ตารางหมวดบล็อกสำหรับ Uno (Confirmed DEC-20 · ไม่มีแถบภารกิจ DEC-25)

| หมวด | เก็บ / เพิ่ม | ตัดจาก Main-1D |
|---|---|---|
| เริ่มต้น | `setup` (เริ่มต้น) และ `loop` (วนทำซ้ำ) อย่างละ 1 บล็อกต่อโปรแกรม (แก้ BUG-15) | บล็อกเริ่มที่ซ้ำ |
| ควบคุม | รอ (ms), ทำซ้ำ n ครั้ง, ทำซ้ำตลอด, ถ้า/ไม่เช่นนั้น (⊕/⊖), ทำซ้ำจนกว่า, หยุดโปรแกรม (1 บล็อก แก้ BUG-20) | บล็อกเธรด/ตัวจับเวลาของ ESP32 |
| ตรรกะ | เปรียบเทียบ, และ, หรือ, ไม่, จริง/เท็จ (หกเหลี่ยม) | - |
| คณิต | ตัวเลข, + − × ÷, สุ่ม, map, constrain | ฟังก์ชันคณิต Python เฉพาะ |
| ตัวแปร | สร้าง, ตั้งค่า, เพิ่มค่า | ตัวแปรแบบ list/dict ของ Python |
| ขาสัญญาณ | digitalWrite (dropdown สูง/ต่ำ แก้ BUG-17), digitalRead, analogRead, analogWrite (PWM) | ขาเฉพาะ ESP32/MixGo, touch pin |
| เสียง | tone, noTone | เพลงสำเร็จรูปของ MixGo |
| มอเตอร์ | servo (ขา, มุม) | มอเตอร์บนบอร์ด MixGo |
| สื่อสาร | Serial print → แผงข้อความจากบอร์ด (SCR-26 · DEC-24) · `Serial.begin` ใส่อัตโนมัติ (ARC-I27 Proposed) | WiFi, Bluetooth, MQTT, IoT |
| Stage | ขยับ, พูด, เปลี่ยนท่า (เลือกจาก 10 ท่าของมาสคอต · DEC-30) · ทำงานเฉพาะในจอ ข้ามเมื่อส่งลงบอร์ด (DEC-23) | - |
| แขนกล | **ตัดออก** (FR-21 นอก MVP · CR-02) | - |

อุปกรณ์รับค่า: ปุ่มกด → `digitalRead`, potentiometer → `analogRead` โต้ตอบได้ระหว่างจำลอง (DEC-28)

## กฎ/Logic (AC เดิมย่อ)
- AC-10: รายการบล็อกมีเฉพาะสิ่งที่ Uno ทำได้ และรูปทรงบอกหน้าที่ (มน/หกเหลี่ยม)
- AC-11: **When** เปิดดูโค้ด **Then** เห็น Arduino C++ ที่ตรงกับบล็อกและแก้ไม่ได้ · ส่งลงบอร์ดและหยุดใช้ได้เมื่อเชื่อมต่อ Uno แล้ว
- AC-12: **When** กดทดสอบโดยไม่มีบอร์ด **Then** ตัวจำลองหรือ stage แสดงผลตามโปรแกรม · **Given** งานใหม่ **Then** ตัวจำลองเริ่มจาก Uno + breadboard เปล่าและต่อสายเองได้ · วงจรยังอยู่เมื่อเปิดงานอีกครั้ง
- AC-16: **When** จำลองแล้วอุปกรณ์เสีย **Then** การจำลองหยุด เห็นอุปกรณ์ที่เสีย สาเหตุ และปุ่มเปลี่ยนอุปกรณ์ใหม่ โดยไม่มีแสงกะพริบ · **When** กำลังจำลอง **Then** กดปุ่มกดหรือหมุน potentiometer ได้ทั้งเมาส์และคีย์บอร์ด และผลเปลี่ยนตาม
- AC-17: **When** โปรแกรมมี Serial print **Then** ข้อความแสดงในแผงข้อความจากบอร์ด ทั้งตอนจำลองและตอนต่อ Uno
- AC-18: **When** ส่งลง Uno และมีบล็อก Stage **Then** ส่งสำเร็จได้ และเห็นข้อความว่าบล็อกตัวละครทำงานเฉพาะในจอ · **When** กดส่งลงบอร์ด **Then** เห็นการเตือนให้ต่อสายจริงตามวงจรในจอ
- AC-19: มาสคอตในหน้าใดก็ตามใช้เฉพาะ 10 ท่า ข้อความกำกับบอกความหมายเสมอ ภาพตกแต่ง alt ว่าง ภาพที่มีความหมายมี alt ไม่กะพริบ
- ถ้อยคำ: Block Lab ใช้ **"ส่งลงบอร์ด"** (frame เดิมเขียน "ส่งลงหุ่น") · Arm Lab ใช้ "อัปโหลดลงบอร์ด" · ชื่อ "Block Lab" ห้าม "Block Studio"/"Code Lab" (CF-05, BUG-19)

## Edge cases
- EC-07 ส่งโปรแกรมที่มีบล็อก Stage ลง Uno จริง: ส่งได้ · บล็อก Stage ไม่ถูกแปลงเป็นโค้ด · แจ้งสั้น ๆ "บล็อกตัวละครทำงานเฉพาะในจอ" (Confirmed DEC-23)
- EC-08 อุปกรณ์ในตัวจำลองเสีย (เช่น LED ไม่มีตัวต้านทาน): หยุดจำลอง · อุปกรณ์แสดงสถานะเสีย · บอกสาเหตุและวิธีแก้ภาษาเด็ก · ปุ่ม "เปลี่ยนอุปกรณ์ใหม่" · ไม่กะพริบ ไม่มีเอฟเฟกต์ระเบิด (Confirmed DEC-22 · ระดับ OQ1)
- EC-09 ส่งลง Uno จริงแต่สายจริงต่อไม่ตรงกับวงจรในจอ: แอปตรวจสายจริงไม่ได้ · ก่อนส่งแจ้งให้ต่อสายตามวงจรในจอ (Confirmed DEC-27)
- EC-01/EC-04 เน็ตหลุด/เปลี่ยนเครื่อง: ดู my-work (FR-22–24 · ฉบับใหม่กว่าชนะ) · ENT-17 ต้องรวมวงจรใน export ของ Block (รูปแบบไฟล์ → OQ5)
- EC-06 เด็ก ป.1 อ่านไม่ออก: ไม่มีตัวช่วยเพิ่ม (R12)
- แก้วงจร/บล็อกระหว่างจำลอง: หยุดอัตโนมัติ (R10 · Proposed)
- CF-01 Block Lab ใน frame (ESP32/MixGo/Python/แถบภารกิจ) ขัด requirement → ต้องทำรายการบล็อกและตัวสร้างโค้ดใหม่ทั้งชุด ตัดแถบภารกิจ (Open → Designer แก้ใน Canvas C · หมวดยืนยันแล้ว DEC-20)
