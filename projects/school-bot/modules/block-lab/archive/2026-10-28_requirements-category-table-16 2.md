# ตารางหมวด 16 หมวด (เลิกใช้ 2026-10-28 · แทนด้วย OQ156–OQ166)

## ตารางหมวดบล็อกสำหรับ Uno (16 หมวดตาม R18 · ไม่มีแถบภารกิจ DEC-25)

การจับคู่บล็อกอุปกรณ์เข้าหมวด Servo/Sound/Sensor/Light **ผู้ใช้ยืนยันแล้ว 2026-10-22** (OQ61 · ปุ่มกดอยู่หมวด Sensor) · บล็อกรายตัวยัง Delegated → Designer + dev (OQ4) · บล็อกอุปกรณ์ใช้ "เลือกอุปกรณ์" แทนเลขขา (R16 · OQ54)
