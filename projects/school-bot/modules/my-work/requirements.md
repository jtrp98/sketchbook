# my-work (งานของฉัน · บันทึก · cloud · sync): Requirements (จาก role 1)

> นำเข้าจากระบบเก่า (`Handoff/01_REQUIREMENT` v3.1 · `02_FEASIBILITY` v3–v4 · `03_DESIGN` v10) 2026-10-21 · **sketchbook เป็นแหล่งความจริงแล้ว** · ID เดิม (FR/AC/ST/SCR/ENT/ARC-I/DEV-Q/CR/EDIT/FRM) อยู่ในวงเล็บเพื่อ grep · ป้ายหลักฐานดู `../../context.md`
> module นี้เป็นเจ้าของ: หน้ารวมงานตามโปรแกรม, การบันทึกบน cloud, ออฟไลน์/sync, export/import, กู้คืนสำรอง · arm-lab R6–R9 และ block-lab เป็นด้านของ lab แต่ละตัว อ้าง FR-22–25 เหมือนกัน

## เป้าหมาย
นักเรียนจัดการงาน Arm Lab และ Block Lab ของตัวเองได้ในหน้าของแต่ละโปรแกรม: งานบันทึกบน cloud ผูกกับบัญชี (แทนโฟลเดอร์ในเครื่อง/USB ของ 6A เดิม) ส่งออก/นำเข้าไฟล์ได้ กู้คืนสำรองในเครื่องได้ และทำงานต่อได้เมื่อเน็ตหลุด

## Requirements
ลำดับ: M = Must · ? = ยังไม่ยืนยัน (ดู OQ)

- R1 (M): งานของนักเรียน**บันทึกบน cloud ผูกกับบัญชีเป็นค่าเริ่มต้น** บันทึกอัตโนมัติหรือเมื่อกดบันทึก · แทนตัวเลือกโฟลเดอร์ "งานเก็บไว้ที่…" (ในเครื่อง/USB) ของ 6A (CF-03 → แก้ผ่าน CR-05 Closed 2026-10-21) · เปลี่ยนเครื่องแล้วเปิดงานต่อจาก cloud ได้ (EC-04) · ความถี่บันทึกอัตโนมัติ Unknown → OQ2 · (FR-22, AC-13, DEC-13, CHG-03)
- R2 (M): **export งานเป็นไฟล์ได้** · Arm Lab = ไฟล์ `.ini` ที่เปิดใน Zide ได้ (ผู้ใช้ตอบ 2026-10-20) · Block Lab = รูปแบบแยก (ชื่อนามสกุล `.sbb` เป็นค่าชั่วคราว ถาม dev) และ**ต้องรวมวงจรของตัวจำลอง** · เมนู export แยกตามประเภทงาน · ใช้คำ "ส่งออกเป็นไฟล์ .ini" · (FR-23, AC-13, ARC-I07, DEV-Q06) → OQ5
- R3 (M): **กู้คืนงานสำรองที่อยู่ในเครื่อง** · แอปสำรองอัตโนมัติ (6A ทุก 10 วินาที · Observed EV-03) · เมื่อเปิดโปรแกรมหลังปิดผิดปกติและพบสำรองใหม่กว่าบน cloud → dialog ให้ "กู้คืน" หรือ "ทิ้ง" · (FR-24, SCR-10, ST-18, ENT-18, EC-01, AC-13)
- R4 (?): **นำท่าหรืองานจากไฟล์ .ini เข้ามาได้** · Inferred จาก frame (Ctrl+A) · frame ปัจจุบันทำปุ่ม "นำเข้าไฟล์…/นำเข้าจากไฟล์ .ini…" แล้ว · → OQ4 · (FR-25, OQ-08 Delegated → Architect)
- R5 (M): **หน้า "งานของฉัน" แยกตามโปรแกรม** (Arm Lab / Block Lab โครงเดียว 2 ชุด **ไม่มีหน้ารวม**) เข้าจาก sidebar ของหน้าหลักและจาก ☰ › งานของฉัน ในตัวแก้ไข · ทำได้: สร้าง เปิด เปลี่ยนชื่อ ทำสำเนา ลบ ส่งออก นำเข้า ค้นหาชื่อ · แสดง: ชื่อ เวลาแก้ล่าสุด สถานะ sync (กรองประเภทตามหน้า) · (SCR-09, FR-22–25, CF-03, CR-05, CR-06, ARC-I17, ENT-13)
- R6 (M): **การสร้างงานใหม่:** ทำได้ที่หน้า "งานของฉัน" ของแต่ละ lab (จุดสร้างหลัก) และ**ในตัวแก้ไขของ lab นั้นด้วย "งานใหม่" (Ctrl+N) สร้างงานใหม่ในหน้าเดิม** · **หน้าหลักไม่มีปุ่มสร้างงาน** (กลุ่มงานล่าสุดที่ว่างมีข้อความ + ปุ่มรอง "ไปที่ Arm Lab / Block Lab") · งานเดิมบันทึกก่อนสลับ · ถ้าบันทึกหรือ sync ไม่สำเร็จ ใช้ leave guard เดียวกับ ☰ › งานของฉัน · Block Lab (SCR-16) ต้องมี "งานใหม่" และ "งานของฉัน" แบบเดียวกับ Arm Lab (ตำแหน่ง Delegated → Designer) · "ที่เดียว" ในข้อความเดิมหมายถึงเทียบกับหน้าหลักเท่านั้น · (CR-06, CR-07, ST-10)
- R7 (M): **ออฟไลน์และ sync (cloud เป็นที่เก็บหลัก):** ทำงานต่อได้เมื่อเน็ตหลุด ไม่เสียงาน (EC-01) · สถานะการบันทึกมี 4 แบบ ไอคอน + ข้อความทุกแบบ (ไม่ใช้สีอย่างเดียว) แสดงที่**แถบหน้าต่างที่เดียว**: บันทึกขึ้นคลาวด์แล้ว / กำลังบันทึกขึ้นคลาวด์ / ไม่มีเน็ต · เก็บงานในเครื่องไว้ก่อน / บันทึกขึ้นคลาวด์ไม่สำเร็จ (ลองอีกครั้ง + รหัส E-CLOUD) · บนการ์ดงานแสดงป้ายเฉพาะงานที่รอ sync / sync ไม่สำเร็จ · Proposed: login ต้องออนไลน์ · บันทึกลงเครื่องก่อนแล้ว sync เมื่อเน็ตกลับมา · คะแนน Quiz เข้าคิวรอส่ง · Arm Lab สั่งหุ่นได้แม้ออฟไลน์ (หุ่นต่อ USB) · (NFR-06, ARC-I05, ST-03, ST-17, DEV-Q05)
- R8 (M): **งานชนกัน = "ฉบับใหม่กว่าชนะ"** (ไม่มีหน้าจัดการงานชน · SCR-11 ยกเลิก) · เมื่อเปิดงานที่ถูกแทนด้วยฉบับใหม่กว่า แสดงข้อความแจ้งสั้น ๆ "ถูกแทนด้วยฉบับใหม่กว่า" · นิยาม "ใหม่กว่า" ไม่ระบุในต้นฉบับ → OQ2 · (ARC-I06, EC-04, DEV-Q05)
- R9 (M): **dialog "นำท่าจากงานอื่นมาต่อ" (Arm Lab)** เป็น dialog ของแอป (ไม่ใช่หน้าต่างเลือกไฟล์ของระบบ): รายการงานของฉันบน cloud + ปุ่ม "นำเข้าจากไฟล์ .ini…" · ไม่มีเน็ต → แถบเตือน ใช้ได้เฉพาะนำเข้าไฟล์ · ปุ่ม "นำท่ามาต่อ" ใช้ `aria-disabled` + บอกเหตุผล · dialog เว้นแถบล่าง 76px (ไม่บังปุ่มหยุด) · (EDIT-04, FR-25, CR-05)
- R10 (M): **งาน Block บันทึกวงจรไปกับงานบน cloud:** บล็อก ตัวแปร วงจรในตัวจำลอง (อุปกรณ์ ตำแหน่ง การหมุน ค่าอุปกรณ์ สาย) และการตั้งค่า "ไม่ต้องเตือนต่อสายอีกในงานนี้" บันทึกกับงาน · วงจรเป็นแบบให้ดู (แอปตรวจสายจริงไม่ได้) · สถานะการจำลอง (ENT-26) และข้อความจากบอร์ด (ENT-25) **ไม่บันทึกกับงาน** (Proposed) · เนื้อหาบล็อก/วงจรเป็นของ block-lab · (ENT-17, DEC-27, DEV-Q06)
- R11 (M): **ข้อมูลเด็กบน cloud เท่าที่จำเป็น:** เก็บเท่าที่จำเป็น (ชื่อ ห้อง ผลด่าน งาน) ไม่มีหน้ายินยอม · ผู้ใช้ยอมรับความเสี่ยง (ARC-I14 · ไม่ใช่คำปรึกษากฎหมาย) · งาน Arm/Block ไม่มีคะแนน ไม่ส่งเข้า SchoolBright ไม่แสดงบนเว็บครู (DEC-18) · (NFR-05, RSK-05, OQ8)

## พฤติกรรมที่ออกแบบและอนุมัติแล้ว (FRM-03 MyWorkV1 · Canvas A · ผู้ใช้อนุมัติ 2026-10-21)
Observed จาก EDIT_LOG ระบบเก่า (อ่านโค้ด ทดสอบ render 16 ภาพ ไม่ได้ดูบน canvas จริง) ต้องรักษาไว้เมื่อแก้ผ่านใบสั่งแก้:
- หัวหน้า: ไอคอนสีประจำแอป (D-04) + ชื่อโปรแกรม (Arm Lab / Block Lab) · ช่องค้นหาชื่องาน · ปุ่มหลัก "สร้างงานใหม่" · ปุ่มนำเข้าไฟล์ .ini / ไฟล์งาน (FR-25)
- รายการเป็นการ์ด 3 คอลัมน์ **เลื่อนเฉพาะแผงรายการ** ไม่เลื่อนทั้งหน้า (D-15) · ป้าย sync บนการ์ดเฉพาะงานที่รอ/ไม่สำเร็จ (ST-17)
- ปุ่ม ⋯ ขนาด 44px เห็นตลอด (แท็บเล็ตไม่มี hover) เมนู: เปิดงาน · เปลี่ยนชื่อ (ในการ์ด · error ชื่อว่าง / ชื่อซ้ำ) · ทำสำเนา · ส่งออก .ini · ลบ → **toast + เลิกทำ ไม่มี pop-up ยืนยัน** (ขัดกับ ARC-I17 "ยืนยันก่อนลบ" → ยึด frame ที่อนุมัติ ดู OQ6) · Esc ปิดเมนู / ยกเลิกการเปลี่ยนชื่อ
- สถานะ: ว่าง (ST-10) "สร้างงานแรก" · ค้นหาไม่เจอ · แจ้งงานถูกแทนด้วยฉบับใหม่กว่า (EC-04)
- **หลัง EDIT-09 (ผู้ใช้ตัดสิน 2026-10-21):** ตัดป้ายคลาวด์รวมและปุ่มลองบันทึกขึ้นคลาวด์ออกจากหน้านี้ (ย้ายไป popover ของแถบหน้าต่าง) · การ์ดตัดบรรทัด "บันทึกขึ้นคลาวด์แล้ว · เวลา" → เวลาไปต่อท้ายบรรทัดรายละเอียด · คงบรรทัดเฉพาะงานที่ยังไม่ขึ้นคลาวด์/ไม่สำเร็จ (ST-17)
- ถ้อยคำสถานะใต้ชื่องาน (ตัวหนังสือเขียว ใช้ทั้ง Arm Lab และ Block Lab): "บันทึกแล้ว 10:20" / "… · มีแก้ไขใหม่" (ตัดกรณีออฟไลน์ เพราะแถบหน้าต่างบอกแล้ว)
- ชื่อคำสั่ง ☰ ใน Arm Lab (EDIT-04): "บันทึกงาน" (Ctrl+S) · "บันทึกสำเนา…" · "ส่งออกเป็นไฟล์ .ini" · ห้ามเขียน "บันทึก" คำเดียว / "อัปโหลด" / "Sync" (`../../brand.md` §7)
- sidebar ใช้ component HomeRail ร่วมกับหน้าหลัก (เป็นของ app-shell)

## กฎ/Logic
- **AC-13:** งานบันทึกบน cloud อัตโนมัติหรือเมื่อกดบันทึก · export .ini ได้ · กู้คืนสำรองในเครื่องได้
- **AC-04 (ส่วนงานล่าสุด · ของ app-shell):** หน้าหลักแสดงงานล่าสุดแยก 2 กลุ่ม Arm Lab / Block Lab เรียงเวลาแก้ล่าสุด กลุ่มละ ≤ 3 ใบ "ดูทั้งหมด →" ไปหน้างานของฉันของโปรแกรมนั้น · ไม่มีปุ่มสร้าง
- งาน Arm/Block ไม่มีคะแนน และไม่ส่งเข้า SchoolBright (DEC-18) · เว็บครูไม่แสดงงาน Lab ใน MVP
- สถานะ sync ใช้ถ้อยคำ "บันทึกขึ้นคลาวด์" (ไม่ใช้ Sync/อัปโหลดคำเดียว) · error มีรหัส + วิธีแก้ (E-CLOUD)

## การตัดสินใจที่ผูกกับ module
DEC-13 งานบันทึกบน cloud เป็นหลัก export .ini ได้ กู้คืนสำรองได้ (CHG-03) · DEC-14 ครูจัดการผ่านเว็บ (งานนักเรียนไม่เกี่ยว) · DEC-18 งาน Lab ไม่มีคะแนน · DEC-27 วงจรในตัวจำลองบันทึกกับงานบน cloud และเป็นแบบให้ดู · CHG-03 (2026-10-20): การเก็บงานเปลี่ยนจาก "cloud อย่างเดียว" เป็น cloud เป็นหลัก + export .ini + กู้คืนสำรองในเครื่อง

## Edge cases
- EC-01 เน็ตหลุดระหว่างทำงาน: ไม่เสียงาน มีสำรองในเครื่องให้กู้คืน (R3, R7) · รายละเอียด OQ2
- EC-04 เปลี่ยนเครื่องคอมพิวเตอร์: เปิดงานต่อจาก cloud (R1) · ถ้ามีฉบับใหม่กว่า ฉบับใหม่กว่าชนะ + แจ้ง (R8)
- ปิดโปรแกรมตอนยังไม่ได้บันทึกขึ้นคลาวด์: แถบหน้าต่างแจ้งว่างานอยู่ในเครื่อง (ของ app-shell)
- เปิดโปรแกรมหลังปิดผิดปกติ: พบสำรองใหม่กว่า cloud → R3
- ลบงานโดยพลาด: toast + เลิกทำ (ระยะเวลาเลิกทำ Unknown → OQ6)
- ความขัดแย้งในต้นฉบับ: CF-03 (6A เก็บแบบโฟลเดอร์ ขัด cloud) แก้แล้วผ่าน CR-05 · ARC-I17 ยืนยันก่อนลบ vs FRM-03 toast + เลิกทำ (OQ6)
