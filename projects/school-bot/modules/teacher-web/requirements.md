# เว็บครู School Bot: Requirements (จาก role 1)

> นำเข้าจากระบบเก่า (`Handoff/01_REQUIREMENT` v3.1, `02_FEASIBILITY` v3 รวมคำตอบผู้ใช้ถึง 2026-10-21) · **sketchbook เป็นแหล่งความจริงแล้ว** ไม่ต้องเปิดโฟลเดอร์เดิม · ID เดิม (FR/NFR/EC/AC/DEC/ST/SCR/ENT/ARC-I/DEV-Q) เก็บในวงเล็บเพื่อ grep · ป้ายหลักฐานดู `../../context.md`
> ใช้คำตอบล่าสุดของผู้ใช้จาก feasibility รอบ 2 (2026-10-20) แม้ `04_DECISIONS` เดิมยังเปิดอยู่ (บันทึกไว้ใน `oq.md`)

## เป้าหมาย
ครูในโรงเรียนลูกค้า SchoolBright ใช้เว็บ School Bot (แยกต่างหากจากแอปนักเรียน เปิดผ่านเบราว์เซอร์) เพื่อ **ดูความคืบหน้าและคะแนน Quiz ของนักเรียนรายเทอมและรายปี จัดตามห้อง** · **ตั้งค่า** (เปิด/ปิดหน่วย เวลาเปิดด่าน ดูเครื่องและหุ่น) · **แก้ปัญหาหุ่น** (คู่มือ + สถานะหุ่นที่แอปรายงาน) · ครูจัดการทุกอย่างผ่านเว็บ ส่วนแอปเป็นพื้นที่ของนักเรียน ยกเว้นโหมดครูของ Arm Lab (DEC-14 · อยู่ module `arm-lab`)

## Requirements
ลำดับ: M = Must · ? = ยังไม่ยืนยัน (ดู OQ)

- R1 (M): ครู login เข้าเว็บด้วย**บัญชี SchoolBright** (SSO ปุ่มเดียว) · ลืมรหัส → ส่งไปที่ SchoolBright · MVP มีบทบาท**ครูอย่างเดียว** (ผู้บริหารอาจมีในอนาคต) · รหัสผิดแสดงข้อความบอกวิธีแก้ (ST-07) · ดู OQ2, OQ3 · (FR-29, UJ-05, DEV-Q09, SCR-21)
- R2 (M): ตัวกรองช่วงเวลาและห้อง **ปีการศึกษา → เทอม / ทั้งปี → ห้อง อยู่บนสุดของทุกหน้าที่แสดงผล** (บังคับ) · ครูเลือกแล้วเห็นความคืบหน้าและคะแนน Quiz ตามตัวเลือกนั้น ทั้งแบบรายเทอมและรายปี · จัดคะแนนเข้าเทอมด้วยวันเริ่ม–จบของเทอมจาก SchoolBright · ทุกคะแนนเก็บ**เวลาที่ได้ + ห้อง ณ เวลานั้น** (Proposed) · API SchoolBright ยังไม่ทราบ → OQ1 · (FR-26, DEC-15, AC-14, ARC-I01, ENT-05)
- R3 (M): หน้า**ภาพรวมห้อง**: สรุปความคืบหน้าและคะแนน Quiz รายคนของทั้งห้อง · ห้องหนึ่งอาจมีนักเรียน 40+ คน จึงต้อง **ค้นชื่อ · เรียงตามคะแนนหรือความคืบหน้า · กรอง "ยังไม่เริ่ม"** · เปิดรายคนได้ · แสดงเฉพาะผล **Quiz** (ไม่แสดงงาน Arm/Block เพราะไม่มีคะแนน) · ตัวเลขสรุปใช้ ดาว 0–3 ต่อด่าน + คะแนนต่อด่าน + % ด่านที่ผ่าน (Proposed · OQ10) · (FR-26, DEC-18, SCR-22, ARC-I18, ARC-I02)
- R4 (M): หน้า**รายละเอียดนักเรียน**: ผลรายด่านของนักเรียนคนนั้น (ดาว คะแนน) พร้อมสถานะการส่งคะแนนเข้า SchoolBright (รอ/ส่งแล้ว/ล้มเหลว) · ย้อนกลับไปภาพรวมห้องได้ · ใช้ตัวกรองปี/เทอมตามหน้าภาพรวม · (FR-26, SCR-23, ENT-10, ENT-11)
- R5 (M): หน้า**ตั้งค่า**ของครู (MVP 3 รายการที่ผู้ใช้ยืนยัน): (1) **เปิด/ปิดหน่วยบทเรียนรายห้อง** (2) **กำหนดเวลาเปิดด่าน** (3) **ดูรายการเครื่องและหุ่นของห้อง** · บันทึกสำเร็จ/ไม่สำเร็จ แจ้งผล (ST-38) · ผลของการปิดหน่วยแสดงในแอปเป็นด่านล็อก (quiz · ST-11) · รายการอื่นนอกนี้ ผู้ใช้ให้ประเมินเพิ่มตามความเหมาะสมและ Architect ไม่เพิ่มใน MVP · รายละเอียดเวลาเปิดด่าน → OQ7 · (FR-27, ARC-I15, SCR-24, ENT-21)
- R6 (M): หน้า**แก้ปัญหาหุ่น**: คู่มือแก้ปัญหา (ค้นหาหัวข้อได้) + **สถานะหุ่นล่าสุดรายเครื่องที่แอปรายงานขึ้น cloud** (ตอบแล้วว่าได้ DEV-Q08 → A) · เว็บสั่งหุ่นตรงไม่ได้ (หุ่นต่อกับเครื่องนักเรียนผ่าน USB) จึงไม่มีปุ่มสั่งหุ่นบนเว็บ · คำสั่งที่ต้องทำกับเครื่องจริงอยู่ในเมนูครูในแอป (Proposed · OQ14) · ถ้าไม่มีรายงานสถานะ แสดงเฉพาะคู่มือ · (FR-28, ARC-I12, SCR-25, ENT-22)
- R7 (M): **สิทธิ์และข้อมูลเด็ก:** ครูเห็นเฉพาะห้องที่ตัวเองสอน (Proposed · OQ5 · ST-37 เมื่อไม่มีสิทธิ์) · เก็บข้อมูลเด็กเท่าที่จำเป็น (ชื่อ ห้อง ผลด่าน งาน) · **ไม่มีหน้ายินยอม** ผู้ใช้ยอมรับความเสี่ยง (ARC-I14 · ไม่ใช่คำปรึกษากฎหมาย) · (NFR-05, ARC-I14, RSK-05)
- R8 (M): **แพลตฟอร์มและขอบเขตข้อมูล:** เว็บในเบราว์เซอร์ ออกแบบหลักที่ **1280px ขึ้นไป รองรับ 1024px** (layout ยืดได้ · ใช้ Tweak 1024) · 3 ภาษา ไทย / EN / 中文 เผื่อข้อความยาว +40% · **ไม่ใช้มาสคอต** (DEC-29) · แสดงเฉพาะคะแนน Quiz (DEC-18) · ข้อมูลตัวอย่างทดสอบ: ห้อง 45 คน ชื่อไทยยาวสุด ~30 ตัวอักษร · (NFR-02, DSG-01, ARC-I19, ARC-I20, FR-04)

## กฎ/Logic
- AC-14: **When** ครูเลือกปีการศึกษา เทอม และห้อง **Then** เห็นความคืบหน้าและคะแนน Quiz ตามตัวเลือกนั้น ทั้งแบบรายเทอมและรายปี
- ตัวกรองบังคับทุกหน้า: ปี → เทอม/ทั้งปี → ห้อง (SCR-22 ตัวกรองบังคับ · SCR-23 ตามหน้า SCR-22 · SCR-24, SCR-25 กรองตามห้อง)
- ไม่มีข้อมูลในช่วงที่เลือก (เทอมใหม่/นักเรียนยังไม่เล่น) → บอกว่าไม่มีข้อมูลช่วงนี้ (ST-36)
- SchoolBright ล้มเหลว → กำลังโหลด/โหลดไม่สำเร็จ + ลองใหม่ (ST-35)
- ใช้ตารางข้อมูลที่ค้น เรียง กรองได้ และแถวเยอะ (DSG-07 ต้องเพิ่ม component ใหม่)
- login ครูในแอป (Arm Lab) ใช้บัญชี SchoolBright ตัวเดียวกัน (module `arm-lab` · FR-13)
- ดาว 0–3 ต่อด่าน: ≥60% = 1 ดาว · ≥80% = 2 ดาว · 100% = 3 ดาว (ที่มา quiz · ARC-I02 Closed) · เกณฑ์เหรียญยัง Delegated → Designer เสนอ (quiz · DSG-10)

## การตัดสินใจที่ผูกกับ module
- DEC-14 ครูจัดการทุกอย่างผ่านเว็บ School Bot ที่แยกออกมา ซึ่งออกแบบในรอบนี้ ส่วนแอปเป็นพื้นที่ให้นักเรียน
- DEC-15 เว็บครูดูผลได้ทั้งรายเทอมและรายปี จัดตามห้องจาก SchoolBright
- DEC-18 คะแนนที่ส่ง SchoolBright และผลบนเว็บครูมาจาก Quiz อย่างเดียว (CHG-06)
- DEC-29 ไม่ใช้มาสคอตบนเว็บครู
- DSG-01 (ผู้ใช้ตัดสิน 2026-10-20): D-14 ใช้กับแอปเท่านั้น เว็บครูยืดได้ตั้งแต่ 1024px หลัก 1280px · ต้องบันทึกเป็น D ใหม่ใน DECISIONS.md ผ่านเจ้าของ design system (ยังไม่ทำ)

## Edge cases
- ลืมรหัสของครู (EC-02 ส่วนครู): ไปที่ SchoolBright (ST-08) · นักเรียนลืมรหัส → ข้อความ "บอกครูให้ช่วยรีเซ็ต" (Proposed · module `app-shell`) ซึ่งทำให้ต้องรู้ว่าครูรีเซ็ตที่ไหน → OQ8
- ส่งคะแนนเข้า SchoolBright ไม่สำเร็จ (EC-05): เว็บครูต้องแสดงสถานะส่งรายด่าน (R4) · กลไกคิวอยู่ module `quiz`
- เทอมใหม่/ไม่มีข้อมูล (ST-36) · ไม่มีสิทธิ์ดูห้องนี้ (ST-37) · นักเรียนย้ายห้องระหว่างเทอม → OQ9
- ไม่มีรายงานสถานะหุ่น (DEV-Q08 ไม่ทำงาน/ยังไม่มีข้อมูล) → คู่มืออย่างเดียว (R6)
- ความขัดแย้งที่เปิด: CF-06 (เมนูครูในแอปครอบคลุมหลายเรื่อง ขัดกับ "ครูจัดการผ่านเว็บ") → OQ14

คำถามที่ยังไม่ตัดสินอยู่ใน `oq.md`
