## 1. แถบปุ่มล่างตายตัว `sb-actionbar` (OQ25 ข้อ 1 + OQ26)

โครง: `sb-actionbar` = [หยุด] `sb-actionbar-spacer` [รอง][หลัก] · gap `space-3` · padding `space-4`/`space-6` · พื้น `surface` · ขอบบน `border-default` สี `border` · `z-bottombar` 60 · ปุ่มสูง `control-lg` 56 ทุกตัว
- **ซ้ายสุด = ปุ่มหยุด `sb-btn-stop`** ตายตัวทุกสถานะ (ตาม DS: มุมซ้ายล่าง · `radius-lg` · ไอคอน `square` · `z-stop` 70 · ไม่มีสถานะปิดใช้) · ไม่มีปุ่มหยุดใน header
- **ขวา = ปุ่มรอง (`sb-btn-secondary sb-btn-lg`) + ปุ่มหลักตัวเดียว** (`sb-btn-primary sb-btn-lg` หรือ `sb-btn-robot sb-btn-lg` เมื่อกดแล้วหุ่นขยับ) · ช่องปุ่มรองว่างได้เมื่อไม่มีปุ่มรองที่มีความหมาย · ช่องปุ่มหลักไม่ว่างทุกสถานะ
- ไม่มีปุ่มกดได้อื่นในแถบ ยกเว้น Baud rate (ข้อสังเกตข้อ 5)
- ช่อง input ชื่อหุ่น (`sb-input`) และ checkbox (`sb-check`) อยู่ในเนื้อหาเหนือแถบ (แถบมีแต่ปุ่ม)

## 2. Header = แถบ N1 ตาม DS (OQ26 answered)
- แถบบนหน้าเชื่อมต่อ = N1 Lab แบบเชื่อมต่อ (README §11): บ้าน · โลโก้ lab · ปุ่มหน้าต่าง **ไม่มีปุ่มกลับ ไม่มีปุ่มหยุด** (แทนที่คำสั่ง OQ25 ข้อ 2) · "กลับ Arm Lab" อยู่ขวาล่างที่เดียว (ไม่ซ้ำกับ header)
- แถบหน้าต่างใช้ `z-windowbar` 65 (ต่ำกว่า `z-stop` 70 → ปุ่มหยุดไม่ถูกบัง · AUD-F01/CR-10 · ปิด DS gap 6)
- ฉากหลัง dialog ใช้ `sb-scrim-lab` เว้นตำแหน่งปุ่มหยุด (ปุ่มหยุดกดได้ระหว่างมี dialog)
- พฤติกรรมปุ่มหยุดตามสถานะ: เชื่อมอยู่ → ส่งคำสั่งหยุด ห้ามเขียน "หยุดแล้ว" ถ้าไม่มี ack (E-NOREPLY → ข้อความ ST-21) · ยังไม่ต่อ (ST-19) → ปุ่มปกติ กดแล้ว toast "ยังไม่ได้ต่อหุ่น ปุ่มนี้ยังไม่ต้องใช้" · ST-21 → กดแล้วไฮไลต์บรรทัดถาวรข้อ 3 (ไม่ใช่ hint ชั่วคราว) · `title`/tooltip ตามสถานะ ไม่ใช้ "ต่อหุ่นก่อนจึงใช้ได้" ตอนหลุด (AUD-F02)

## 4. Checkbox "ดูรอบหุ่นแล้ว" ที่เดียว (`sb-check`)
แถวเดียวในเนื้อหา ชิดเหนือ `sb-actionbar` ตำแหน่งตายตัว ใช้ร่วม ST-48 (พาไปท่าพัก/พาอีกครั้ง) **และ dialog ตัดการเชื่อมต่อ (ข้อ 6)** · ข้อความ "ดูรอบหุ่นแล้ว ไม่มีของหรือมือใกล้แขน" ตรงกับ popup ใน Arm Lab (D1 ข้อ 6) · เลิกสำเนาที่กล่อง "ต่ออยู่" (`foldChecked`) · แถวสูง ≥ `control-sm` 44 · ติ๊กแล้วปลดล็อกปุ่ม `sb-btn-robot` · ไม่ติ๊ก = `aria-disabled` + เหตุผล "ดูรอบหุ่นแล้ว แล้วติ๊กก่อน"

## 5. การ์ดหุ่น: แตะทั้งการ์ดเพื่อเลือก
- การ์ด = `sb-card` กดได้ (ขอบล่างนูน `border-raise`) · ไม่มีปุ่มต่อแถว · กลุ่มการ์ด `role="radiogroup"` ชื่อ "หุ่นที่พบในเครื่องนี้" · แต่ละใบ `role="radio"` `aria-checked` (DS Card ระบุ `aria-pressed`/`aria-selected` · ใช้ radio ตามคำสั่งผู้ใช้ ขัดเล็กน้อยกับข้อความ DS แจ้งไว้) · ลูกศร ←/→ เลื่อนเลือก · Space/Enter เลือก
- selected = state `selected` ของ DS (ขอบ 3px `action-primary` + พื้น `action-primary-subtle` + ข้อความ "เลือกอยู่") · focus ring วงนอก offset 2
- สถานะบนการ์ด `sb-dev-st`: "กำลังใช้อยู่" = `ok` · "สายหลุด · รอเสียบกลับ" = `err` (`circle-alert` + `danger`) · เลิกป้ายพิลล์สี
- การ์ดที่กดไม่ได้ = `aria-disabled` (พื้น `off-bg` ขอบ `border`) + เหตุผลตามข้อ 3
- อุปกรณ์อื่นที่ไม่น่าใช่หุ่น: การ์ดเล็กแบบเดียวกัน เลือกแล้วใช้ปุ่มหลักขวาเหมือนกัน

## 6. dialog ตัดการเชื่อมต่อ (OQ28 answered)
แทนกล่องเหลืองในหน้าด้วย `sb-dialog` (520) + `sb-scrim-lab` เว้นปุ่มหยุด · `role="alertdialog"` · โฟกัสเริ่มที่ "ยกเลิก" · ท้าย dialog ใช้ `sb-dialog-actions`
- เนื้อหา: ตัวเลือกเรียงตามความปลอดภัย · **"พับแขนลงกล่องแล้วตัด"** เป็นตัวเลือกใน dialog นี้ (ปุ่ม `sb-btn-robot` ขวา เพราะหุ่นขยับ) · ปลดล็อกด้วย `sb-check` "ดูรอบหุ่นแล้ว" **ตัวเดียวกับข้อ 4 (ข้อความเดียว ไม่มีสำเนาที่สอง)** · ไม่ติ๊ก = `aria-disabled` + เหตุผล
- ไม่มีท่ายังไม่อัปโหลด: "ยกเลิก" (รอง) · "ตัดการเชื่อมต่อ" (`sb-btn-secondary`) · "พับแขนลงกล่องแล้วตัด" (`sb-btn-robot` · ต้องติ๊ก)
- มีท่ายังไม่อัปโหลด: "ยกเลิก" · "ตัดโดยไม่อัปโหลด" (รอง) · "อัปโหลดลงบอร์ดแล้วตัด" (หลัก · ทางปลอดภัย) · และตัวเลือก "พับแขนลงกล่องแล้วตัด" ตามเงื่อนไขเดียวกัน (ปุ่มหลักตัวเดียวยังคงเป็นตัวที่ปลอดภัยที่สุด)

## DS gap
เติมแล้วใน DS เวอร์ชัน 11 (OQ27 · 2026-11-04): gap 1 แถบปุ่มล่าง → `sb-actionbar` · gap 2 กล่องสถานะ → `sb-notice` · gap 3 checkbox → `sb-check` · gap 6 ชั้นแถบหน้าต่าง → `z-windowbar` 65
ยังไม่เติม (ผู้ใช้ให้ใช้ของเดิมใน DS ไปก่อน · ห้ามเติมเอง):
- **DS gap 4:** แถบความคืบหน้า (กำลังพาไปท่าพัก, เชื่อมสำเร็จ 2 วินาที) · ใช้ที่ ST-48 กำลังพา, เชื่อมสำเร็จ · ใกล้เคียงที่สุดใน DS: `sb-spin` (ไม่ใช่แถบ) + สี `action-robot`/กฎ Attention · ตอนทำ frame: ใช้ `sb-spin` + ข้อความแทน ไม่วาดแถบเอง
- **DS gap 5:** select/ช่องอ่านอย่างเดียวของ Baud rate และ `sb-input` สำหรับชื่อหุ่น · ใกล้เคียง: `sb-input`
- **DS gap 7:** การ์ดข้อมูลไม่กดได้ (ขั้นตอนเช็ก 1–2–3, รายการเช็กทีละข้อ) · ใกล้เคียง: `sb-card` (เฉพาะแบบกดได้) · ใช้ `sb-notice` (info) เป็นกล่องข้อมูลไปก่อน

## ข้อสังเกต (ไม่ตัดสินเอง)
- **Baud rate:** คงไว้ตามเดิม (ผู้ใช้ตัดสิน) เป็นช่อง select อ่านอย่างเดียว + ไอคอนกุญแจ + ป้าย "ตั้งตามหุ่นอัตโนมัติ" · อยู่ใกล้ปุ่มในแถบและรูปเหมือนปุ่มกดได้ เด็กอาจลองกดแล้วสับสน · ผู้ใช้ตัดสินว่าจะย้ายไปในเนื้อหา/เป็นข้อความธรรมดา
- ช่องปุ่มรองว่างในหลายสถานะ · แถบมีปุ่มหยุดซ้ายสุด + ปุ่มหลักขวา
- ปุ่มหยุดชิดซ้ายล่างใกล้ปุ่มรอง ("ยกเลิก"/"ตัดการเชื่อมต่อ") ที่อยู่ด้านขวา คั่น spacer ไกลกัน เพื่อกันกดผิด (H5)
- เชื่อมสำเร็จแล้วไป Arm Lab อัตโนมัติ 2 วินาที (ของเดิม) เด็กอ่านไม่ทัน/ยกเลิกไม่ได้ (H3) · ไม่ได้เปลี่ยนในรอบนี้
- หุ่นวาด SVG เปลี่ยนเป็นมาสคอตตาม DS (เกิน OQ25 เล็กน้อย) · ถ้าไม่ต้องการ แจ้งให้คงไว้
- `sb-btn-stop` ตัวอักษร 20px ต่างจากปุ่มอื่น 16px ตาม DS (ไม่แก้)

## Heuristics / WCAG AA
- H1 สถานะเห็นตลอด (spinner + ข้อความ, status บนการ์ด) · H3 ทางออกซ้าย/ปุ่มหยุดเห็นตลอด · H4 ชื่อและตำแหน่งปุ่มเหมือนกันทุกสถานะ · H5 ไม่มีทางข้ามท่าพัก + ปลดล็อกด้วย checkbox ตัวเดียว · H6 การ์ด selected (ขอบ+พื้น+ข้อความ) · H9 error บอกวิธี ไม่ตำหนิ · H10 รายการเช็กทีละข้อ
- Contrast (ตาม README DS ไม่ได้คำนวณใหม่): ขาวบน `action-primary` 5.55 · `text-primary` บน `action-robot` 6.59 · ขาวบน `stop` 4.98 · `text-secondary` บน `off-bg` 5.56 · `success` 5.13 · `danger` 4.98
- เป้ากด: ปุ่ม 56 · ปุ่มรอง/หัวรายการ 44 · การ์ด ≥ 44 · `sb-check` ≥ 44 · keyboard: Tab การ์ด → checkbox → หยุด → รอง → หลัก (ลำดับ DOM ตามซ้ายไป ขวา) · ปุ่มปิดใช้ `aria-disabled` โฟกัสได้ + เหตุผล · `role="status"` สถานะ/toast · `role="alert"` เฉพาะ error ใหม่ · reduced-motion: spinner ไม่เคลื่อน
- **ยังไม่ได้ตรวจ:** render/screenshot, contrast ที่คำนวณใหม่, screen reader, ซูม 200%, ภาษาอื่น +40% (ป้าย "เชื่อมต่อ <ชื่อ>" ยาว), ความกว้างแถบเมื่อมีปุ่ม หยุด + รอง + หลัก ในหน้าต่างแคบ (ต้องตรวจตอน render)
