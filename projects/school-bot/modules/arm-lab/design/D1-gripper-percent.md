## สิ่งที่เปลี่ยน
1. **Slider S5 (MainV6AJoints):** แถบหนึ่งทิศ 0–100% ซ้าย = ปิด ขวา = เปิด · ป้ายที่ปลายแถบ "ปิด 0%" / "เปิด 100%" (12px ตัว 700 สี #3F5A7A) · ไม่มีเส้นกลาง ไม่มีเลข 0 กลางแถบ ไม่มีแถบลายขีดจำกัด 5% (ของ S0–S4 ที่เป็น ±) · ไม่มีสัญลักษณ์ ° ทุกที่ของ S5 · ใส่ `role="meter"` + `aria-valuemin/max/now/valuetext` ที่แถบ (S5 อ่านว่า "เปิด 50 เปอร์เซ็นต์" / "ปิดสุด 0 เปอร์เซ็นต์" / "เปิดสุด 100 เปอร์เซ็นต์" · S0–S4 อ่านค่ามุมเดิม)
2. **ช่องพิมพ์ S5:** รับ "50" หรือ "50%" (ค่า = 50%) · ทศนิยม, เครื่องหมายลบ, ตัวอักษรไม่รับ → ขึ้นข้อความแจ้ง + คงค่าเดิม · ค่านอก 0–100 (เช่น 150) clamp แล้วแจ้ง "ใส่ได้ 0% ถึง 100% · ปรับเป็น 100%" (ใช้ msgPop เดิม)
3. **ขั้นแก้ S5:** กดค้างปุ่ม ◀ ▶ = ±5% ตรงค่า ไม่ snap (47 → 52) หยุดที่ 0/100 · พิมพ์/ลูกศร (ปุ่ม ‹ › หรือ ← →) = ±1% · ป้ายปุ่มและคำแนะนำปรับเป็น "ลด 1%" / "เพิ่ม 1%"
4. **แสดงผลทั่วไป:** `fmt` ของ S5 = "50%" (เดิม "เปิด 50%" ซึ่งอ่านผิดที่ 0%) ใช้ในข้อความขีดจำกัด, ล็อก, ปลดล็อกข้อต่อ, ท่า 0
5. **ตารางลำดับท่า (MainV6ASeq):** หัวคอลัมน์ "S5 (%)" · ทุกเซลล์ S5 มีเครื่องหมาย % ต่อท้าย · เซลล์พิมพ์ "50%" ได้ (ตัด % ก่อนเก็บ) · ลูกศรขึ้นลง ±1 (Shift ±10) · ท่า 0 แสดง "50%" · aria-label "มือคีบ เปอร์เซ็นต์ (0 = ปิด, 100 = เปิด)" ไม่มีคำว่าองศา
6. **popup "ก่อนหุ่นขยับ" (MainV6ABar · ST-24):** เพิ่มกล่องถาวร "เก็บนิ้วออกจากมือคีบ ก่อนหุ่นขยับ" (พื้น #FFF4E8 ขอบ #FF8A00 ตัวอักษร #8A4700 13px/700 + ไอคอน warn) เหนือข้อความช่วย · เปิดทุกครั้งที่ popup ขึ้น ไม่ขึ้นกับสถานะติ๊ก
7. **เตือนไกล 30° (ST-23):** logic `maxDiff` นับเฉพาะ S0–S4 อยู่แล้ว (ท่าที่ต่างที่ S5 อย่างเดียวไม่เตือน) · ไม่ต้องแก้

## ค่าที่ใช้
สีทั้งหมดมาจากชุดสีเดิมของ frame (#14243D, #5A6377, #3F5A7A, #8A4700, #FFF4E8, #FF8A00) · ไม่มี `design-tokens.md` ของโปรเจกต์ → ค่าชั่วคราวตาม frame ฐาน · Shift = ±10 สำหรับ S5 เป็น **ค่าชั่วคราว** (requirement ไม่ระบุ · ให้ S0–S4 เดิมคือ 10 เท่า)
ค่าที่เก็บจริง PWM 500–2500 (PWM = 500 + 20 × %) · UI ไม่แสดง PWM (ฟังก์ชัน gcode เดิมคำนวณ PWM ภายในเท่านั้น)

## Heuristics / WCAG AA
- H1/H2 (ป้ายคำ ปิด/เปิด ตรงกับของจริง), H5 (ป้องกันพิมพ์ผิด: แจ้ง + คงค่าเดิม), H4 (ใช้ % เหมือนกันทุกที่), H9 (ข้อความแจ้งบอกวิธีแก้ที่ถูก)
- ตัวอักษรป้ายปลายแถบ #3F5A7A บนขาว ≈ 7.7:1 (ผ่าน 4.5:1, ดีกว่า #8A96A3 เดิม ~3:1 ของ S0–S4) · ข้อความเก็บนิ้ว #8A4700 บน #FFF4E8 ≈ 6.9:1 · สีไม่ใช่ตัวบอกอย่างเดียว (มีไอคอน + ข้อความ)
- ปุ่ม/ช่องพิมพ์ขนาดเดิม (ปุ่มกดค้าง 48×40) · **ยังไม่ได้ตรวจ** (ไม่ได้ render) ขนาดเป้าสัมผัส ≥ 44px ของปุ่มกดค้าง (สูง 40px เป็นค่าเดิมของ frame ฐาน)
