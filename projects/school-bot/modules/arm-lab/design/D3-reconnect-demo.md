## State (Ready · Lost · Reconnecting · Failed · Verify · Unconfirmed · Offline)
- ช่องสถานะใต้แถบ N1 (สูง 88 ตายตัว) ใช้ช่องเดียวทุก state ไม่ทับ ไม่ดัน: Ready = บริบทท่า + ร่าง · Lost = `sb-notice-warning` + "Editing Paused" + บรรทัดถอดสายไฟ adapter ถาวร · Reconnecting = `sb-notice` + 3 ขั้น (พบอุปกรณ์ / ตรวจหุ่นตัวเดิม / สร้างการเชื่อมต่อใหม่) · Failed = `sb-notice-error` + "ลองอีกครั้ง" · Unconfirmed = เชื่อมแล้วยังไม่ตรวจแขน + ปุ่ม "ตรวจตำแหน่งแขน" · Offline = เปิดโปรแกรมใหม่ ร่างถูกเรียกคืน
- ชิปบนแถบแยก "เชื่อมต่อแล้ว" ออกจาก "พร้อมสั่งงาน" (warn = เชื่อมแล้วยังไม่พร้อม)
- Modal Verify (`sb-dialog` + `sb-scrim-lab` เว้นปุ่มหยุด): โฟกัสเริ่มที่ "ยกเลิก" · Esc = ยกเลิก · ข้อความ "การยืนยันจะไม่ทำให้แขนกลเคลื่อนไหวทันที" · ระบุว่าปุ่มหยุดแทนปุ่มหยุดฉุกเฉินของหุ่นไม่ได้ · แบบหุ่นตัวอื่น: "พบหุ่นอีกตัว"

## กติกาฮาร์ดแวร์ที่ demo ทำให้ดู
1. ไม่ส่งค่าร่างกลับเอง (ตัวนับ "ส่งเอง" = 0) · 2. คำสั่งค้างตอนหลุดถูกทิ้ง ไม่ส่งซ้ำ · 3. เปิด/แตะ slider ไม่ขยับ ไม่ส่ง · 4. ร่าง (แอปจำไว้) แยกจากแขนจริง (มุมมองผู้ทดสอบเท่านั้น แอปไม่เคยแสดงตำแหน่งจริง) · 5. คำสั่งแรกของแต่ละข้อต่อหลังเชื่อมกลับช้ากว่าปกติ (5000 ms **ค่าสมมติ รอ firmware**) · 6. ตัวเลขข้อต่อมีป้าย "ค่าที่สั่งล่าสุด" / "ค่าร่างที่จำไว้ · ไม่ทราบตำแหน่งแขน" · knob เปลี่ยนเป็นเส้นประจนกว่าจะขยับครั้งแรก
Edge case: หลุดซ้ำ · หลุดก่อนยืนยัน · ไม่ยืนยัน · เปลี่ยนหน้า (ปุ่มบ้าน) · ปิด/เปิดโปรแกรม · บันทึกตอนหลุด (บันทึกได้ แจ้งว่าไม่ได้ตรวจกับแขน) · ขยับตอนหลุด · หุ่นคนละตัว · กดควบคุมทันทีหลังเชื่อมกลับ (ถูกกัน + เหตุผล)

## DS gap (ยังไม่เติม · แจ้งผู้ใช้แล้ว)
- แถบ servo meter + knob + ปุ่มลูกศร (ไม่มีใน DS) · ใกล้เคียง: `sb-ibtn` · ใช้ token ล้วนแทน (ชั่วคราว)
- ป้ายสถานะ (tag/pill) ร่าง/Editing Paused · ใกล้เคียง: `sb-dev-st` · ใช้ token ล้วนแทน (ชั่วคราว)
- ขั้นตอนความคืบหน้า 3 ขั้นใน `sb-notice` (DS gap 4 เดิม)
