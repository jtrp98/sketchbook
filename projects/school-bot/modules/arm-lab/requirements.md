# Arm Lab: Requirements (จาก role 1)

> นำเข้ารายละเอียดจากระบบเก่า (`Handoff/01_REQUIREMENT` v3.1 + ผลหลังจากนั้นถึง 2026-10-21) · **sketchbook เป็นแหล่งความจริงแล้ว** ไม่ต้องเปิดโฟลเดอร์เดิม · ID เดิม (FR/NFR/EC/AC/DEC/ST/SCR) เก็บไว้ในวงเล็บเพื่อ grep ข้ามไฟล์ · ป้ายหลักฐาน (Confirmed/Observed/Proposed ฯลฯ) ดู `../../context.md`
> R1–R11 ID เดิม ไม่เปลี่ยนความหมาย · R12–R17 เพิ่มวันนี้ (นำรายละเอียดฟังก์ชัน 6A ที่ผู้ใช้อนุมัติแล้ว และผล CR-11 เข้ามา) ดู CHANGELOG

## เป้าหมาย
นักเรียน ป.1–6 (UI เดียวกันทุกชั้น) สอนท่าแขนกล 6 ข้อต่อ (S0–S5) แล้วเล่นเป็นลำดับ กับหุ่นที่มีบอร์ด Raspberry Pi ผ่าน USB · ครูตั้งค่าขั้นสูงแบบ Zide ในโหมดครู · ฐานงานออกแบบ: frame 6A แขนกล (MainV6A) ที่ผู้ใช้อนุมัติแล้ว (รีดีไซน์จาก Zide)

## Requirements
ลำดับ: M = Must · ? = ยังไม่ยืนยัน (ดู OQ)

- R1 (M): ใช้ frame 6A แขนกล (MainV6A) เป็นฐานฟังก์ชันและ layout · **อนุมัติแล้ว (DEC-08)** แก้ผ่านใบสั่งแก้เท่านั้น ห้ามทำใหม่ทั้งหน้า · ฟังก์ชันและพฤติกรรมความปลอดภัยต้องครบตาม R5, R12–R16 หลังปรับให้เข้ากับ cloud, Raspberry Pi และ ป.1–6 · **ขนาดปุ่ม/ตัวอักษรคงตาม 6A เดิม ไม่ปรับให้ผ่านเกณฑ์ ≥16px/44px** (ผู้ใช้ตัดสิน 2026-10-21 · OQ20) · โน้ตเพื่อทบทวนอนาคต: ใน 6A มี control ต่ำกว่า 16px อยู่ 129 จาก 152 ตัว ไม่ผ่านเกณฑ์เด็กของ brand/context.md (ความเสี่ยงที่ยอมรับ ร่วมกับ RSK-04) · (FR-10, AC-07, DEL-04)
- R2 (M): ใช้กับแขนกลที่มีบอร์ด Raspberry Pi · โปรโตคอล "ใกล้เคียง Zide" (ผู้ใช้ตอบ 2026-10-20 → คง 6A เกือบทั้งหมด) · 6A สมมติ COM7 ที่ 115200, PWM 500–2500, คำสั่งรูปแบบ `{G0001#000P1500T3000!}` [Observed EV-03] · รายการค่าตั้งขั้นสูงยืนยันกับ firmware → OQ1, OQ12 · (FR-11, DEC-07)
- R3 (M): แขนกลบนจอ**ไม่ขยับไม่ว่ากรณีใด** (ไม่มีการจำลอง) ทั้งเล่นท่า ขยับข้อต่อ หรือทำอะไรก็ตาม · (FR-12, AC-08, CON-07)
- R4 (M): โหมดครูของ Arm Lab: การตั้งค่าขั้นสูงแบบ Zide · ครู**ของโรงเรียนเดียวกับนักเรียนที่ login อยู่** เข้าได้โดย login ด้วยบัญชี SchoolBright ของตัวเองใน dialog (แทน "ใส่รหัส") · (FR-13, AC-09, DEC-09, UJ-06) · การจบเซสชันครู → OQ9
- R5 (M): ปุ่มหยุดเห็นได้ตลอด · เตือนก่อนสั่งขยับไกลหรือเล่นวนไม่หยุด · ปิดปุ่มสั่งงานเมื่อหลุดการเชื่อมต่อ · (FR-14, NFR-04, AC-07)
- R6 (M): งานบันทึกบน cloud ผูกกับบัญชีเป็นค่าเริ่มต้น · (FR-22, AC-13, DEC-13) · รายละเอียดหน้ารวมงาน/sync อยู่ module `my-work`
- R7 (M): export งานเป็นไฟล์ .ini ได้ (Arm Lab = .ini ที่เปิดใน Zide ได้ · ผู้ใช้ตอบ 2026-10-20) · (FR-23, AC-13)
- R8 (M): กู้คืนงานสำรองที่อยู่ในเครื่องได้ (6A สำรองอัตโนมัติทุก 10 วินาที) · (FR-24, AC-13)
- R9 (?): นำท่าหรืองานจากไฟล์ .ini เข้ามาได้ · Inferred จาก frame (Ctrl+A) · frame ปัจจุบันทำปุ่ม "นำเข้าจากไฟล์ .ini…" แล้ว · → OQ4 · (FR-25)
- R10 (M): ใช้ UI เดียวกันทั้ง ป.1–6 ต้องอ่านและใช้ได้สำหรับ ป.1 · เป้า WCAG 2.2 AA + เกณฑ์เด็ก (`../../context.md`) · ไม่มีตัวช่วยเพิ่มสำหรับ ป.1–3 ใน MVP (RSK-04 ยอมรับ) · frame เดิมสมมติผู้ใช้ ป.4–6 ต้องปรับข้อความ/ความซับซ้อน (CF-02) · **ยกเว้นขนาดปุ่ม/ตัวอักษร: คง 6A เดิมตาม R1 (ยังไม่ผ่านเกณฑ์ 16px/44px · ทบทวนภายหลัง)** · (NFR-02, DEC-06, DEC-19, EC-06, AC-15)
- R11 (M): เชื่อมต่อหุ่นผ่าน USB ในโปรแกรมติดตั้ง Windows/Mac · ไม่ต้องติดตั้ง driver (ฝังใน installer) · สถานะ: ยังไม่เชื่อม (ปุ่มสั่งงานปิด) / กำลังเชื่อมต่อ / เชื่อมแล้ว / หลุด · ชื่อหุ่นและการจับคู่ → OQ5 · (NFR-03, EC-03, FR-11, ST-19, ST-20)

### รายละเอียดฟังก์ชัน 6A (Observed EV-03 · frame อนุมัติแล้ว ต้องรักษาไว้)

- R12 (M) **ท่าและท่าชุด:** ท่ามีรหัส `G####` · ท่าชุด (action group) สีม่วง `K####` (tooltip เดิมเขียนสลับ = BUG-05) · ท่า 0 "แขนตั้งตรง" **แก้ไขไม่ได้** · ท่า 0 กับท่าพักเป็นคนละท่า · เพิ่มท่า · คัดลอก ตัด วาง ลบ · เลิกทำได้ **6 วินาที** · ลำดับท่าแสดงเป็นการ์ดหรือตาราง · เลือกท่าด้วยแถบ ‹ › หรือแตะจุด S0–S5 บนเวทีหุ่น · **เรียงลำดับท่าด้วยปุ่มขึ้น/ลงบนการ์ดท่า (ไม่ต้องลาก · WCAG 2.5.7) โดย UI ต้องไม่เทอะทะ** · **ท่าชุด K#### คงอยู่ใน MVP** Designer เสนอวิธีสร้าง/เล่นที่เด็ก ป.1–6 เข้าใจง่าย (ผู้ใช้ตัดสิน 2026-10-21 · OQ20) · (ENT-14, ENT-15)
- R13 (M) **ข้อต่อและขีดจำกัด:** ข้อต่อ 6 ตัว S0–S5 · **S0 ±180° · S1–S4 ±135° · มือคีบ 0–100%** · เวลาเข้าท่า **1000–9000 ms (ค่าตั้งต้น 3000)** · ค่าเกินขีดจำกัดต้องถูกป้องกันหรือเตือน · แก้ค่าได้ 3 ทาง: กดค้าง (ขยับทีละ 3°) พิมพ์หรือใช้ลูกศร (ทีละ 1° · ต่างกัน = BUG-11 ต้องทำให้สม่ำเสมอ) · ค่าเริ่มต้นไม่สอดคล้อง: ตารางแสดงเวลาท่า 0 = 2000 แต่ `POSE0.t` = 3000 · ท่าแรกที่เพิ่มได้มือคีบ 0% แต่ท่า 0 ใช้ 50% (BUG-06)
- R14 (M) **แก้ท่า อ่านค่า ประวัติ:** ต้องให้หุ่นอยู่ที่ท่านั้นก่อนจึงแก้ได้ (แก้แล้วมีผลทันที) · **slider หลังพาหุ่นไปท่าพัก (ผู้ใช้ตัดสิน 2026-10-21):** ยังเลือกท่าเดิม (เช่น ท่า 3) และ slider คงค่าที่บันทึกไว้ของท่านั้น แต่**ล็อก**พร้อมข้อความว่าหุ่นยังไม่ได้อยู่ที่ท่านี้ จนกว่าจะกด "ไปท่านี้" (ผ่านเตือน >30° และติ๊กดูรอบหุ่นตาม R15) หุ่นไปถึงแล้วจึงปลดล็อก · slider ไม่ใช่ตำแหน่งจริงของหุ่น ห้ามลากแล้วสั่งหุ่นกระโดดทันที · **ปลดล็อกข้อต่อ (คลายแรงบิด) เพื่ออ่านท่าปัจจุบันจากหุ่น** — มีเตือน "แขนอ่อน" + นับถอยหลัง · **ผู้ใช้ตัดสิน 2026-10-21 (OQ18 บางส่วน):** นักเรียนใช้ปลดล็อกได้เอง ตาม 6A เดิม · ระหว่างนับถอยหลังมีปุ่ม "ยกเลิก" ตลอดช่วงนับ และเวลานับต้องนานพอให้เตรียมตัว · **ถ้าสายหลุดตอนแขนอ่อนอยู่ (ล็อกกลับไม่ได้):** ขึ้นหน้าจอเตือนแยก "ประคองแขนไว้ก่อน แขนยังอ่อนอยู่" + บอกให้เรียกครู (ถาวร ไม่หายเอง) · **ยังไม่ตัดสิน (พับไว้):** วิธีล็อกแขนกลับ — ตัวเลือก ก) กดค้างปุ่มเดียว ปล่อยแล้วล็อก+อ่านท่าเอง (ไม่ต้อง 2 คลิก ไม่มีทางลืมล็อก ต้องมีทางเลือกสำหรับคนกดค้างไม่ถนัด เช่น ปุ่ม Space ค้าง) ข) กดครั้งเดียว มีแถบเหลือง "แขนอ่อนอยู่ จับแขนไว้" และล็อกเองเมื่อครบเวลา/กด "เสร็จ" ค) ตามเดิม: ล็อกอัตโนมัติหลังกด "อ่านท่าปัจจุบัน" + ปุ่ม "ล็อกแขนกลับ" (ใช้ 2 คลิก ผู้ใช้ห่วงว่ายากสำหรับเด็ก) · ทุกวิธีต้องมีข้อความถาวรว่า "แขนล็อกอยู่ ห้ามบิดด้วยมือ ถ้าจะจับแขน กดปุ่มนี้ก่อน" (กันบิดแขนตอนล็อก) · ผลต่อ OQ1: ถ้า Pi อ่านค่าตอนคลายแขนไม่ได้ ตัดขั้นปลดล็อกทั้งชุดและใช้กรอกมุมแทน · "อ่านค่าตอนคลายแขน" ทำได้ไหมบน Pi = ยังไม่ยืนยัน (OQ1, OQ12) · ประวัติการใช้งาน (ENT-23) · ใช้คำว่า "อ่านท่าปัจจุบัน" (ห้าม "อ่านท่าจากหุ่น")
- R15 (M) **การเล่น:** ก่อนเล่นต้อง**ติ๊ก "ดูรอบหุ่นแล้ว"** (ST-24) · เล่น**จากโปรแกรม**หรือ**จากบอร์ด** ("เล่นจากบอร์ด" ขึ้นกับ firmware = OQ1) · เลือกช่วงท่าและ**จำนวนรอบ 1–9 หรือวนไม่หยุด** (วนไม่หยุดต้องเตือน ST-23) · **เตือนเมื่อสั่งขยับไกลเกิน 30°** (ST-23) · **นิยาม (ผู้ใช้ตัดสิน 2026-10-21 · OQ16):** วัดต่อข้อต่อ ตามเส้นทางจริงที่ข้อต่อหมุน (S0 ที่หมุนอ้อมหลังหุ่นนับตามจริง) · ตำแหน่งหุ่นที่ไม่ทราบ (เชื่อมครั้งแรก/เชื่อมใหม่/แขนอ่อน/กู้คืนงาน) ถือว่าไกลเสมอ · การขยับจากท่าสุดท้ายกลับท่าแรกเมื่อเล่นหลายรอบ/วนไม่หยุดนับด้วย · เตือนครั้งเดียวก่อนเริ่มทั้งลำดับ พร้อมรายการก้าวที่ไกล · การติ๊ก "ดูรอบหุ่นแล้ว" รีเซ็ตทุกการเชื่อมต่อใหม่ และเมื่อแก้ลำดับหลังติ๊ก · ปุ่มหยุดสีแดงอยู่ข้างปุ่มเล่น · ระหว่างเล่น (ST-22): ปุ่มหยุดเด่นชัด รูปแขนนิ่ง · อัปโหลดลำดับท่าลงบอร์ดได้ (ใช้คำ "อัปโหลดลงบอร์ด") · (ENT-16)
- R16 (M) **หุ่นหลุดและเชื่อมกลับ (CR-11 · Proposed ฝั่งพฤติกรรมหุ่น Unknown = OQ11):** เมื่อสาย USB หลุดหรือหุ่นไม่ตอบ (ST-21): ปิดปุ่มสั่งงานทั้งหมด · เล่นท่าในแอปหยุด · **ปุ่มหยุดยังเห็นอยู่** แต่ส่งคำสั่งไม่ได้ → กดแล้วบอก**วิธีหยุดทางกายภาพ (ปิดสวิตช์/ถอดสายไฟ adapter ของหุ่น) เป็นข้อความถาวรในแถบแจ้ง** ไม่ใช่ hint ชั่วคราว · **ห้ามเขียนว่า "หุ่นหยุดแล้ว"** จนกว่า firmware ยืนยัน · งานไม่หาย ดูและบันทึกได้แต่แก้ท่าไม่ได้ (การแก้ท่าต้องมีหุ่นอยู่ที่ท่านั้น) · ปุ่ม "เชื่อมต่อใหม่" → หน้าเชื่อมต่อ · **หลังเชื่อมใหม่สำเร็จ (ST-48):** Arm Lab ล็อกจนกว่าจะ **ติ๊ก "ดูรอบหุ่นแล้ว" → "พาหุ่นไปท่าพัก" (ท่า 0 · Inferred)** สำเร็จ · **ขั้นติ๊ก+พาไปท่าพักรวมเป็น popup เดียว** และใช้ทุกครั้งที่เชื่อมหุ่น **รวมการเชื่อมครั้งแรกของวัน** ไม่ใช่เฉพาะหลังสายหลุด (ผู้ใช้ตัดสิน 2026-10-21 · OQ16) · **ไม่มีปุ่มข้ามขั้นนี้** แต่ระหว่างล็อกเด็กเข้า "โหมดไม่ใช้หุ่น" ได้: ดู แก้ลำดับ บันทึก ส่งออกงาน โดยปุ่มสั่งหุ่นปิดทั้งหมด ไม่นับเป็นการข้ามท่าพัก (ผู้ใช้ตัดสิน 2026-10-21 · OQ15) · ถ้าพาไปท่าพักไม่สำเร็จ → กลับ ST-21 · **ออก/สลับงาน/ปิดโปรแกรมขณะหุ่นกำลังขยับ:** ห้ามจนกว่าจะกดหยุด แสดง dialog "หยุดก่อนแล้วไปต่อ" และไม่เขียนว่า "หยุดแล้ว" ถ้า firmware ไม่ยืนยัน (dialog ปิดโปรแกรมของ app-shell ต้องปรับตาม) (ผู้ใช้ตัดสิน 2026-10-21 · OQ15) · ทั้งหน้าเชื่อมต่อและ Arm Lab ต้องใช้กติกาเดียวกัน
- R17 (M) **เมนู ☰ และคีย์ลัด:** บันทึกงาน (Ctrl+S) · บันทึกสำเนา… · ส่งออกเป็นไฟล์ .ini · นำท่าจากงานอื่น/นำเข้าไฟล์ .ini (Ctrl+A) · งานของฉัน (Ctrl+O) · **งานใหม่ (Ctrl+N) สร้างงาน Arm ใหม่ในหน้าเดิม** (งานเดิมบันทึกก่อนสลับ · ถ้าบันทึก/sync ไม่สำเร็จใช้ leave guard เดียวกับ "งานของฉัน") · ประวัติ (Ctrl+H) · เมนูครู · เกี่ยวกับ School Bot Studio · ต้องตัดสิน: Esc ตอนไม่มีอะไรเปิดอยู่จะหยุดหุ่นทั้งหมด (Inferred) และ Ctrl+A/Ctrl+H ชนกับปุ่มลัดมาตรฐาน (BUG-10 → OQ13)

## กฎ/Logic
- แขนบนจอไม่ขยับในทุกสถานะ (R3)
- โหมดครู (R4) · AC-09: **When** เปิดเมนูครู **Then** ต้อง login ด้วยบัญชีครูของโรงเรียนเดียวกันก่อนจึงเห็นการตั้งค่าขั้นสูง · บัญชีผิด หรือไม่ใช่ครูของโรงเรียนนี้ → ข้อความบอกวิธีแก้ ไม่เข้าโหมดครู · ออฟไลน์ใช้ได้ถ้าบัญชีนั้น**เคย login บนเครื่องนี้** (ตอบแล้ว: DEV-Q07) · ออกจากโหมดครู → กลับเป็นนักเรียนคนเดิม งานไม่หาย (Proposed) · โหมดครูหมดเวลาเมื่อไม่ใช้งาน 10 นาที และออกเมื่อปิด Arm Lab (Proposed · Delegated → OQ9)
